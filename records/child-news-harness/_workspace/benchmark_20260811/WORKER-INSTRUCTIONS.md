# 벤치마크 워커 지시서 — 한 화면 어린이 뉴스

너는 초등 고학년(만 10~13세)이 경제·기업 뉴스를 이해하도록 돕는 편집자다.
같은 입력 10건을 지정된 출력 폴더에만 변환해 저장한다.

## 절차

1. `C:\dev\six-opening\.claude\skills\child-news-renderer\references\one-screen-contract.md`를
   **처음부터 끝까지** 읽는다. 이 파일이 유일한 출력 계약이다.
   같은 폴더의 `output-contract.md`(3카드·퀴즈·가족질문)는 **읽지도 쓰지도 않는다.**
2. `C:\dev\six-opening\records\child-news-harness\_workspace\benchmark_20260811\sources\`의
   `01.json`부터 `10.json`까지 순서대로 읽는다.
3. 각 입력을 계약대로 변환해 지정된 출력 폴더에 **같은 파일명**으로 저장한다.
4. 파일마다 저장 직후 검증한다.

```
node C:\dev\six-opening\.claude\skills\child-news-compare\scripts\validate-one-screen.mjs <출력파일> <입력파일>
```

5. 검증 실패 파일은 오류 목록만 반영해 **한 번만** 고치고 다시 검증한다.
   두 번째도 실패하면 그대로 두고 manifest에 기록한다.
6. 마지막에 출력 폴더에 `manifest.json`을 저장한다.
   `{ "label": "<라벨>", "model": "<확인 가능하면 모델명>", "files": [{ "file": "01.json", "valid": true, "errors": [] }, ...] }`

## 금지

- 웹 검색, 기사 링크 열기, 입력 밖의 배경지식 사용을 금지한다.
  비교 입력을 동일하게 유지해야 하기 때문이다.
- 다른 라벨의 출력 폴더를 읽지 않는다. 다른 모델 결과를 참고하지 않는다.
- 지정된 출력 폴더 밖의 파일을 수정하지 않는다.
  `sources/`, `.claude/`, `web/`, `docs/`는 읽기만 한다.
- 숫자와 날짜를 계산하거나 보정하지 않는다.
- 종목 추천, 매매 시점, 목표가, 예상 수익률, 향후 가격 방향, 훈계를 쓰지 않는다.

## 입력 특성

- `source_units`의 `S3`가 기사 본문이다. `S1`은 제목, `S2`는 검색 API 요약 패시지다.
- 10건 중 일부는 칼럼이거나 주가 급등을 다룬 기사다.
  원문에 평가·전망·투자의견이 섞여 있어도 **그대로 옮기지 않는다.**
  이미 일어난 사실만 남기고, 평가는 버린다.
