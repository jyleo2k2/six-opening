# f2-trade — 모의투자 (담당 에이전트 전용)

- 이 디렉터리의 `AGENTS.md`와 `CLAUDE.md`는 한 쌍이다. 둘 중 하나를 수정하면 같은 작업에서 짝 파일도 동일하게 수정하고 완료 전 비교한다.
- 소유: 이 폴더 전부. 밖은 수정 금지.
- 스펙: `docs/기능명세.md` F2 + `docs/디자인시스템.md`.
- 화면: 종목 탐색(검색+업종 칩+리스트) → 종목 상세(현재가·라인 차트·내 보유·**아이 눈높이 설명 카드 2개**) → 매수/매도(수량→예상 금액→**f3 질문식 기록 폼 삽입**→시장가 즉시 체결) → 보유종목(포트폴리오).
- 질문식 기록 폼(근거 태깅+확신도)은 `features/f3-reason`의 공개 컴포넌트를 import — 직접 구현하지 않는다.
- 종목 상세의 **체류시간·탭 전환 이벤트를 `shared/store` 액션으로 적재** — F8 펫의 관찰 데이터 (기능명세 §6.2).
- 시세: `app/api/quote` 프록시만 사용(키움 API 직접 호출 금지). 개발은 fixtures 시세로.
- 체결 완료: "기록 완료! 통통이가 기억해둘게" + ConfettiBurst. 거래는 `shared/store` 액션으로 기록.
- 완료 기준: 골든 패스 ② — 탐색→상세(체류 이벤트 적재)→민지 매수(질문식 기록 포함) 흐름이 시드+픽스처로 동작 + `npm run build`.
