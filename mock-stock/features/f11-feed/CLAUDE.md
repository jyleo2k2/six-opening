# f11-feed — 가족 거래 피드 (화면 코드)

- 이 디렉터리의 `AGENTS.md`와 `CLAUDE.md`는 한 쌍이다. 둘 중 하나를 수정하면 같은 작업에서 짝 파일도 동일하게 수정하고 완료 전 비교한다.
- 단일 스펙: `../../../web/features/f11-feed/SPEC.md`.
- 이 폴더만 수정한다. 좌표·필터 계산은 `shared/engine`이 소유하며 여기서는 렌더만 한다.
- 타인 카드에 수량·금액을 표시하지 않는다. 부모→자녀 코멘트는 게이트를 통과한 것만 저장한다.
- UI는 `../../../docs/디자인시스템.md` 토큰과 `shared/ui` 컴포넌트만 사용한다.
- 완료: `npm test` + `npm run build`.
