# f3-reason — 질문식 매매 기록 폼 (담당 에이전트 전용)

- 소유: 이 폴더 전부. 밖은 수정 금지. f2가 import하는 폼 컴포넌트를 공개 index로 내보낸다.
- 스펙: `docs/기능명세.md` F3 + `docs/기획서.md` §5.3.
- 매수 폼: ① 근거 칩 5개(뉴스에서 봤어/차트가 좋아 보여/친구·가족이 추천했어/이 회사(제품)를 잘 알아/그냥 느낌이 좋아 — 유형: 뉴스·차트·추천·지식·느낌) ② **확신도 4단계**(ConfidenceSelector — 😕 잘 모르겠어 25/🙂 조금 50/😄 꽤 75/🤩 완전 100, 펫이 묻는 프레이밍 + "정답은 없어!" 캡션) ③ 한 줄 메모(선택).
- 매도 폼: 근거 칩 5개(목표한 만큼 올랐어/더 떨어질까 봐 걱정돼/다른 종목이 더 좋아 보여/그냥 불안해/기타) + 한 줄 메모(선택). 확신도 없음.
- 칩·확신도 필수(각 탭 1회), 메모 선택. 저장은 `shared/store`의 기록 액션 — 확신도 수치(25/50/75/100)와 근거 유형이 F8 트리거·F9 리포트의 입력이 된다.
- 톤: 시험·채점 아님 — 펫이 궁금해하는 가벼운 기록. 점수·정답 표시 금지.
- 완료 기준: 매수(근거+확신도)·매도 폼이 f2 플로우에 삽입돼 기록이 store에 쌓임 + `npm run build`.
