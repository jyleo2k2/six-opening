# f8-pet — AI 투자코치 (담당 에이전트 전용)

- 이 디렉터리의 `AGENTS.md`와 `CLAUDE.md`는 한 쌍이다. 둘 중 하나를 수정하면 같은 작업에서 짝 파일도 동일하게 수정하고 완료 전 비교한다.
- 소유: 이 폴더 전부. 밖은 수정 금지 (라우트 연결·shared 변경은 오케스트레이터).
- 스펙: `docs/기능명세.md` F8 + `docs/기획서.md` v7 결정. `docs/펫서비스기획.md`는 보존 원안이다. 상위 규칙: `web/AGENTS.md`.
- 구성 요소: AI 코치 채팅 화면(감지 선발화·개인 대화 이력) · 홈 상주용 코치 위젯(f0가 import) · LLM 대화 server action.
- **철칙: 선발화 뒤 제한 범위 자연어 대화.** 코치가 먼저 발화한 뒤에만 텍스트 입력을 연다. 음성 입력은 만들지 않는다. 종목 유니버스·자녀 본인 아카이브·서비스/금융 기초 외 질문은 안전 응답으로 전환한다.
- 트리거 판정은 `shared/engine`의 행동 프로파일 함수 결과만 사용 — 이 폴더에서 임계치 로직을 중복 구현하지 않는다. LLM 호출은 임계치 통과 시에만, `shared/llm` client 경유.
- 답변 원칙: 정답·훈계·추천 금지. 매수·매도 시점·가격·수익률 전망을 말하지 않는다. 모든 생성 문구는 `shared/llm/filter`를 통과한다.
- 개인정보: 부모에게 자녀 대화 원문·행동 정보를 전달하는 UI를 만들지 않는다. 판단력 채점 UI도 금지한다.
- 완료 기준: 골든 패스 ③ — 확신도 25 매수 → 코치 선발화 → 종목/아카이브 자연어 질문과 근거 답변 → 금지 질문 안전 응답이 시드+픽스처로 동작 + `npm run build`.
