# 영웅 키움 — 프레임 에셋

다른 페이지/도구에서 화면을 그릴 때 쓰는 폰 프레임 세트입니다.

## 파일

| 파일 | 크기 | 용도 |
|---|---|---|
| `Frame.svg` | 450×920 | 폰 외곽 프레임 (원본) |
| `iphone-frame.png` | 450×920 | 같은 프레임의 PNG 버전 — 프로토타입에서 실제로 쓰는 것 |
| `statusbar.svg` | 402×59 | 상단바 (검정 글자, 밝은 배경용) |
| `statusbar-white.svg` | 402×59 | 상단바 (흰 글자, 어두운 배경용) |
| `parts/Vector*.svg` | — | 상단바를 이루는 원본 조각 (시각·아일랜드·신호·와이파이·배터리) |

## 화면 좌표

프레임 안쪽 화면 영역은 다음 위치입니다. 이 규격을 지키면 프로토타입과 정확히 겹칩니다.

```
프레임 전체   450 × 920
화면 영역     402 × 874
화면 좌상단   left 24px, top 23px
화면 라운드   border-radius 40px
```

상단바는 화면 영역의 맨 위 (0, 0)에 그대로 올립니다 — 402×59.
하단 홈 인디케이터는 화면 하단에서 6px 위, 140×5px, radius 999px, `#1A2233` 85%.

## 레이어 순서

프로토타입에서는 이 순서로 쌓습니다.

1. 화면 콘텐츠 (402×874, radius 40px, overflow hidden)
2. 상단바 SVG (z-index 3, pointer-events none)
3. 홈 인디케이터 (z-index 3)
4. 노이즈 텍스처 (z-index 4, opacity 0.18, mix-blend-mode overlay)
5. 프레임 PNG (z-index 5, pointer-events none)

## 주의

`statusbar-white.svg`의 다이내믹 아일랜드는 흰색이 아니라 검정(`#000000`)입니다.
물리적으로 파인 구멍이라 배경이 어두워도 검정이어야 맞습니다. 흰색으로 바꾸지 마세요.
