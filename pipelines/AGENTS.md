# pipelines — 배치 데이터 파이프라인 세션 하네스

> 적용 범위: `pipelines/` 하위 전체 (`news_digest/` 뉴스 재작성).
> 규칙 본문은 이 파일에만 쓴다. 같은 폴더 `CLAUDE.md`는 `@AGENTS.md` 한 줄이다 (루트 `AGENTS.md` §동기화).
> 최종 갱신: 2026-08-07 — **`close_snapshot/`(전일 종가) 폐기.** 게임이 익명 가상 종목·정적
> 데이터 팩으로 확정되어(기획서 §7.1) 실시세를 쓰지 않는다. 남은 파이프라인은 `news_digest`뿐이다.

## 담당 오너

**김경렬·강소정** (트랙 ③). 산출물은 `content/news`의 검수 대기 초안이다.
게임 뉴스 풀·사건 문구(`game/data`)는 파이프라인 산출물이 아니라 **사람이 쓰고 검수해 커밋하는
편집 데이터**다 — 공급 절차는 `game/AGENTS.md`·`content/AGENTS.md`를 따른다.

## 세션 시작 규칙

1. 루트 `AGENTS.md` → `pipelines/README.md`(디렉터리 정의) → 이 파일 순서로 읽는다.
2. 루트 `C:\dev\six-opening`에서 고치지 않는다. `git_session_manager.py start`로 워크트리를 받아 거기서 작업한다.
3. 산출물 경로(`content/`)를 같은 세션에서 함께 고치지 않는다. claim을 나누고 PR을 분리한다.

## 불변식

- **게임 런타임에 개입하지 않는다.** 게임은 `game/data` 정적 팩만 읽는다 — 파이프라인 장애·레이트리밋·
  응답지연이 대전 중에 영향을 줄 수 있는 경로 자체가 없어야 한다.
- **뉴스 원문을 크롤링·전재하지 않는다.** 이슈를 재작성한 결과물만 내놓는다. 원문 링크와 출처는 남긴다.
- **`news_digest`는 발행하지 않는다.** LLM 재작성 결과는 사람 검수 대기 상태로만 내놓는다.
  검수를 자동화·생략하는 플래그를 추가하지 않는다.
- Python은 **`uv run python`** 으로만 실행한다. 단독 `python` 호출 금지.
- 수집 결과는 요청 파라미터·기준일·출처를 함께 남긴다.
- 시크릿(API 키)은 읽어서 출력·커밋하지 않는다.

## 검증 명령

아직 Python 코드가 없다 (`README.md`만 존재, `pyproject.toml` 미생성).
첫 모듈을 추가하는 세션이 `uv` 프로젝트를 초기화하고 이 절을 실제 명령으로 채운다.

```powershell
uv run python -m news_digest      # 예정
```
