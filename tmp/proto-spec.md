# engine-proto.html 보완 스펙 (이 파일은 임시 — 작업 후 참조 불필요)

`tmp/engine-proto.html`에 아래 두 섹션을 추가하라. 다른 파일 수정 금지, 기존 섹션·스타일 유지.

## 1) 선제 신호 시연 패널 (미니 주문 카드)

매수/매도 탭 + 수량 입력창 + 확신도 4버튼(25/50/75/100)으로 구성된 작은 주문 카드.

- (a) 수량을 45초 내 3회 수정하면 말풍선 **"몇 주 살지 계산해볼까?"** 표시.
  - 수정 카운트 규칙: 입력이 0.7초 멈춘 값을 1회 수정으로 계산 (타이핑 글자수를 수정 횟수로 오인하지 말 것)
- (b) 매수/매도 탭을 30초 내 3회 전환하면 말풍선 **"매수와 매도 차이가 헷갈려?"** 표시.
- 말풍선에는 **[괜찮아]** 버튼 = 해당 신호를 세션 내 뮤트.
- 발화 간 최소 간격 10초(시연용 축소), 세션 최대 2회.

## 2) 이벤트 로그 패널

- 위 패널들의 모든 계산·감지·뮤트 이벤트를 시각(HH:MM:SS)과 함께 목록으로 기록.
- 상단 고정 배지: **"서버 호출: 0회 — 전부 브라우저 안에서 계산됨"**
- 챗봇 답변 자리만 회색 비활성 버튼 **"여기서부터 서버 필요(LLM)"**로 표시.
