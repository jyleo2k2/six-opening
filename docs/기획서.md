# 기획서 — 히스토리 투자 시뮬 (게임명 【미정】)

- 작성: 2026-08-07, 이재용 구두 기획(records/260807-01.m4a) + 세션 확정 Q&A 반영
- 이전 기획(1:1 PvP 카드게임)은 폐기됐다. 이 문서가 게임 룰의 유일한 근거다.
- 표기: 【미정】 = 밸런스 시뮬레이션·사료 검증·후속 결정 대상

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 2~8인 실시간 멀티 투자 시뮬레이션 (과거 실제 사건 배경) |
| 플랫폼 | 웹 (확정) |
| 인원 | 2~8명, 초대코드 방 |
| 플레이 타임 | 5턴 × (준비 90초 + 채팅 60초 + 이벤트 연출 ~20초) ≈ 15분 |
| 배경 | 과거 실제 10년. 1차 구현은 **2011~2020** — 다른 연대(2001~2010 등)는 데이터 팩 추가로 확장 |

### 1.1 목표 (교육이 아니라 매력)

주식 공부를 시키는 게임이 아니다. 순서대로:

1. **허들 낮추기** — 계좌·호가·차트 없이, 뉴스 읽고 사고파는 것부터
2. **친밀함** — 친구들과 찌라시 흘리고 웃고 우는 경험이 곧 시장 경험
3. **"해보고 싶다"** — 과거 사건 속에서 돈이 불어나는 짜릿함을 직접 느끼게

교육 효과(사건과 주가의 인과, 정보의 값어치, 분산의 이유)는 목표가 아니라 부산물로 얻는다.

### 1.2 핵심 재미 루프

> 뉴스 조각을 읽는다 → 정보를 살까, 감으로 갈까 → 채팅에서 친구 말을 믿을까, 속일까 →
> 이벤트가 터진다 → 순위가 뒤집힌다 → 이모티콘으로 웃고 운다 → 다음 턴엔 내가 1등

승부는 "누가 정보를 잘 모으고, 잘 속고 안 속았나"로 갈린다. 상대 자산을 직접 공격하는 수단은 없지만,
**채팅으로 속이는 것은 공식 룰이다** (이전 기획의 비공격 원칙은 폐기).

## 2. 게임 구조

### 2.1 시작 조건 (확정)

- 각자 현금 **1,000,000원**. 보유 종목 없음
- 종목 시세판은 전원에게 동일하게 공개
- 게임 시작 시 이번 판의 **이벤트 5개가 시드로 확정**된다(비공개, §5.1)

### 2.2 턴 구조 (확정)

**1턴 = 1년** 컨셉. 한 턴은 세 페이즈로 구성되고 전원 동시 진행한다. 총 **5턴** 후 정산.

| 페이즈 | 시간 | 하는 일 |
|---|---|---|
| ① 준비 | 90초 | 개인 뉴스 수신 → 매수/매도/정보소 |
| ② 채팅 | 60초 | 자유 채팅 — 찌라시·자랑·추천·연막 |
| ③ 이벤트 | 연출 ~20초 | 사건 발생 → 주가 변동 → 전체 순위 연출 |

- 페이즈 전환은 서버 타이머가 권위를 갖는다. 전원이 준비 완료를 누르면 조기 전환
- 시간 수치는 초안 【미정: 플레이테스트로 조정】

## 3. 준비 페이즈

### 3.1 개인 뉴스 (무료)

준비 페이즈 시작 시 **플레이어마다 서로 다른 뉴스 1개**가 배달된다.

- 뉴스는 전부 **사실**이고, **주가 얘기는 하지 않는다** (확정)
- 두 종류가 섞여 있다 — 받은 사람은 어느 쪽인지 모른다:
  - **단서 뉴스**: 이번 턴 이벤트의 전조 (예: 코로나 턴 → "먼 나라에서 원인 모를 폐렴 환자가 늘고 있대")
  - **배경 뉴스**: 그 시대의 사실이지만 이벤트와 무관 (예: "프로야구 관중이 역대 최다래")
- 같은 턴 안에서 두 플레이어가 같은 뉴스를 받지 않는다
- 내 뉴스는 나만 본다. 공유는 채팅으로 — 그대로 옮겨도 되고, 꾸며내도 된다

### 3.2 매매 (확정)

| 규칙 | 내용 |
|---|---|
| 방식 | 시장가 즉시 체결, 수수료·세금 없음 |
| 단위 | 정수 주. 잔여 현금 한도 내 무제한 횟수 |
| 금지 | 공매도·대출·미수 없음. 현금과 보유 주식이 전부 |
| 가격 | **이벤트만 가격을 움직인다** (확정). 준비·채팅 중 시세 변동 없음 |

### 3.3 정보소 (확정 컨셉)

돈을 내면 **이번 턴 이벤트에 대한 예보**를 판다. 싸면 찌라시, 비싸면 고급 정보.

| 티어 | 가격 | 적중률 | 컨셉 |
|---|---|---|---|
| 찌라시 | 30,000원 | 40% | 시장에 도는 소문 |
| 소식통 | 80,000원 | 70% | 업계 관계자 귀띔 |
| 고급 정보 | 150,000원 | 95% | 확실한 소식통 |

- 내용물: **사건명 + 수혜 섹터 1 + 피해 섹터 1**
- 빗나가면 **다른 사건의 예보**가 온다(이번 판에서 아직 안 터진 사건 중 무작위) — 진짜와 구별 불가
- 턴당 1회, 준비 페이즈에만 구매 가능
- **구매 사실(누가 몇 원짜리를 샀는지)은 전원 공개, 내용은 본인만** — "쟤 30만원 질렀다"가 채팅 소재가 된다
- 가격·적중률 수치는 초안 【미정: 시뮬레이션으로 정보의 기대가치 검증】
  (5/15/30만원 첫 안은 sim 3000판에서 "정보 사면 손해"로 판명 — 정보를 사는 플레이가 이겨야
  코어 루프가 성립해서 인하. 근거 수치는 `game/AGENTS.md` 밸런스 규칙대로 PR에 첨부)

## 4. 채팅 페이즈 (확정)

- **자유 텍스트 채팅** (닉네임, 200자 제한). 찌라시 프리셋 카드도 제공 【미정: 프리셋 문구】
- 거짓말 허용이 룰이다: 가짜 찌라시, 매매 자랑(진위 무관), 종목 추천, 연막 전부 가능
- **이모티콘 5종은 모든 페이즈에서 상시 사용 가능** (확정): 웃음 · 울음 · 절망 · 따봉 · 야르(신남)
- 채팅 중 매매·정보 구매 불가 (준비 페이즈 전용)
- 유해어 필터 등 안전장치는 후속 【미정 T: 금칙어 필터】

## 5. 이벤트 페이즈

### 5.1 사건 추첨 (확정)

- 연대 풀(2011~2020, §7)에서 게임 시작 시 **5개를 비복원 추첨**해 턴 순서대로 배정
- **역사 순서와 무관하게 섞인다** (확정 — 코로나 다음에 동일본 대지진이 올 수 있다)
- 추첨 결과는 서버만 안다. 클라이언트에는 절대 내려보내지 않는다 (§9 정보 비대칭 무결성)

### 5.2 주가 반영 (확정 컨셉)

- **등락 방향은 역사 그대로, 등락폭은 게임마다 다르게** (확정)
- 사건마다 섹터별 효과 범위 `[min%, max%]`가 정의된다 (부호 동일 = 방향 고정)
- 발동 시 **종목마다** 범위 내 수치를 개별 추첨 → 같은 섹터라도 조금씩 다르게 움직인다
- 가격은 원 단위 반올림, 바닥 100원

### 5.3 연출 (확정)

1. 사건 배너 — 사건명 + 실제 역사 한 줄 설명
2. 보유 종목들의 주가 변동이 시각적으로 표현됨 (등락 애니메이션)
3. **총자산 순위 변동 장면이 화면 꽉 차게** — 순위가 뒤집히는 순간이 게임의 하이라이트
4. 이모티콘 난사 구간

## 6. 승리·기록

- 5턴 종료 시 **총자산(현금 + 보유 종목 평가액) 최다**가 우승 (확정). 동점은 공동 순위
- 종료 화면: 자산 순 대시보드 + 턴별 자산 그래프
- **명예의 전당** (확정 — 리텐션 장치): 최종 자산 기록, 방 단위 + 전체 랭킹. 저장은 Supabase 【미정 T: 테이블 설계】
- 보너스 점수·소기능(예: 최다 역전, 찌라시 적중왕)은 별도 추가 예정 【미정 — 기획 예고만】

## 7. 데이터 — 종목·섹터·이벤트 (2011~2020 팩)

### 7.1 종목 — 익명 회사 (확정)

**실명 기업을 쓰지 않는다.** 섹터를 대표하는 가상 회사로 만든다 — 데이터 라이선스·초상권 문제가
사라지고, 가격 스케일을 게임에 맞게 잡을 수 있다(시드 100만원으로 최저가 종목 ~200주, 최고가 ~10주).

- 8섹터 × 2종목 = **16종목**, 시작가 5,000~100,000원
- 회사명은 아이도 어른도 웃을 수 있는 순한 가명 (예: 한빛반도체, 구름항공). 실존 상표 연상 금지
- 종목별 한 줄 소개 (뭘 하는 회사인지) — 섹터 이해가 곧 게임 실력이 되게

## 8. 톤 & 콘텐츠 정책

- **실제 재난·사건을 다룬다**: 사건 배너에 반드시 실제 역사 한 줄 설명을 붙여 "그때를 겪어보기" 프레임을
  유지한다. 재난 자체를 희화화하는 카피 금지 (웃음은 플레이어들 사이에서 나오게)
- 앱이 실존 종목을 추천하는 문구 금지 (기존 정책 유지 — 게임 속 회사는 전부 가상)
- **사람 검수 대상은 편집 텍스트다** (`content/`·`game/data`의 뉴스·사건 문구). **실시간 유저 채팅은
  검수 대상이 아니다** — 대신 닉네임만 노출, 200자 제한, 금칙어 필터 【미정 T】
- 수익 보장·확정 수익류 표현 금지는 앱 전체 공통 (기존 유지)

## 9. 정보 비대칭 무결성 (엔진 불변식)

이 게임의 상품은 정보 격차다. 새는 순간 게임이 죽는다.

1. 이벤트 큐(이번 판 5개 사건)는 서버만 안다
2. 내 뉴스·내 정보소 구매 **내용**은 나만 받는다
3. 정보소 구매 **사실**(누가·몇 원)은 전원 공개
4. **타인의 현금·보유 내역은 비공개.** 공개되는 건 총자산(순위)뿐 — "뭘 들고 있는지"는 채팅으로 떠보는 것
5. 클라이언트로 나가는 상태는 항상 플레이어별 필터(`viewFor`)를 거친다

## 10. UI 최소 요구

- 시세판(16종목, 섹터 그룹핑) + 내 포트폴리오(현금·보유·평단) + 총자산 순위(상시)
- 뉴스 카드(내 것만) · 정보소(3티어 구매 버튼 + 구매 공개 피드)
- 채팅창 + 이모티콘 바(5종, 상시) + 찌라시 프리셋
- 이벤트 연출: 사건 배너 → 등락 → **풀스크린 순위 변동** → 다음 턴
- 종료: 자산 순 대시보드 + 명예의 전당

## 11. 잔여 미정

1. 게임명
2. 밸런스 수치 — 이벤트 폭 범위·정보소 가격/적중률·페이즈 시간 (시뮬 + 플레이테스트)
3. 이벤트 방향표 사료 검증 (트랙 ③ — 특히 #1 반도체, #11 방향)
4. 찌라시 프리셋 문구 · 뉴스 풀 확장 (트랙 ③)
5. 명예의 전당 테이블 설계 · 금칙어 필터 · 보너스 점수/소기능
6. 다른 연대 데이터 팩 (2001~2010 등)
