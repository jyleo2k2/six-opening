## 2. 게임 구조

### 2.1 시작
- 전원 현금 **1,000,000원**, 보유 없음. 시세판(16종목/8섹터) 전원 동일 공개
- 이번 판 사건들은 시작 시 시드로 비복원 추첨(라운드당 1개), **서버만 안다**
- 입장 연출: 매칭 → 타임머신 출발(2026 → 과거 연도 롤링)

### 2.2 라운드 = ①준비 → ②작전 회의 → ③사건 → ④순위

| 페이즈 | 시간 | 내용 |
|---|---|---|
| ① 준비 | R1 60초, 이후 45초 | 내 뉴스 수신(모달) → 매수/매도 → 정보소 |
| ② 작전 회의 | 25초 | 템플릿 채팅 — 참말·거짓말·연막 |
| ③ 사건 | 연출 ~13초 | 속보 → 사건 카드 → 섹터 게이지 → 내 손익 |
| ④ 순위 | 14초 | 전체 순위 + 등락 화살표 + 이모지 파티 |

- 서버 타이머가 권위. **전원 준비 완료 시 조기 전환** (사람 기준 — 봇은 진행을 막지 않는다)
- 시간 수치 초안 【미정: 플레이테스트】

## 3. 준비 페이즈

### 3.1 내 뉴스 (무료, 라운드마다)
- 라운드 시작 시 전원에게 뉴스 1개 — **딱 2명만 이번 사건의 진짜 전조**, 나머지는 그 시대 배경 노이즈(사건 섹터 제외)
- 전부 사실 문장이고 주가 얘기 없음. 뉴스 카드에 관련 섹터 배지 표시
- 카피: "플레이어마다 다른 뉴스 — **절반만 진짜 전조.** 이 뉴스가 진짜인지는 아무도 모릅니다"
- 내 뉴스는 나만 본다. 회의에서 "내 뉴스 공유" 버튼으로 원문 공개 가능(진위 표시 없이)

### 3.2 매매
- **금액 기반**: 만원 단위 슬라이더(최소 1만원) + 프리셋(10/20/50만/전액) → 소수점 주식
- 시장가 즉시 체결, 수수료 없음. 공매도·대출 없음. 사건만 가격을 움직인다
- 잔여 평가 100원 미만 보유는 자동 정리
- "안 사는 것도 전략 — 무행동 페널티는 없어요"

### 3.3 정보소 — 게임당 2회 (확정)
- **꼴찌(총자산 최하위)는 50% 할인** — 역전 장치
- 탭 2개 × 티어 3개. 구매 사실(누가·티어)은 공개, **내용은 본인만**

| | 🥉 10,000원 | 🥈 30,000원 | 🥇 80,000원 |
|---|---|---|---|
| 📊 해설 (사건 예보) | 찌라시 — 섹터 하나 (정확도 ~50%) | 리포트 — 핵심 섹터+방향 (~75%) | 보고서 — 전 섹터 근사 수치 (~95%) |
| 🔭 정찰 (남의 패) | 익명 소문 — "누가 ○○ 만졌다더라" (거짓 가능) | 1인 정찰 — 한 명의 실제 보유 | 전체 정찰 — 전원 보유 요약 |

- 빗나간 해설은 미끼 정보(형태 동일, 진위 구별 불가). "싼 정보는 대개 틀리고, 비싼 정보도 100%는 아닙니다"
- 프로토 초안 가격(1/5/20만)은 sim에서 순손해로 판명 → 1/4/10만으로 인하 (정보를 사는 플레이가
  성립해야 한다). 가격·정확도는 계속 시뮬 튜닝 대상 【미정】

## 4. 작전 회의 — 템플릿 채팅 (확정)

- 발화는 **3단 조합만**: `[나는|얘들아|<닉네임>] × [섹터 8] × [샀어|살 거야|팔았어|사지 마|조심해|믿지 마]`
  + 📰 내 뉴스 공유 + 퀵 이모지(😂🔥). 이모티콘 5종(😂😭😱👍🔥)은 모든 페이즈 상시
- 자유 텍스트 없음 → 유해어 필터 불필요, 아동 안전 원천 확보
- **거짓말 추적**: "[나는][X][샀어]"인데 실제 미보유면 거짓말로 기록 → 그 거짓말에 안 넘어간 플레이어들의
  **"안 속은 횟수"** 적립 (진실의 눈 상·리포트 지표). 거짓말은 벌칙이 아니라 공식 전술이다
- 서버가 조합을 검증한다 — 템플릿 밖 문자열은 거부

## 5. 사건 페이즈

- 라운드당 실제 사건 1개 발동, 역사 순서 무관 (2011~2020 팩: 12종 §8)
- **등락 = 실제 관찰 등락률(imp) × 변동 밴드 0.7~1.3** (종목별 개별 추첨) — 방향은 역사 그대로
- 무영향 섹터도 **±2% 시장 노이즈** — 시장은 늘 흔들린다
- 연출: ⚠속보(사이렌) → 사건 카드("✓ 실제로 있었던 일이에요" + 관찰 구간 N거래일) → 8섹터 좌우 게이지(내 보유 표시) → 내 손익·총자산
- 사건 카드의 역사 설명은 병기 필수, 재난 희화화 금지

## 6. 순위·종료·귀환

- ④ 순위: 총자산 순 + 직전 대비 ▲▼ + 이모지 플로팅. 동점 공동 순위
- 최종 라운드 후 **시상식**: 🏆 수익왕(자산 1위) · 🔍 진실의 눈(안 속은 횟수 1위) · 🛡️ 든든이(최대 낙폭 MDD 최소 — "잃지 않는 것도 이기는 것")
- **내 리포트**: 최종 순위 · 수익률 · 안 속은 횟수 · 최대 낙폭 · 이번 판 사건 복기("왜 떨어졌는지 보기") · 도감 해금(+거래 기업 · +겪은 사건)
- **타임머신 귀환** 연출(과거→2026) → ☀️ 라이트 테마 랜딩: "네가 없는 동안 오늘의 시장은" —
  오늘 날짜 + KOSPI + **게임에서 만난 회사들의 현재가**(시연은 mock) → [🌙 로비로] [⚡ 한 판 더]
  — 게임→현실 계좌·제안서로 이어지는 다리다
- 명예의 전당(T6)은 별도 유지
