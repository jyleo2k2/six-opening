# 키즈:키움 PvP 카드게임 — 기획서 v0.3 (룰 확정판)

- 원본: 마스터룰 Vol.0 개정판 + 결정사항 Q1~Q20 (2026-08-06)
- 표기: 【미정】 = §11 잔여 항목 (대부분 카드 풀 확정·엔진 시뮬레이션 후 결정)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 1:1 턴제 PvP 카드게임 (디지털) |
| 플랫폼 | **웹 (확정)** |
| 타겟 | 초등 고학년 ~ 중학생 |
| 플레이 타임 | 5라운드(10턴), 턴 제한 1분 → 약 10~15분 |

### 1.1 교육 목표
1. 기초 개념: 용어, 시장가, 매수, 매도, 환율, 기업 섹터
2. 심화 개념: 거시경제 상황이 섹터별 기업에 미치는 상이한 영향, 그 위에서 발생하는 시장 이벤트의 효과

### 1.2 핵심 재미 루프
다음 라운드의 경제환경(호재/악재)을 예측해 섹터를 갈아타고, 스킬카드로 내 보유 섹터에 호재를 터뜨리고, 회피카드(손절 예약)로 악재 손실을 제한하고, 싸게 사서 비싸게 판다.

> **비공격 원칙 (확정, Q1)**: 상대를 직접 공격·사보타지하는 카드는 없다. 스킬카드는 호재 뉴스 중심이고, 하락은 경제환경 또는 뉴스의 현실적 반대급부(예: 종전협상 → 방산 하락)로만 발생한다. 승부는 "누가 시장을 더 잘 읽고 대응했나"로 갈린다.

### 1.3 게임 용어 ↔ 실제 증권 개념
| 게임 용어 | 실제 개념 |
|---|---|
| 매수 (패→필드) | 시장가 매수 |
| 매도 (필드→덱) | 시장가 매도 |
| 평가금액 | 보유 종목의 현재 가치 |
| 매수가격 (스택 시) | 평균 매수 단가 · 물타기/불타기 |
| 영역 전개 | 거시경제 환경 변화 |
| 스킬카드 | 시장 이벤트 (호재 뉴스) |
| 회피카드 | 조건부 예약매매 · 손절(스탑로스) · 헷지 |

## 2. 승리 조건

5라운드(각 플레이어 5턴, 총 10턴) 종료 시 총자산이 높은 플레이어가 승리. **동점 시 무승부 (확정)**.

> 총자산(원) = 원화 현금 + 달러 현금 × 현재 환율 + Σ 한국주식 평가금액 + Σ 미국주식 평가금액 × 현재 환율

## 3. 시작 조건

- 시작 자금: 각자 원화 1,000,000원 + 달러 $1,000
- 기준환율 1,450원/$ 에서 시작 — 화면 우측 상단 상시 표시 (변동제 §9)
- 각자 30장 덱 지참 (§5)
- 선공/후공 랜덤
- **게임 시작 시 경제환경 1회 발동 (확정)** → 시작가에 즉시 반영 후 1라운드 시작
- 각자 패가 5종류가 되도록 덱에서 드로우

## 4. 카드 시스템

### 4.1 종목카드
실제 상장기업 카드. KOSPI / NASDAQ / NYSE 우량주 중 게임 목적에 맞게 선정 (카드 풀 확정은 다음 단계 【미정】).

카드 구성 요소:
1. 명칭 · 종목코드 · 본국
2. 일러스트 — 로고 중심, 뭘 하는 회사인지 아이가 바로 이해할 수 있게 (피그마 참조)
3. 섹터 (7종 중 1개)
4. 효과 & 기업특징 — 아이 눈높이 설명 + 대표 키워드 3개
5. 가격 — 한국기업 원화 / 미국기업 달러 표시. 게임 시작 시점의 전일 종가를 API로 로드

**섹터 7종**: 반도체 · 에너지 · 자동차 · 소비재/음식 · 방산/우주 · 조선/해양 · 은행/금융

> **섹터 지정 원칙**: 경제환경·스킬·회피의 가격 효과는 항상 **섹터 단위**로 지정한다. 종목 고유 명칭 지정 금지.
> 예: "반도체 섹터 전 종목 -10%" (O) / "삼성전자·마이크론·웨스턴디지털 -10%" (X)

### 4.2 스킬카드 — 시장 이벤트

- 발동 코스트 없음. 자신의 턴에 발동, **턴당 1장**
- **"미리 발동" 의미 (확정, Q13)**: 세트/지연 발동이 아니다. 자기 턴 안에서 종목카드를 내기(매수) 전에 먼저 발동할 수 있다는 뜻이며, **발동 즉시 효과가 적용**된다. 턴 내 행동 순서는 자유 (호재 발동 → 같은 턴에 매도하는 "뉴스에 팔기" 가능)
- **비공격 원칙 (확정)**: 카드는 항상 '시장 뉴스' 프레임. 특정 섹터 하락만이 목적인 공격성 카드는 만들지 않는다. 단, 현실 반영을 위한 반대급부 하락은 허용 (예: 종전협상 진전 → 방산 하락)
- **대상 섹터는 카드에 인쇄 (확정, Q14)** — 예: "반도체 깜짝 실적!" → 덱 빌딩 전략과 연결
- **효과 수치는 발동 시 범위 내 랜덤 (확정, Q14)** — 변수를 키워 게임마다 다른 전개. 운 보정 시스템 적용(아래)
- 효과는 섹터 단위 → 양 플레이어 필드에 공통 적용. 전략은 "나만 보유한 섹터"에 호재 터뜨리기
- 종류 (수치 범위는 밸런스 초안 【미정: 시뮬레이션 조정】):

| 카드 (가칭) | 효과 (발동 시 랜덤) | 교육 포인트 |
|---|---|---|
| 깜짝 실적 발표! | 인쇄된 섹터 +10~20% (원문 d.가) | 실적과 주가 |
| 신제품이 대박났어요! | 인쇄된 섹터 +5~15% | 혁신과 기업가치 |
| 수주 잭팟! | 인쇄된 섹터 +10~20% | 수주 산업(조선·방산)의 구조 |
| 금리를 내린대요! | 모든 섹터 +3~7% | 금리와 주가의 관계 |
| 환율이 출렁여요! | 기준환율 ±50~150원 (달러 강세/원화 강세 2종) | 환율과 자산 배분 |
| 전쟁이 끝날 것 같아요! | 방산/우주 -5~-15%, 소비재/음식 +5% (원문 개요의 '종전협상 진전') | 같은 뉴스에도 웃는 섹터, 우는 섹터 |

#### 운 보정 시스템 (확정 컨셉, Q14)
연속 불운을 완화한다. 랜덤 수치 판정에서 손해를 본 플레이어는 다음 판정에서 덜 손해 보도록 확률을 조정한다.

- 스케치: 플레이어별 운 점수 L 누적 — 판정마다 (실제값 − 범위 중앙값)을 발동자 기준 유불리로 환산해 더한다. L이 음수(누적 불운)면 다음 랜덤 판정을 유리한 쪽으로 가중 샘플링. 행운 페널티(반대 방향 보정)는 없음
- 가중 함수·이력 감쇠 등 세부는 엔진 단계에서 시뮬레이션으로 확정 【미정】

### 4.3 회피카드 — 손절 예약 (확정, Q2·Q15)

- 발동 코스트 없음
- 컨셉: **조건부 예약매매(스탑로스)**. 하락을 무효화하는 게 아니라 **하락폭에 상한**을 건다
- 룰 (확정):
  1. 자신의 턴에 자기 필드 **종목 존 1개**에 **뒷면(비공개)으로 세트**. 세트는 턴당 1장 (기본값)
  2. 이후 해당 종목에 하락 효과 발생 시 자동 발동 → 하락률을 **-5%로 제한 (고정)** (예: 금융위기로 -20% 맞을 것을 -5%만 하락)
  3. 1회용. 발동 후 덱으로 복귀
  4. 세트된 존의 종목을 매도하면 회피카드도 덱으로 복귀

## 5. 덱 & 패

- 덱: 정확히 30장, **종목+스킬+회피 전부 포함 (확정, Q3)**. 동일 종류 최대 5장
- **비율 (확정, Q19): 종목 18 / 스킬 8 / 회피 4**
  - 근거: 자기 턴은 5번 → 스킬 발동 최대 5회(턴당 1장), 8장이면 상황별 선택지 확보. 회피는 보험 성격이라 소수. 종목 18장이면 4~6종목 구성으로 3존 스택 매수 + 교체 여력. 시뮬레이션으로 미세조정 가능
- 패 유지: 패는 항상 **5종류** (장수 기준 아님, 전 카드 유형 포함). 5종류 미만이 되면 5종류까지 덱에서 랜덤 드로우. 드로우 중 이미 가진 종류가 나오면 그대로 패에 추가. 덱에 새 종류가 없으면 중단
- 매도·사용된 카드는 자기 덱으로 복귀 (묘지 없음 — 단순화) → 재드로우/재매수 가능
- **패↔덱 종류 교체 (확정, Q7)**: **자신의 턴에만, 턴당 1회**. 종류 단위 1:1 전량 맞교환

## 6. 필드

- 종목카드 존 3개 = 최대 3종류 보유
- 같은 종목 여러 장은 한 존에 스택
- 존 표시 정보: 매수가격 (**스택 시 평균단가, 확정 Q11**) / 평가금액
- 존당 회피카드 세트 슬롯 1개 (확정, Q15)

## 7. 진행 규칙

### 7.1 라운드 구조 (확정, Q8)
내 턴 → 상대 턴 = 1라운드. 총 5라운드(10턴) 후 종료·정산.
**턴 제한시간 1분 (확정, Q20)** — 초과 시 턴 자동 종료.
(원문 a.의 "한 라운드는 각 플레이어가 5개 턴씩"은 '한 게임은'의 오기로 확정)

### 7.2 자신의 턴에 가능한 행동 (순서 자유)

| 행동 | 규칙 | 횟수 |
|---|---|---|
| 환전 | 현재 환율로 원↔달러, 수수료 없음 | 무제한 |
| 매수 | 패의 종목카드를 현재가격 지불하고 필드로. 3종류 한도 내 | 무제한 |
| 매도 | 필드 종목카드를 평가금액에 판다. 임의 장수, 카드는 덱으로 | 무제한 |
| 종류 교체 | 패↔덱 (§5) | **턴당 1회 (확정)** |
| 스킬카드 발동 | §4.2 — 즉시 효과, 매수 전 '미리 발동' 가능 | 턴당 1장 |
| 회피카드 세트 | §4.3 — 뒷면 비공개 | 턴당 1장 |
| 턴 종료 | — | — |

상대 턴에는 매수/매도/환전 불가. 세트된 회피카드의 자동 발동만 일어난다.

### 7.3 영역 전개 — 경제환경

- **라운드제 (확정, Q6)**
- 발동 시점 (확정, Q4): **게임 시작 시 1회 + 1~4라운드 종료 시 각 1회 = 총 5회**. 5라운드 종료(정산 직전)에는 발동하지 않는다
- 발동 시 안내 문구: **"영역 전개: 새로운 경제환경이 시장 전역에 발동됩니다."**
- **랜덤 방식 (확정, Q17)**: 7종 균등 추첨, 직전 환경은 제외. (호재 4 : 악재 3 — 약간 호재 우세는 의도: 아이들이 자산 우상향을 경험)
- 환경 풀 — 아이 눈높이 7종. **실제 역사 사례는 각 환경 카드의 설명(플레이버)으로 활용 (확정, Q16)**:

| 구분 | 환경 | 실제 사례 (교육 콘텐츠) |
|---|---|---|
| 악재 | 기름값이 올랐어요! | 1970년대 석유파동 |
| 악재 | 금융위기 | 1990년대 일본 버블 붕괴 · 1997 한국 외환위기 · 2000 닷컴버블 · 2008 글로벌 금융위기 |
| 악재 | 전쟁 | 2022 러우전쟁 · 2026 미국-이란 전쟁 |
| 호재 | 인터넷의 보급과 IT혁명 | 1990년대 중후반 IT혁명 |
| 호재 | 스마트폰 혁명 | 2010년대 모바일 시대 |
| 호재 | 생성형 AI개발 | 2025 AI반도체 투자열풍 |
| 호재 | 경기호황 | 2001 중국 WTO 가입 · 2008 글로벌 QE · 2010년대 셰일가스 혁신 · 2023 글로벌 경기확장 |

- 효과: 발동 즉시 가격·환율에 반영. 환경은 다음 영역 전개까지 유지

## 8. 환경×섹터 영향 매트릭스 (확정, Q18 — 1차 검수 완료)

반도체는 **하이리스크 하이리턴** 컨셉 — 상승도 크고 악재 하락도 가장 크다 (Q18 반영: 악재 -15/-20/-15).
시뮬레이션에서 미세조정 가능.

| 환경 | 반도체 | 에너지 | 자동차 | 소비재/음식 | 방산/우주 | 조선/해양 | 은행/금융 | 환율 |
|---|---|---|---|---|---|---|---|---|
| 기름값이 올랐어요! | **-15%** | **+15%** | **-10%** | -5% | +5% | +10% | -5% | +100원 |
| 금융위기 | **-20%** | -10% | -10% | -5% | -5% | -10% | **-20%** | **+350원** |
| 전쟁 | **-15%** | +10% | -5% | -5% | **+20%** | +10% | -10% | +150원 |
| 인터넷 보급과 IT혁명 | **+15%** | 0 | 0 | +5% | 0 | 0 | +5% | -50원 |
| 스마트폰 혁명 | +10% | 0 | 0 | **+10%** | 0 | 0 | +5% | -50원 |
| 생성형 AI개발 | **+20%** | **+10%** | 0 | 0 | 0 | 0 | 0 | -50원 |
| 경기호황 | +5% | +5% | +10% | +10% | 0 | +10% | +10% | **-100원** |

교육 포인트:
- **반도체** → 하이리스크 하이리턴: 호재에 가장 크게 오르고 악재에 가장 크게 빠진다
- **금융위기** → 은행 직격 + 원화 약세(달러 보유자가 유리). 소비재는 덜 빠진다(경기방어주 개념)
- **전쟁** → 방산 급등, 에너지·조선(LNG선 수주) 수혜 — "나쁜 뉴스에도 오르는 섹터가 있다"
- **생성형 AI** → 반도체뿐 아니라 에너지(데이터센터 전력)도 수혜
- **기름값 급등** → 자동차 타격, 에너지·조선(유조선·해양플랜트) 수혜

## 9. 가격·환율 시스템

- 시작가: 게임 시작 시점 기준 전날 종가 (실시세 API, 소스 【미정】) × 시작 환경 효과
- 가격 변동: 모든 효과는 %로 적용. 현재가 = 시작가 × ∏(1 + 효과ᵢ)
- **환율 변동제 (확정, Q9)**: 1,450원/$에서 시작, 경제환경 발동 시 매트릭스의 환율 변동을 적용. 환전·정산 모두 **현재 환율** 기준. (외환위기 때 달러 들고 있으면 이득 — 환율 교육의 핵심)
- 스킬카드(환율이 출렁여요!)로도 환율 변동 가능
- 반올림: 원화는 원 단위, 달러는 센트 단위

## 10. UI 최소 요구 (피그마 연동 전 메모)

- 우측 상단: 현재 환율 (변동 시 연출)
- 플레이어별: 종목카드 존 3개 (평균단가/평가금액 + 회피 세트 표시), 패, 덱
