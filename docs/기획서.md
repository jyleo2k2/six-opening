## 1. 정의

> **부모와 자녀가 각자 모의투자를 하고, 가족이 함께 키우는 AI펫이 두 사람의 투자 생각을 이어주는 가족형 모의투자 리그.**

### 서비스 핵심 문장

> **"평일에는 각자 투자하고, 우리 가족의 투자 생각은 함께 키우는 AI펫이 이어준다."**

### 가장 중요한 차별점

> 가족이 같이 주문하는 서비스가 아니라, **각자 투자한 뒤 AI가 서로의 생각을 연결해주는 서비스.**
> 기존 가족/어린이 모의투자와의 차별점은 수익률 경쟁이 아니라 **투자 판단 과정 + 가족 관계 + AI 분석**에 있다.
> 그리고 그 연결의 매개가 챗봇이 아니라 **이 가족의 데이터로만 존재하고 성장하는 펫**이라는 점 — 범용 GPT로 대체할 수 없는 이유(§6.1).

### 핵심 AI Loop

```
각자 투자 (질문식 매매: 근거 태깅+확신도)
→ 펫이 행동 관찰 (규칙 엔진 상시)
→ 판단이 흔들리는 순간 감지 → 펫 리액션·되물음 (메타인지)
→ 부모에게 '오늘의 순간' 번역 전달 (일 1회)
→ 주간 질문 생성 → 부모·자녀 각자 답 → 동시 공개
→ 펫 성장 (소통할수록 큰다) → (반복) → 시즌 아카이브 가족 성장기록
```

## 3. 문제 정의

### 발견한 문제
- 아이들은 경제·투자를 직접 경험하며 배울 기회가 부족하다.
- **부모도 주식을 잘 안다는 보장이 없어** 자녀에게 직접 투자교육을 해주기 어렵다.
- 기존 모의투자는 개인 수익률 경쟁 중심이라 가족 간 대화 요소가 약하다.
- 증권사는 부모 고객뿐 아니라 자녀를 미래 고객으로 연결할 장기 접점이 필요하다.

### 핵심 문제 재정의

> **"부모가 투자 전문가가 아니어도, 아이가 스스로 투자해보고 AI의 도움을 받아 배우면서 부모와 자연스럽게 투자 이야기를 나눌 수 없을까?"**

역할 구조가 해법의 뼈대: **부모 = 선생님이 아니라 같이 참여하는 투자 파트너, 관찰·연결 = AI펫.** 부모에게 가르칠 부담을 지우지 않고, 대화의 소재와 타이밍은 펫이 대신 마련한다(§6.4) — '부모 참여 지속성' 리스크의 1차 대응이기도 하다(§11).

## 5. 서비스 구조

### 5.0 사용자

| 역할 | 정의 |
|---|---|
| 부모 | 키움증권 계좌 보유자. 자녀와 같은 가족팀으로 참가, **본인도 별도 모의투자 진행**. 펫이 전하는 '오늘의 순간'과 주간 질문으로 아이의 생각을 확인. 참가 혜택: **로보마켓 프리미엄 체험권** |
| 자녀 | 초등 고학년~중학생. **부모 승인 없이 자유롭게 모의투자.** 주문 때마다 근거·확신도를 간단히 기록(질문식 매매). 판단이 흔들리는 순간엔 펫이 먼저 말을 건다 |

### 5.1 전체 User Flow

```
[개설] 부모 리그 개설 → 자녀 초대(법정대리인 동의) → 프리셋 선택 → 가상금 지급
       → 부모·자녀가 함께 펫 이름 짓기 (첫 공동 행위)
[평일] 홈(펫 상주) → 종목 탐색 → 상세 → 질문식 매매(근거 태깅+확신도)
       → 펫이 행동 관찰, 흔들리는 순간 감지 시 리액션·되물음
       → 감지된 순간이 부모 화면 '오늘의 순간'으로 번역 전달 (일 1회)
[주말] 펫이 주간 질문 제시 → 부모·자녀 각자 답변 → 둘 다 답하면 동시 공개
       → 펫 성장(컨디션·레벨) 반영
[시즌 종료] 아카이브 가족 성장기록 (판단 변화 + 펫 성장 비포/애프터) + 리워드
```

- 진입: 부모가 영웅문S#에서 가족리그 개설 → 자녀 초대 (미성년: 법정대리인 동의 **[사실 — 개인정보보호법 22조의2]**) → 시즌 프리셋 선택 → 전원 동일 가상금 지급 → **펫 작명(공동)**.
- 첫 진입 시 튜토리얼 코치마크로 기본 화면(홈 구성·펫·매매 진입)을 안내한다.

### 5.2 시즌 설계

- **8주 시즌, 분기마다 개최** / 부모 1+ 자녀 1+ / 전원 동일 가상금(예: 1,000만) / **국내 기업 주식 50종목**
- 제외: ETF·ETN, 선물·옵션, 신용·미수, 공매도, 가상자산, 초저유동성. 해외주식은 제공하지 않는다.
- 프리셋(부모가 세부 설정에 빠지지 않게): 입문형(단일종목 ≤30%) / 성장형(≤40%). 건별 승인 없음, 한도 초과 주문만 차단+안내. **[사실 — StockTrak이 단일종목 25% 상한을 실제 운영. 교육 시장 검증 관행]**
- 위험행동(손실 직후 거래금액 급증 등) 시 부모 코칭 알림: "차단하기보다 투자 이유를 먼저 물어보시겠습니까?"

### 5.3 질문식 매매 (주문 플로우 내장 기록)

'제안서'가 아니라 **펫과 아카이브의 재료가 되는 간단한 생각 데이터**(팀 합의). 주문 플로우 안에 내장되어 스킵 불가, 단 2탭이면 끝나게 설계한다.

- **근거 태깅** (매수): 뉴스에서 봤어 / 차트가 좋아 보여 / 친구·가족이 추천했어 / 이 회사(제품)를 잘 알아 / 그냥 느낌이 좋아 — 근거 유형 = 뉴스·차트·추천·지식·느낌 5축
- **근거 태깅** (매도): 목표한 만큼 올랐어 / 더 떨어질까 봐 걱정돼 / 다른 종목이 더 좋아 보여 / 그냥 불안해 / 기타
- **확신도** (매수 시): "얼마나 자신 있어?" 4단계 선택 — 잘 모르겠어(25) / 조금(50) / 꽤(75) / 완전(100). 펫이 물어보는 프레이밍으로 시험·채점 느낌을 제거한다. 내부에는 25/50/75/100 수치로 저장 — 행동 프로파일 엔진의 임계치 재료.
- 내 생각 한 줄(선택 입력).
- 선례 **[사실]**: StockTrak "Require Trading Notes" 기본 활성, SIFMA InvestWrite 에세이 결합 — '모의투자+기록'은 교육 시장의 검증된 결합.

## 6. AI 활용 구조 — 행동 분석 기반 가족 AI펫 (원안: `펫서비스기획.md`)

> 아이의 투자 행동 데이터를 관찰해서, 그 결과를 대화가 아니라 **가족이 함께 키우는 펫의 상태**로 표현한다.

### 6.1 왜 챗봇이 아니라 펫인가 (발표 Q&A 방어 자산)

| | 챗봇 | **펫** |
|---|---|---|
| 존재 방식 | 열어야 보임 | **상시 존재** — 홈에 항상 떠서 가족의 투자 상태를 은유적으로 계속 보여줌 |
| 소유 주체 | 아이 개인 도구 | **가족 공동 소유물** (가족 단위 1마리, 이름도 함께 지음) |
| 감지 결과 표현 | 텍스트 발화 | 표정·행동·성장 상태 |
| 관계 지표 | 로그에 숨음 | 펫 상태로 항상 가시화 |
| "굳이 왜 필요해?" | 범용 GPT와 헷갈림 | **이 가족의 데이터로만 존재·성장하는 캐릭터라 대체 불가능** |

**상호작용 원칙 (확정): 자유 입력 없음.** 아이가 펫에게 말을 거는 챗봇이 아니라, **펫이 먼저 감지하고 발화**하며 아이는 말풍선을 열람하고 선택지로 반응한다. 미성년 대상 실시간 대화형 AI의 발화 사고 표면적을 구조적으로 제거한다(§12-8).

### 6.2 관찰 대상 데이터

- 질문식 매매의 **근거 태깅** (뉴스/차트/추천/지식/느낌)
- 매수 전 **확신도** (25/50/75/100)
- 종목 상세 **체류시간·탭 전환 패턴**
- 교차 시그널도 재료다: "확신도 100 + 5분 망설임"처럼 말과 행동이 어긋나는 순간이 펫이 주목하는 지점.
- ※ **판단력 채점은 서비스 어디에도 없다** (완전 제외 — 원안 §7).

### 6.3 감지 → 펫 리액션 → 부모 전달 흐름

```
[아이 행동 이벤트]  예: 확신도 25로 매수 시도 / 종목 상세 5분+ 체류
      ↓
[행동 프로파일 엔진 판단]  규칙 기반, 상시 실행 — LLM 아님
      ↓
[임계치 통과 시에만 LLM 호출]  상황 맥락 반영한 짧은 문구 생성
      ↓
[펫 리액션]  갸우뚱 애니메이션 + 열어볼 수 있는 말풍선 (강제 팝업 아님)
      ↓
[아이가 열면]  정답을 주지 않고 되묻기 — "확신이 낮아 보이는데, 이유가 있어?"
      ↓
[같은 순간이 부모 화면에도 동기화]  "오늘 민지가 이런 고민을 했어요" (번역 전달)
```

### 6.4 오늘의 순간 (부모 화면, 일 1회)

- 감지된 아이의 행동 중 **이례적인 순간 하나만** 펫이 "물어다 주는" 형태로 부모에게 전달 (평소 대비 확신도가 크게 낮았던 매수 등). 매번 다 알리면 감시처럼 느껴지므로 빈도를 제한한다.
- **투명성 원칙 (확정): 부모에게 전달된 순간은 아이 화면에도 동일하게 표시한다** — "펫이 오늘 엄마한테 이 얘기를 물어다 줬어." 아이 몰래 보고하는 구조가 아니어야 펫이 고자질쟁이가 아니라 매개자가 된다.

### 6.5 주간 질문 (구 투자토크 흡수)

- 감지된 순간들을 재료로 펫이 그 주의 가족 질문을 던진다 — 예: 이번 주 '느낌' 태그가 많았음 → "어떤 기준으로 종목을 골랐어?"
- 부모·자녀 각자 답변(상대 답 비공개) → **둘 다 답하면 동시 공개** → 펫이 공통점/차이 정리.
- 예시 — "인기는 많은데 아직 돈을 못 벌고 있는 회사라면 우리 가족은 투자할까?" → 아이 "계속 많이 쓰면 나중엔 벌 수 있을 것 같아" / 부모 "계속 적자라면 기다렸다 투자할 것 같아" → 펫 정리 "아이는 미래 성장 가능성을, 부모는 현재 수익성을 더 중요하게 봤어요."

### 6.6 펫 성장 = 부모·자녀 커넥션 지표

- 펫의 성장 단계·컨디션은 **수익률이 아니라 "둘이 얼마나 소통했는지"**로 결정된다.
- 주간 질문에 둘 다 성실히 답하면 밝아지고, 한쪽만 응답이 없으면 시무룩해진다.
- 시즌 종료 시 "우리 펫이 이만큼 컸어요" — 커넥션 변화의 비포/애프터(§6.7 가족 성장기록).

### 6.7 아카이브 — AI 성향 리포트 · 수익률 리포트 · 가족 성장기록

- **AI 성향 리포트** (주간): 근거 태깅 분포·확신도 패턴·업종 다양성·투자 빈도 기반 성향 서술 + **유형 라벨**(재미 요소, 주간 갱신 — 아이 "뉴스 사냥꾼형" 등 / 부모 "분석가형" 등) + 잘한 점·놓친 점.
- **수익률 리포트**: 보유·평가손익·수익률 추이 (정량엔진 산출 그대로).
- **가족 성장기록** (시즌): 시즌 초↔말 비교 — 근거의 구체성 / 업종 탐색 다양성 / 확신도-행동 일치 / 주간 질문 참여 + **펫 성장 비포/애프터**. 리워드·재참여의 근거 화면.

### 6.8 예측 질문 대응 원칙 (카피 전반 공통)

자유 입력이 없어 "이 종목 오를까?"를 직접 받는 상황은 구조적으로 없지만, 펫의 모든 생성 문구·선택지에 같은 원칙을 적용한다:
1. 방향성 언어("오른다/내린다") 절대 사용하지 않음.
2. 정답 대신 되묻기 — 훈계 금지, 항상 선택지 또는 질문으로 마무리.
3. 사실 정보(공시·과거 이력)만, 미래 예측·권유 표현 금지 (미성년 대상 투자권유성 발언 리스크 회피).

### 6.9 구현 분리 구조 (환각 차단 — 발표의 기술 증거)

| 층 | 역할 |
|---|---|
| 행동 프로파일 엔진 | 확신도·태깅·체류 데이터에서 트리거 판단과 모든 지표 계산 (룰·통계, 상시 실행). **생성형 AI가 수치를 추정하지 않음** |
| 생성형 AI | 임계치 통과 시에만 호출. 엔진 산출**만** 입력받아 펫 문구·오늘의 순간·주간 질문·리포트 서술 생성 |

LLM이 상시 대기하지 않고 트리거 시점에만 소환되는 구조는 비용 효율적이면서 "관찰 후 반응"이라는 펫의 정체성과 기술적으로 일치한다.

### 6.10 출력 필터 (전 AI 경로 공통)

"이 종목을 사야 합니다 / 지금이 매수 기회 / 다음 주 상승 가능성 / 목표가·손절가 ○○원" — 차단. 펫 문구·오늘의 순간·주간 질문·아카이브 서술 전부 통과 후 출력, 탐지 건수 로깅(§9 안전 지표). 데이터가 적은 초기엔 "아직 관찰 초기" 문구 병기.

## 7. 대회·순위·리워드

### 7.1 가족 순위

- **가족 단위 순위** 제공 (통상 모의투자 대회 방식 — 가족 합산/평균 수익률 기준, 세부 산식은 운영 설계 시 확정 **[미확정]**)
- 홈에 우리 가족 현재 순위 + 부모·자녀 각각 수익률 표시.
- 순위(수익률)와 펫 성장(소통)은 **독립 축** — 순위가 낮아도 펫은 클 수 있다. "수익률 경쟁만 남는다"는 비판에 대한 구조적 답(§7.3).

### 7.2 리워드 (팀공유 원안)

| 대상 | 리워드 |
|---|---|
| 아이 | Robux, Minecoin, 시즌 인기 완구, (상위) 아이패드·닌텐도 |
| 가족 | 경험형 — 숙박권·항공권(휴가 시즌), 워터파크·리조트(여름), 스키장(겨울), 놀이공원·영화·외식권(상시). **"같이 투자해서, 같이 즐긴다"** |
| 금융 | 자녀 신규 키움계좌 개설 연계 — 투자지원금·소수점 주식. **계좌 개설은 참가 필수조건이 아니라 추가 리워드** (진입장벽↓ + 개설 KPI 확보) |
| 부모 | 로보마켓 프리미엄 체험권 (참가 즉시) |

### 7.3 게임화 리스크 관리 (발표 Q&A 방어 논리 — 삭제 금지)

**[사실]** FCA(영국 금융감독청) 9,000명+ 실험: 포인트·경품은 거래 +12%·위험거래 +6%p, 리더보드·푸시는 젊은 층을 위험거래로 유인. OSC(캐나다): "게임화 자체가 아니라 보상 대상이 문제."

**우리의 방어 구조** — 심사위원이 "애들 도박 가르치는 것 아니냐"고 물으면:
1. **모의투자다** — 실제 금전 손실이 없다 (FCA 실험은 실거래 맥락).
2. 위험상품 원천 배제 + 단일종목 상한 프리셋(§5.2) — 몰빵 학습을 구조로 차단.
3. 질문식 매매(근거+확신도)가 주문 플로우에 내장되어 **"왜"를 묻는 과정 학습**이 강제 리듬이다 — 수익률만 보는 대회와 다른 지점.
4. **펫 성장이 수익률과 무관한 소통 지표**라 아이의 일상 동기가 수익률 경쟁이 아니라 가족 소통에 걸려 있다.
5. 부모 동반 구조 + 위험행동 코칭 알림.
6. 유형 라벨은 주간 갱신이라 고정 낙인이 아니고, AI는 추천·시점·가격을 말하지 않는다(§6.10). 판단력 채점도 없다(§6.2).

## 8. 계좌 정책과 로보마켓

- 부모: **키움 계좌 보유 필수** (기존 고객 활성화 대상).
- 자녀: **계좌 없이 참가 가능** → 신규 미성년 계좌 개설 시 추가 혜택·투자 리워드. 모의투자 → 실제 금융생활로 자연스럽게 연결.
- **로보마켓**(키움의 AI/전문가 투자정보 마켓 **[사실]**): 아이에게는 제공하지 않고(아이에게는 관찰·연결형 AI펫), 부모에게 참가 혜택으로 프리미엄 체험권 → 대회 기간 체험 → 유료 전환·영웅문 사용 확대.
- 사업 퍼널: 부모 고객 → 가족리그 개설 → 자녀 참여·주간 재방문 → 시즌 완주 → 자녀 계좌 개설+첫 입금 → **성년 이후에도 키움** (세대 승계).

## 9. KPI

**최상위 지표: 펫이 매개한 가족 소통('오늘의 순간' 부모 열람 + 주간 질문 양측 응답)이 주 1회 이상 발생한 활성 가족 수.**

| 축 | 핵심 지표 |
|---|---|
| 획득 | 자녀 초대율, 수락률, 가족리그 개설률, 펫 작명 완료율 |
| 활성 | 첫 주 주문 완료율, 질문식 매매 기록률, 펫 말풍선 열람률, '오늘의 순간' 부모 열람률, 주간 질문 응답률(양측), 부모·자녀 모두 거래한 가족 비율 |
| 유지 | 4주/8주 유지율, 시즌 재참여율, 펫 성장 단계 분포 |
| 교육 효과 | 확신도-행동 일치 변화, 업종 탐색 다양성, 근거 태깅의 구체성 변화('느낌' 비중 추이) |
| 사업 | 자녀 신규계좌 개설률, 첫 입금률, 로보마켓 체험→유료 전환율, 자녀 고객 CAC |

## 12. 컴플라이언스 쟁점 (전부 법무 검토 필요 — 결론 미확정)

1. **투자자문 경계**: AI 출력이 '투자판단 조언' 해석 소지 → 종목 추천·시점·가격 전면 금지(§6.10), 관찰+일반 교육 한정. 해외 면책 레퍼런스 **[사실]**: Robinhood Cortex "not financial advice", Public Alpha "to help you reach your own conclusions".
2. **미성년 개인정보**: 만 14세 미만 법정대리인 동의(개인정보보호법 22조의2 **[사실]**) — 가입 절차 내장, 최소 수집.
3. **가족 간 정보 공유**: 자녀 거래·행동 정보의 부모 공개 범위·동의 — **'오늘의 순간'이 정확히 이 쟁점**. 투명성 원칙(§6.4)과 별개로 수집·제공 동의 설계 필요. 신용정보법 해당 여부 **[추론 — 검토 필요]**.
4. **경품 규제**: Robux·완구·아이패드·숙박권 등 경품류 제공 규제(한도·사행성) + 수익률 순위 연동 경품의 적정성. 미성년 대상 경품 고시 확인.
5. **전환 권유성**: 계좌 개설 리워드 안내가 투자 권유·광고 규제에 걸리는 범위.
6. **자동 성향 분류 고지**: 유형 라벨·행동 지표 산출·표시에 대한 고지 의무 — 행동 프로파일 엔진의 관찰 항목 고지 포함.
7. **AI 능력 과장 금지**: PortfolioPilot 'AI 워싱' SEC 제재($175,000, 2024) **[사실]** — "AI가 실력을 올려준다"류 효능 주장 금지, "관찰·교육 보조"로 일관.
8. **AI 발화 통제**: 미성년 대상 생성 문구 — 자유 입력 제거로 실시간 대화형 리스크는 구조적으로 축소. 남는 생성 경로(펫 문구·순간·질문·리포트)는 원칙(§6.8)+필터+전 문구 로깅, 고지 의무 검토.

## 13. 검증 계획 (PoC)

**PoC-1 (가장 위험): "부모가 자녀와 함께 8주 시즌에 참여할 의향이 있다"**
- 초등 고학년~중학생 자녀를 둔 부모 8~12명 인터뷰 + '오늘의 순간'·주간 질문 목업 반응. 질문: 본인 모의투자 부담 / 주당 투입 시간 / 펫이 전한 순간으로 대화를 시작할 의향 / 아이 행동 전달의 감시 느낌 여부 / 로보마켓 체험권·가족 리워드의 유인 효과.
- 통과: 과반 "주 30분 이내면 참여" + 목업에 대화 의향 + 감시 거부감 소수.

**PoC-2: "생성형 AI가 정량 사실만으로 왜곡 없는 서술을 만든다"**
- 모의 행동 데이터 20가족분 → 펫 리액션 문구·오늘의 순간·주간 질문·성향 리포트 생성 → (a) 사실 일치율(환각 검출) (b) 금지 표현 통과율 (c) 훈계·정답 제공 회피율(되묻기 마무리 준수) (d) 평가단 "대화하고 싶어지는가".
- 통과: 사실 불일치 0, 금지 표현 누출 0, 훈계·정답 0, 질문 품질 긍정 ≥ 70%.

## 14. 발표 논리 (KDA) + 중간발표 체크리스트

1. **문제**: 아이는 투자를 배울 경험이 없고, 부모는 전문가가 아니라 가르치기 어렵다 (미성년 계좌 +119% **[사실]** — 관심은 행동으로 증명).
2. **기존 대안의 한계**: 퍼핀은 가족 대회를 하지만 순위 비교까지 **[사실]**, 증권사 모의투자는 개인 중심, AI 분석은 전부 개인 단위 **[사실]** — **'가족의 생각을 연결'하는 AI는 무주공산**.
3. **해결**: 각자 투자하고, **가족이 함께 키우는 AI펫이 연결한다** — 관찰(행동 감지) → 되묻기(메타인지) → 번역('오늘의 순간') → 질문(주간 동시 공개) → 성장(커넥션 지표)이 하나의 루프. 챗봇이 아니라 펫인 이유(§6.1 비교표)가 "왜 굳이?"에 대한 답.
4. **왜 키움만**: 그룹 모의투자 인프라 + 미성년 비대면 계좌 퍼널 + 영웅문S# AI 스택·로보마켓 **[사실]**.
5. **왜 지금**: 신한이 세대 성향차 통계 발표·유사 서비스 구축 추진 중 **[사실]** — 아직 아무도 제품화 못 했다.
6. **사업 효과**: 부모 활성화 + 자녀 첫 투자 경험 선점 + 세대 승계. 최상위 KPI = 펫이 매개한 소통 가족 수.
7. **정직한 한계 + Q&A 대비**: 부모 참여 의향 미검증(PoC-1) / 게임화 질문에는 §7.3 방어 6종 / 감시 우려에는 투명성 원칙 / 컴플라이언스 8쟁점 미확정.

| 중간발표 체크리스트 (팀공유 §17) | 내용 |
|---|---|
| 한 줄 소개 | 부모와 자녀가 각자 모의투자를 하고, 함께 키우는 AI펫이 투자 생각을 이어주는 가족 투자 리그 |
| 사용자 | 키움 계좌 보유 부모 + 초등 고학년~중학생 자녀 |
| 발견한 문제 | 직접 경제교육 경험 부족, 부모의 교육 부담, 가족 금융 대화 부족 |
| 판단 근거 | 미성년 투자 관심 증가 [사실], 기존 서비스의 수익률 경쟁 중심 구조 [사실], 키움 서비스 자산 [사실] |
| 핵심 문제 재정의 | 부모가 전문가가 아니어도 아이가 스스로 투자하며 배우고 가족이 대화할 수 없을까? |
| 해결 방향 | 가족 모의투자(질문식 매매), 행동 분석 AI펫(감지·되묻기·오늘의 순간·주간 질문·성장), 아카이브(성향·수익률·성장기록) |
| 작동 방식 | 투자+근거·확신도 기록 → 펫이 관찰·감지 → 부모에게 번역 전달 → 주간 질문 동시 공개 → 펫 성장 → 시즌 성장기록 |
| 기대효과 | 아이 경제교육(메타인지), 부모 친밀도, 키움 고객 활성화·미래 고객 확보 |
| 진행/검증 | 7개 핵심 화면 MVP, 실제 계좌·주문 연동은 기획 단계 |
| 필요한 피드백 | 펫 매개 구조의 수용성(감시 우려 포함), AI 재미/교육성, 재참여 가능성, 키움 사업효과 |
