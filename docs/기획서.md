## 1. 정의

> **부모와 자녀가 각자 모의투자하고, AI가 투자 행동을 스코어링해 각자의 투자성향을 리포트로 읽어주는 가족형 모의투자 리그. 아이 옆에는 눈높이 AI 챗봇이 상주한다.**

### 서비스 핵심 문장

> **"아이는 그냥 투자해보면 된다 — 방법은 키웅이가 알려주고, 내 투자 스타일은 AI가 읽어준다."**

### 가장 중요한 차별점

> 가족이 같이 주문하는 서비스가 아니라, **각자 투자한 뒤 AI가 각자의 투자 스타일을 읽어 가족이 서로를 이해하게 하는 서비스.**
> 기존 가족/어린이 모의투자와의 차별점은 수익률 경쟁이 아니라 ① **아이 눈높이 AI 도우미** — 부모가 전문가가 아니어도 아이의 질문을 받아준다 ② **행동 스코어링 기반 성향 리포트** — 순위 비교(퍼핀식)를 넘어 서로의 스타일을 이해하게 한다.

### 핵심 AI Loop

```
각자 투자 (탐색·주문 + 질문식 기록: 근거 태깅·확신도, 2탭)
→ 행동 데이터 축적 (거래 로그 + 탐색 이벤트 + 근거·확신도)
→ 스코어링 엔진이 성향 5축 계산 (규칙·통계, 상시 — LLM 아님)
→ 아카이브: 주간 성향 리포트·유형 라벨 + 수익률 리포트 → 가족 비교 → 시즌 기록
막히는 순간 언제든 → 플로팅 챗봇 (물어보면 아이 눈높이로 답하고, 헤매는 신호가 보이면 먼저 도움 제안 — 추천·예측 금지)
```

## 3. 문제 정의

### 발견한 문제
- 아이들은 경제·투자를 직접 경험하며 배울 기회가 부족하다.
- **부모도 주식을 잘 안다는 보장이 없어** 자녀에게 직접 투자교육을 해주기 어렵다.
- 기존 모의투자는 개인 수익률 경쟁 중심이라 가족 간 대화 요소가 약하다.
- 증권사는 부모 고객뿐 아니라 자녀를 미래 고객으로 연결할 장기 접점이 필요하다.

### 핵심 문제 재정의

> **"부모가 투자 전문가가 아니어도, 아이가 스스로 투자해보고 AI의 도움을 받아 배우면서 부모와 자연스럽게 투자 이야기를 나눌 수 없을까?"**

역할 구조가 해법의 뼈대: **부모 = 선생님이 아니라 같이 참여하는 투자 파트너. 가르치는 역할 = 챗봇, 읽어주는 역할 = 스코어링 아카이브.** 아이의 "이게 뭐야?"는 챗봇이 부모 대신 받아주고, 부모는 리포트로 아이의 스타일을 이해하고 대화 소재를 얻는다 — '부모 참여 부담' 리스크의 1차 대응(§11).

## 5. 서비스 구조

### 5.0 사용자

| 역할 | 정의 |
|---|---|
| 부모 | 키움증권 계좌 보유자. 자녀와 같은 가족팀으로 참가, **본인도 별도 모의투자 진행**. 아카이브에서 자녀의 성향 리포트·가족 비교를 보고 대화 소재를 얻는다. 참가 혜택: **로보마켓 프리미엄 체험권** |
| 자녀 | 초등 고학년~중학생. **부모 승인 없이 자유롭게 모의투자.** 모르는 게 나오면 플로팅 챗봇 키웅이에게 바로 물어본다. 주간 성향 리포트로 내 투자 스타일을 확인 |

### 5.1 전체 User Flow

```
[개설] 부모 리그 개설 → 자녀 초대(법정대리인 동의) → 프리셋 선택 → 가상금 지급
[평일] 홈(가족 순위·각자 수익률) → 종목 탐색 → 상세(아이 눈높이 설명)
       → 주문 (수량 → 확인 → 질문식 기록: 근거 태깅+확신도 2탭 → 체결)
       모르는 게 나오면 → 플로팅 챗봇 (사용법·개념, 화면 맥락 인지)
[주간] 아카이브 갱신 — 성향 5축 스코어·유형 라벨·리포트 (부모·자녀 각각) → 가족 비교
[시즌 종료] 시즌 기록 (성향 변화 비포/애프터 + 수익률 결산) + 리워드
```

- 진입: 부모가 영웅문S#에서 가족리그 개설 → 자녀 초대 (미성년: 법정대리인 동의 **[사실 — 개인정보보호법 22조의2]**) → 시즌 프리셋 선택 → 전원 동일 가상금 지급.
- 첫 진입 시 튜토리얼 코치마크로 기본 화면(홈 구성·매매 진입·챗봇 소개)을 안내한다.

### 5.2 시즌 설계

- **8주 시즌, 분기마다 개최** / 부모 1+ 자녀 1+ / 전원 동일 가상금(예: 1,000만) / **국내주식 + 국내 상장 일반 ETF, 30종 내외 큐레이션** [종수·구성 추후 확정]
- 제외: 레버리지·인버스 ETF, ETN, 선물·옵션, 신용·미수, 공매도, 가상자산, 초저유동성. 해외주식은 2단계.
- 체결: **시장가+지정가**, 실제 수준 수수료·세금 안내, 동일 종목 **매도 후 30분 재매수 제한**(단타 억제). 데모 구현은 시장가 즉시 체결(§10).
- 프리셋(부모가 세부 설정에 빠지지 않게): 입문형(단일종목 ≤30%) / 성장형(≤40%). 건별 승인 없음, 한도 초과 주문만 차단+안내. **[사실 — StockTrak이 단일종목 25% 상한을 실제 운영. 교육 시장 검증 관행]**
- 위험행동(손실 직후 거래금액 급증 등) 시 부모 코칭 알림: "차단하기보다 투자 이유를 먼저 물어보시겠습니까?"

### 5.3 질문식 매매 (주문 플로우 내장 기록 — 08-10 팀 조율로 유지 확정)

'제안서'가 아니라 **스코어링 엔진과 리포트의 재료가 되는 간단한 생각 데이터.** 주문 플로우 안에 내장되어 스킵 불가, 단 **2탭이면 끝** — "모의투자는 심플하게" 원칙과 상충하지 않는 선을 지킨다.

- **근거 태깅** (매수): 뉴스에서 봤어 / 차트가 좋아 보여 / 친구·가족이 추천했어 / 이 회사(제품)를 잘 알아 / 그냥 느낌이 좋아 — 근거 유형 5축(뉴스·차트·추천·지식·느낌)
- **근거 태깅** (매도): 목표한 만큼 올랐어 / 더 떨어질까 봐 걱정돼 / 다른 종목이 더 좋아 보여 / 그냥 불안해 / 기타
- **확신도** (매수 시): "얼마나 자신 있어?" 4단계 탭 — 잘 모르겠어(25) / 조금(50) / 꽤(75) / 완전(100). 키웅이가 묻는 프레이밍으로 시험·채점 느낌을 제거하고 "정답은 없어!" 캡션 병기. 내부에는 25/50/75/100 수치로 저장 — 스코어링 엔진 재료(§6.2).
- 내 생각 한 줄(선택 입력).
- 선례 **[사실]**: StockTrak "Require Trading Notes" 기본 활성, SIFMA InvestWrite 에세이 결합 — '모의투자+기록'은 교육 시장의 검증된 결합.

## 6. AI 활용 구조 — 스코어링 엔진 + 두 개의 출구 (아카이브 / 챗봇)

> 아이의 투자 행동을 **정량 엔진이 스코어링**하고, 그 결과를 **아카이브 리포트**로 서술한다. 투자 중 궁금증은 **플로팅 챗봇**이 아이 눈높이로 받아준다. 두 출구 모두 같은 출력 필터(§6.6)를 통과한다.

### 6.1 왜 '아이 눈높이 챗봇'인가 (발표 Q&A 방어 자산)

- 문제 직결: **부모가 전문가가 아니라 못 가르친다(§3)** → 아이의 질문을 부모 대신 받아주는 존재가 서비스 안에 있어야 한다. 챗봇이 그 역할이다.
- "범용 GPT 쓰면 되잖아?"에 대한 답:
  1. **화면 맥락 인지** — 지금 보고 있는 화면·종목 기준으로 답한다 ("이 회사 뭐 하는 데야?").
  2. **미성년 안전 가드레일 내장** — 종목 추천·시점·가격·예측 차단 필터 + 전 대화 로깅. 범용 챗봇에는 없다.
  3. **앱 안 상주** — 투자하다 막히는 순간 이탈 없이 바로 묻는다 (플로팅 버튼).
  4. **아이 눈높이 페르소나 고정** — 키웅이. 짧은 문장, 쉬운 말, 비유.

### 6.2 스코어링 엔진 (성향 분석의 심장 — LLM 아님)

관찰 데이터: 거래 로그(종목·수량·타이밍·실현손익), **질문식 매매의 근거 태깅·확신도(25/50/75/100)**, 탐색 이벤트(종목 상세 체류시간·조회 종목 수), 포트폴리오 스냅샷. **챗봇 대화는 스코어링에 반영하지 않는다** — 질문은 성향이 아니고, 물어보면 점수가 바뀐다는 위축을 만들지 않는다.

**성향 5축** (각 0~100, 주간 산출):

| 축 | 측정 | 스타일 표현 (양끝 — 우열 없음) |
|---|---|---|
| 집중–분산 | 종목·업종 집중도 | 한우물형 ↔ 골고루형 |
| 속도 | 평균 보유기간·회전율 | 진득이형 ↔ 재빨리형 |
| 신중함 | 주문 전 탐색 깊이 + 확신도-행동 일치 | 직진형 ↔ 돌다리형 |
| 손실 대응 | 하락 구간 행동 (보유·손절·추가매수 패턴) | 버티기형 ↔ 갈아타기형 |
| 탐험심 | 새 종목·새 업종 시도 비율 | 익숙함형 ↔ 개척자형 |

- **원칙: 스코어는 '스타일'이지 '성적'이 아니다.** 잘함/못함 축이 없고 어느 끝도 우열이 아니다. 아이 화면에는 "정답은 없어!" 캡션 병기 — 채점·낙인 논란의 구조적 방어(§7.3).
- 유형 라벨 = 두드러진 상위 2축 조합, **주간 갱신**(고정 낙인 아님) — 예: 민지 "재빨리 개척자형", 엄마 "돌다리 분석가형".

### 6.3 아카이브 — 스코어링 기반 성향 리포트 · 수익률 리포트 · 시즌 기록

1. **성향 리포트** (주간, 부모·자녀 각각): 5축 게이지 + 유형 라벨 + 근거 태깅 분포·확신도 패턴('느낌' 비중 추이 등) + LLM 서술(스타일 요약, 잘한 점·아쉬운 점 각 1~2개 — 훈계 아닌 관찰 톤).
2. **수익률 리포트**: 보유·평가손익·수익률 추이 (정량엔진 산출 그대로, LLM 서술 없음).
3. **가족 비교** [확인 필요 §15]: 두 사람의 5축을 나란히 + 중립 서술 1줄 — "민지는 재빨리, 엄마는 진득하게. 스타일이 달라요." 퍼핀식 '순위 비교'를 넘어서는 가족 이해 장치이자 대화 소재. 양측 공개 동의 전제(§12-3).
4. **시즌 기록**: 시즌 초↔말 성향 변화 비포/애프터 + 수익률 결산 — 리워드·재참여의 근거 화면.

### 6.4 플로팅 AI 챗봇 "키웅이" — 개인 코치 (08-10 기능 범위 팀 확정)

> "투자 정답을 주는 AI"가 아니라, 아이의 모의투자 과정에서 질문을 받아 **이해·기록·성찰을 돕는 개인 코치.** 물어보면 답하고, 헤매거나 불안해 보이면 먼저 짧게 말을 건다. 추천·예측은 구조적으로 거절.

**기능 범위 (팀 확정 9종)**

| # | 기능 | 챗봇이 하는 일 |
|---|---|---|
| ① | 대화 시작 | "고민 있어?", "궁금한 거 있어?" 같은 부담 없는 말로 먼저 말 건다. 무시·종료·뮤트 자유 |
| ② | 금융 개념 교육 | 수익률·손익·분산·수수료·세금·지정가/시장가 등 앱에서 마주치는 개념을 청소년 눈높이로 설명 |
| ③ | 서비스 사용 안내 | 모의투자 규칙·거래 시간/방식·종목 검색·포트폴리오·가족 대시보드 보는 법 |
| ④ | 종목 유니버스 안내 | 유니버스 종목(§5.2)의 사업 내용·업종·제품·공개된 과거 정보 설명 — 사실만, 예측 금지 |
| ⑤ | 투자 기록 되짚기 | "왜 이 종목을 골랐어?", "처음 적은 이유와 지금 생각이 같아?" — F3 근거·확신도 돌아보기 |
| ⑥ | 성향 분석 설명 | F9 성향 리포트(태그 분포·확신도·거래 빈도·업종 분산·보유 패턴)를 쉽게 풀어 설명 |
| ⑦ | 아카이브 탐색 | 과거 매매 이유·한 줄 메모·수익률 추이·시즌 기록을 찾아 비교·요약 |
| ⑧ | 불안 행동 감지 | 반복 취소·긴 망설임·낮은 확신도 매수·손실 직후 재접속을 감지해 먼저 말 걸기 (선제 발화 B계층) |
| ⑨ | 안전 대응 | 종목 추천·매매 시점·목표가·수익률 예측 무응답(고정 거절+기준 안내). **과몰입·정서적 위기 표현 → 대화 안전 종료 + 보호 안내** |

- **진입**: 전 화면 우하단 플로팅 버튼(키웅이 얼굴) → 바텀시트 챗 UI. "열어야 보인다"는 약점은 튜토리얼 + 화면별 추천 질문 칩 + 선제 발화로 보완.
- **입력**: 자유 입력 + 화면 맥락별 추천 질문 칩 3개 (종목 상세: "이 회사는 뭐 하는 회사야?" / 주문: "시장가가 뭐야?" 등).
- **컨텍스트(읽기 전용)**: {현재 화면·종목} + **{내 거래 로그·F3 근거/확신도·F9 리포트 산출}** — ⑤⑥⑦의 재료. 수치는 엔진/API 값만 인용(§6.5), 챗봇이 수치를 만들지 않는다.
- **응답 원칙**: 3문장 이내·쉬운 말·비유·이모지. 훈계 금지 — 되묻기·선택지로 마무리.
- **라우팅**: 용어 사전·FAQ 매칭(②③) 우선 → 내 기록·성향 질문(⑤⑥⑦)은 LLM+개인 데이터 → 그 외 LLM(스트리밍) → 실패 시 고정 폴백.
- **사고과정 타임라인**: 응답 전 파이프라인 단계를 칩+한 줄로 표시 — 경로("무슨 질문인지 보는 중") → 사전 → 탐색("기록 찾는 중") → 답변 → **안전 점검("안전 점검 통과!")**. 전부 고정 문구라 생성 표면 증가 없음. '안전 점검' 단계의 가시화 자체가 §12-8 통제 구조의 시연.
- 부모도 같은 챗봇 사용 가능 (톤 동일).

**선제 발화 — 2계층 신호 (⑧ 반영, 08-10 확장)**

키웅이가 먼저 말을 거는 조건은 두 계층이다. 발화 문구는 신호별 **고정 스크립트**(LLM 미사용 — 생성 표면이 늘지 않음, §12-8), 반응은 카드 3장 고정: **상황 설명 / 자유 질문 / 괜찮아**. **부모에게 전달되지 않는다** — 아이 본인에게만 가는 개인 코치라 '오늘의 순간'식 감시 프레임이 성립하지 않는다.

**A계층 — 사용법 헤맴** (같은 종목·같은 주문 세션 안에서만 계산):

| # | 신호 (조건 수치는 전부 [가정] — 초기 운영값) | 고정 발화 |
|---|---|---|
| 1 | 매수↔매도 30초 내 3회 전환 (최초 선택 제외) | "매수와 매도 차이가 헷갈려?" |
| 2 | 주문 확인창 열기→뒤로 가기, 2분 내 2회 반복 | "주문 전에 확인하고 싶은 게 있어?" |
| 3 | 주문 수량 45초 내 3회 재수정 — 입력 후 0.7초 이상 멈춘 값을 1회로 계산(키 입력 아님) | "몇 주 살지 계산해볼까?" |
| 4 | 활성 장기 체류 — 주문 화면 90초 / 종목 상세 180초 (읽기 시간 감안 2배) | "어디에서 막혔는지 같이 볼까?" |

- 체류 유효 조건(모두 만족): 앱 전면 + 최근 30초 내 탭·스크롤·키 입력 + 주문 완료·화면 이동 같은 진행 행동 없음 + 마지막 조작 2초 후 발화.
- **발화 제한**: 선제 발화 간 최소 3분 / 동일 신호 10분 내 재발화 금지 / 세션 최대 2회 / [괜찮아] 선택 시 해당 신호는 세션 내 재발화 금지 / 30분 무활동이면 새 세션.
**B계층 — 불안 행동 (08-10 팀 확정 신설 — 임계값 전부 [가정], 30세션 검증 대상)**:

| 신호 | 안부형 고정 발화 |
|---|---|
| 낮은 확신도 매수 — 평소 대비 크게 낮은 확신도(F3)로 매수 시도 | "고민 있어? 궁금한 거 있으면 물어봐 🐻" |
| 손실 직후 재접속 — 평가손실 확대 후 짧은 간격 재접속 | "괜찮아? 오늘 시장이 좀 출렁였지" |
| 주문 취소·정정 반복 — 지정가 설계 복귀(§5.2)로 후보→채택 | "주문이 마음처럼 안 돼? 같이 볼까?" |

- B계층 원칙: 정답·훈계·거래 재촉 없음(FCA·ICO 중립 개입 [사실]) — 안부만 묻고, 이어지는 대화는 아이가 선택.
- 제외 유지: 차트 기간 반복 변경(학습·탐색과 구분 불가) · 여러 종목 빠른 조회(정상 탐색) · 주문 오류 반복(오류 문구가 직접 설명하는 게 단순).
- 근거 **[사실]**: FCA 연구 노트·ICO 아동 설계 지침(넛지 §13)은 거래를 재촉하지 않는 **중립 개입** 방향을 뒷받침 — 단 반복 횟수 수치까지는 제공하지 않는다. 따라서 수치는 [가정]이며, 자녀 테스트 30세션에서 '실제 도움 필요 순간' 일치율 70% 미만인 신호는 기준 상향 또는 제거한다(§13 PoC-2).

### 6.5 구현 분리 구조 (환각 차단 — 발표의 기술 증거, v5 자산 유지)

| 층 | 역할 |
|---|---|
| 스코어링 엔진 | 거래·탐색 데이터에서 5축 스코어·유형·모든 지표 계산 (룰·통계, 상시 실행). **생성형 AI가 수치를 추정하지 않음** |
| 생성형 AI | ① 아카이브: 엔진 산출 JSON**만** 입력받아 성향 서술 생성 ② 챗봇: 도메인 제한 프롬프트 + 화면 맥락, 시세·보유 수치는 엔진/API 값만 인용 |

### 6.6 출력 필터 (전 AI 경로 공통, v5 자산 유지 + 챗봇 입력단 추가)

- 출력 차단: "이 종목을 사야 합니다 / 지금이 매수 기회 / 다음 주 상승 가능성 / 목표가·손절가 ○○원" — 아카이브 서술·챗봇 응답 전부 통과 후 출력, 탐지 건수 로깅(§9 안전 지표).
- 챗봇 입력 분류(신설): 오프토픽(게임·숙제 등)·유해·개인정보 입력 → 고정 응답으로 우회 ("나는 투자 이야기만 할 수 있어!"). 전 대화 로깅.
- 데이터가 적은 초기엔 성향 리포트에 "아직 관찰 초기" 문구 병기.

## 7. 대회·순위·리워드

### 7.1 가족 순위

- **가족 단위 순위** 제공 (통상 모의투자 대회 방식 — 가족 합산/평균 수익률 기준, 세부 산식은 운영 설계 시 확정 **[미확정]**)
- 홈에 우리 가족 현재 순위 + 부모·자녀 각각 수익률 표시.
- 순위(수익률)와 성향 리포트(스타일)는 **독립 축** — 순위가 낮아도 내 스타일은 읽힌다. "수익률 경쟁만 남는다"는 비판에 대한 구조적 답(§7.3).

### 7.2 리워드 (팀공유 원안)

| 대상 | 리워드 |
|---|---|
| 아이 | Robux, Minecoin, 시즌 인기 완구, (상위) 아이패드·닌텐도 |
| 가족 | 경험형 — 숙박권·항공권(휴가 시즌), 워터파크·리조트(여름), 스키장(겨울), 놀이공원·영화·외식권(상시). **"같이 투자해서, 같이 즐긴다"** |
| 금융 | 자녀 신규 키움계좌 개설 연계 — 투자지원금·소수점 주식. **계좌 개설은 참가 필수조건이 아니라 추가 리워드** (진입장벽↓ + 개설 KPI 확보) |
| 부모 | 로보마켓 프리미엄 체험권 (참가 즉시) |

### 7.3 게임화 리스크 관리 (발표 Q&A 방어 논리 — 삭제 금지)

**[사실]** FCA(영국 금융감독청) 9,000명+ 실험: 포인트·경품은 거래 +12%·위험거래 +6%p, 리더보드·푸시는 젊은 층을 위험거래로 유인. OSC(캐나다): "게임화 자체가 아니라 보상 대상이 문제."

**우리의 방어 구조** — 심사위원이 "애들 도박 가르치는 것 아니냐"고 물으면:
1. **모의투자다** — 실제 금전 손실이 없다 (FCA 실험은 실거래 맥락).
2. 위험상품 원천 배제 + 단일종목 상한 프리셋(§5.2) — 몰빵 학습을 구조로 차단.
3. **질문식 매매(근거+확신도)가 주문 플로우에 내장**되어 "왜"를 묻는 과정 학습이 강제 리듬이다 — 수익률만 보는 대회와 다른 지점.
4. **챗봇이 '기준'을 가르친다** — 종목을 골라주는 게 아니라 고르는 기준·개념을 알려주는 교육 장치(§6.4). 추천 요구는 거절하도록 설계.
5. **성향 리포트가 수익률이 아닌 '스타일' 서사를 매주 제공** — 아이의 주간 관심사가 순위만이 아니게 한다. 스코어는 성적이 아니다(§6.2).
6. 부모 동반 구조 + 위험행동 코칭 알림 + 동일 종목 매도 후 30분 재매수 제한(§5.2 — 단타 억제 장치).
7. 유형 라벨은 주간 갱신이라 고정 낙인이 아니고, AI는 추천·시점·가격을 말하지 않는다(§6.6). 실력 채점·등급은 없다(§6.2).

## 8. 계좌 정책과 로보마켓

- 참가: **부모·자녀 모두 모의투자 계좌를 개설했다는 가정** (08-10 팀 조율). 실계좌는 참가 요건이 아니다.
- 부모: 기존 키움 고객 활성화 타깃 **[가정 — 실계좌 연계 범위는 운영 설계]**.
- 자녀: 신규 미성년 실계좌 개설 시 추가 혜택·투자 리워드 — 모의투자 → 실제 금융생활로 자연스럽게 연결.
- **로보마켓**(키움의 AI/전문가 투자정보 마켓 **[사실]**): 아이에게는 제공하지 않고(아이에게는 눈높이 챗봇·성향 리포트), 부모에게 참가 혜택으로 프리미엄 체험권 → 대회 기간 체험 → 유료 전환·영웅문 사용 확대.
- 사업 퍼널: 부모 고객 → 가족리그 개설 → 자녀 참여·주간 재방문 → 시즌 완주 → 자녀 계좌 개설+첫 입금 → **성년 이후에도 키움** (세대 승계).

## 13. 검증 계획 (PoC)

**PoC-1 (가장 위험): "부모가 자녀와 함께 8주 시즌에 참여할 의향이 있다"**
- 초등 고학년~중학생 자녀를 둔 부모 8~12명 인터뷰 + 성향 리포트·가족 비교 목업 반응. 질문: 본인 모의투자 부담 / 주당 투입 시간 / 리포트·비교로 대화를 시작할 의향 / 아이 행동 스코어링의 감시·채점 느낌 여부 / 챗봇만으로 교육성이 충분하다고 느끼는지 / 로보마켓 체험권·가족 리워드의 유인 효과.
- 통과: 과반 "주 30분 이내면 참여" + 목업에 대화 의향 + 감시·채점 거부감 소수.

**PoC-2: "미성년 대상 챗봇·리포트 생성이 안전하고 정확하다"**
- 챗봇: 아동 관점 질문 시나리오 50개(사용법/개념/종목 맥락/추천 유도/오프토픽/유해) → (a) 금지 표현 누출 0 (b) 추천 유도 거절률 100% (c) 연령 적합성(문장 난이도·톤) (d) 사실 정확도.
- 아카이브: 모의 행동 데이터 20가족분 → 성향 서술 생성 → 엔진 JSON 대비 사실 일치율(환각 검출)·금지 표현 통과율·낙인성 표현 0.
- 선제 신호 정합: 자녀 테스트 **30세션** 기록 → 신호 발동과 '실제 도움이 필요했던 순간' 일치율 측정, **70% 미만인 신호는 기준 상향 또는 제거**(§6.4).
- 통과: 사실 불일치 0, 금지 표현 누출 0, 거절률 100%, 평가단 이해도 긍정 ≥ 70%.

## 14. 발표 논리 (KDA) + 중간발표 체크리스트

1. **문제**: 아이는 투자를 배울 경험이 없고, 부모는 전문가가 아니라 가르치기 어렵다 (미성년 계좌 +119% **[사실]** — 관심은 행동으로 증명).
2. **기존 대안의 한계**: 퍼핀은 가족 대회를 하지만 순위 비교까지 **[사실]**, 증권사 모의투자는 개인 중심, AI 분석은 전부 개인 단위·성인용 **[사실]** — **아이 눈높이 AI + 가족 성향 이해는 무주공산**.
3. **해결**: 각자 심플하게 투자하고 — ① 막히면 **키웅이 챗봇**이 부모 대신 눈높이로 알려주고 ② **스코어링 엔진**이 행동을 읽어 ③ **아카이브**가 각자의 투자 스타일을 리포트로 돌려준다. 가족은 서로의 스타일을 보고 이야기한다.
4. **왜 키움만**: 그룹 모의투자 인프라 + 미성년 비대면 계좌 퍼널 + 영웅문S# AI 스택·로보마켓 + 마스코트 키웅이 **[사실]**.
5. **왜 지금**: 신한이 세대 성향차 통계 발표·유사 서비스 구축 추진 중 **[사실]** — 아직 아무도 제품화 못 했다.
6. **사업 효과**: 부모 활성화 + 자녀 첫 투자 경험 선점 + 세대 승계. 최상위 KPI = 부모·자녀 동반 활성 가족 수.
7. **정직한 한계 + Q&A 대비**: 부모 참여 의향 미검증(PoC-1) / 게임화 질문에는 §7.3 방어 6종 / 미성년 챗봇 안전에는 §12-8 통제 구조 + PoC-2 / 컴플라이언스 8쟁점 미확정.

|---|---|
| 한 줄 소개 | 부모와 자녀가 각자 모의투자하고, AI가 각자의 투자성향을 읽어주며, 아이 옆엔 눈높이 챗봇이 있는 가족 투자 리그 |

| 해결 방향 | 모의투자(가족 리그·질문식 기록), 스코어링 기반 아카이브(성향 5축·유형·리포트·가족 비교), 플로팅 AI 챗봇(아이 눈높이 사용법·개념 + 선제 도움 신호) |
