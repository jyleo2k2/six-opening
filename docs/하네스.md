# 하네스

- 각 소유 경계에는 같은 내용의 `AGENTS.md`와 `CLAUDE.md`를 둔다. 한쪽을 수정하면 짝도 수정하고 완료 전 비교한다.
- 규칙은 루트부터 현재 폴더까지 누적되며, 가장 가까운 가드가 소유 범위를 정한다.
- 현행 경계: 루트, `web`, `web/app`, `web/shared`, `web/features/{f0-home,f2-trade,f3-reason,f9-archive,f10-chatbot}`.
- 기능 담당은 자기 폴더만 수정한다. `app`·`shared` 변경은 해당 가드 절차를 따른다.
- 기준 우선순위: 기획서 v7 > 기능명세 > 디자인시스템 > 기술스택·가드.
