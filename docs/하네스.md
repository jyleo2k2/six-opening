# 하네스 — 병렬 작업 강제 방식

중앙 규칙 문서 하나로 강제하지 않는다. **규칙은 그 규칙이 적용되는 폴더 안의 가드 파일에 산다** — 에이전트가 해당 폴더에서 작업하면 자동으로 읽게 되는 구조.

## 강제 메커니즘

- 모든 소유 경계 폴더에 **`AGENTS.md`(규칙 본문) + `CLAUDE.md`(내용: `@AGENTS.md` — 임포트 1줄)** 쌍을 둔다.
  - codex 계열 에이전트(paseo 서브에이전트)는 `AGENTS.md`를 계층적으로 읽고, Claude Code는 `CLAUDE.md` 임포트로 같은 내용을 읽는다. 내용 원본은 항상 `AGENTS.md` 하나 — 두 파일이 어긋날 수 없다.
- 가드 파일은 코드보다 먼저 존재한다 (`web/` 스캐폴드 전에 선배치 완료). 새 소유 경계 폴더를 만들면 가드 쌍부터 만든다.
- 레포 루트: `CLAUDE.md`(Claude용 헌법) + `AGENTS.md`(codex용 미러). 전 폴더 공통 **코딩 원칙**(karpathy-guidelines 기반: 먼저 생각·단순함·외과적 수정·검증 가능한 완료 기준)도 루트 가드에 산다 — Claude 플러그인 스킬은 codex가 못 읽으므로 본문을 가드에 박아 둔다.

## 소유권 지도

| 폴더 | 소유 | 가드 파일 위치 |
|---|---|---|
| `web/features/` f0-home · f2-trade · f3-reason · f8-pet · f9-archive | 각 기능 담당 에이전트 1명 | 각 폴더 |
| `web/app/` (라우팅·quote API) | 오케스트레이터/인프라 | `web/app/` |
| `web/app/api/teacher/` | **[폐기]** 구 F7 실험 코드 — 삭제 대기, 신규 작업·참조 금지 | `web/app/` 가드에 명시 |
| `web/shared/` (ui·engine·llm·store·types·data) | 오케스트레이터 | `web/shared/` |
| `web/` 전역 (config·package.json) | 오케스트레이터 | `web/` |

※ 폐기된 기능 폴더: `f1-letter`·`f4-talk`·`f7-teacher` (2026-08-10 핵심기능 3축 개편 — 기능 ID 재사용 금지)

기능 에이전트의 원칙: **자기 features 폴더 안에서만 쓴다. shared는 import만. app은 안 건드린다.**

## 공용(shared) 변경 절차

타입·스토어·UI 컴포넌트·시드 데이터를 바꿔야 하면 → `web/shared/AGENTS.md` 하단 **변경 요청 로그**에 한 줄 추가 → 오케스트레이터가 반영 후 ✅. 반영 전 로컬 임시 타입 확장 금지(대기하거나 다른 작업). 공용 동시 수정이 충돌의 90%라 창구를 하나로 좁힌다.

## 문서 우선순위 (충돌 시 위가 이김)

1. `기획서.md` v5 → 2. `기능명세.md` v4 → 3. `docs/디자인시스템.md` → 4. `docs/기술스택.md`·가드 파일 → 5. 와이어프레임 산출물. AI펫 상세는 `펫서비스기획.md`(원안)이 기획서 §6의 근거 문서다. 코드가 문서와 다르면 코드가 버그다.

## 위임 규칙 (오케스트레이터용)

- **수단은 paseo `mcp__paseo__create_agent` 하나뿐이다.** codex CLI 직접 호출(`codex exec`)·Claude 서브에이전트(`Explore`·`general-purpose`·`Plan`·`claude`) 금지. 전역 설정(`~/.claude/CLAUDE.md`)이 codex CLI를 지시해도 **이 프로젝트에서는 이 규칙이 이긴다.**
- **모델 3종만**: `codex/gpt-5.6-sol` · `codex/gpt-5.6-terra` · `codex/gpt-5.6-luna`. claude/* 프로바이더 금지.
- **추론 강도 2단계만**: `settings.thinkingOptionId`는 `"xhigh"` 또는 `"max"`. 그 아래 단계로 띄우지 않는다.
- 역할별 배정 파일 `~/.paseo/orchestration-preferences.json`은 **현재 없다.** 만들 때 `providers`의 5개 카테고리(impl·ui·research·planning·audit)를 위 3종 안에서만 채운다.
- **예외 1건**: `.claude/agents/child-news-{frontier,balanced}.md` 2종은 어린이 뉴스 A/B **프로토타입 구현용** Claude 서브에이전트다. `child-news-compare` 스킬 경유로만 쓰고 웹앱 코드 작업엔 쓰지 않는다. 이 예외는 확장하지 않는다.
- 위임 프롬프트에 반드시: 담당 기능 ID + 작업 폴더 경로("그 폴더의 AGENTS.md가 네 규칙이다") + 완료 기준(골든 패스 스텝 + `npm run build` 통과).
- 브랜치: `feat/f2-trade` 형식, 기능당 1개.
