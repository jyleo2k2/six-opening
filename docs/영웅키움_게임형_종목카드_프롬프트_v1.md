# 51개 기업 게임형 종목카드 이미지 생성 프롬프트

## 사용 방법

각 기업마다 아래 순서로 입력합니다.

1. **Image 1**: 실제 기업명·설명·현재가·등락률·차트가 들어간 기존 종목카드 스크린샷
2. **Image 2**: 해당 기업의 3D 젤리 로고 PNG
3. 해당 기업 아래의 프롬프트 전체를 복사하여 입력

프롬프트는 51장이 한 덱처럼 보이도록 레이아웃을 고정하고, 기업별로 카테고리·브랜드 색·배경 모티프만 다르게 설계했습니다. 상승은 빨강, 하락은 파랑이라는 국내 주식 표기 규칙도 포함되어 있습니다.

> **중요:** 생성형 이미지의 한글과 숫자는 가끔 틀릴 수 있습니다. 발표용 시안에는 사용할 수 있지만, 실제 앱에서는 카드 배경·프레임만 이미지로 만들고 기업명·설명·가격·등락률은 HTML/CSS 또는 Figma 텍스트 레이어로 올리는 방식을 권장합니다.

## 공통 출력 규칙 요약

- 동일한 세로 비율과 동일한 정보 배치
- 좌측 상단 젤리 로고, 우측 상단 영문 카테고리
- 기업명 → 한 줄 설명 → 현재가 → 등락률 순서
- 우측 하단 미니 차트
- 기업 대표색 기반의 어두운 글래스 카드
- 게임 카드의 수집 욕구는 살리되 카지노·유아용·과도한 사이버펑크 느낌은 배제
