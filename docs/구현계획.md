# 구현계획 — 키즈:키움 (자녀 영웅문 + 히스토리 투자 시뮬)

근거 문서: `docs/기획서.md`(2026-08-07 히스토리 투자 시뮬) · `docs/기술스택.md`

## 0. 현황 (2026-08-07)

게임 기획이 전면 교체됐다(1:1 카드게임 → 2~8인 히스토리 투자 시뮬). `claude/이재용/history-sim`
브랜치가 카드게임 엔진·데이터·테스트를 폐기하고 새 엔진 뼈대를 구축한다. 제안서·뉴스·도감
트랙과 앱 셸(자녀 영웅문 + 부모 뷰)은 **그대로 유지**된다.

구조도 유지: `game`·`web` 2워크스페이스(npm workspaces), 룰 엔진 SSOT + Colyseus 권위 서버 + 시뮬.

## 1. 서비스 ↔ 구조 매핑

| 기능 | 구현 위치 |
|---|---|
| ① 히스토리 투자 시뮬 | `game/src`(룰 SSOT) · `game/data`(종목·이벤트·뉴스) · `game/server`(2~8인 룸) · `game/sim` + `web/features/game` + `(child)/game` |
| ② 눈높이 경제뉴스 + 도감 | `pipelines/news_digest` + `content/` + `(child)/news`·`dex` |
| ③ 투자 체험 + 제안서 | `web/lib/brokerage`(port+mock) + `(child)/home`·`stock`·`proposal` + `(parent)/inbox`·`onboarding` |

게임과 제안서·뉴스는 서로 독립 — 병렬 진행 가능.

## 3. 트랙 경계

| 트랙 | 담당 | 경로 |
|---|---|---|
| ① 게임 | 이재용·이호연 | `game/` 전체 + `web/features/game` + `web/app/(child)/game` |
| ② 투자제안서 | 김설빈·박혜준 | `web/lib/brokerage` + `(child)/{home,stock,proposal}` + `(parent)/` + 관련 `api/` |
| ③ 뉴스·도감 | 김경렬·강소정 | `pipelines/` + `content/` + `(child)/{news,dex}` **+ `game/data` 텍스트 공급(뉴스 풀·사건 문구·사료 검증)** |

- `game/data` 텍스트는 ③이 쓰고 **①이 승인해 머지** — 밸런스 수치(`effects` 범위)는 ① 소유
- 공유 핫스팟: `game/src/types.ts`(엔진 계약) · `web/app/layout.tsx` · `web/components/ui/**` → 계약 PR 먼저, 통합 오너 승인

## 4. 작업 규칙

- **루트에서 코드 수정 금지** — `git_session_manager.py start`로 워크트리 세션 claim 후 작업
- 콘텐츠 정책: 사람 검수 대상은 **편집 텍스트**(`content/` + `game/data` 문구) — 실시간 유저 채팅은 검수
  대상이 아니다(닉네임만·200자·금칙어 필터 후속). 앱이 실존 종목 추천 금지. 자녀 개인정보는
  닉네임+부모 FK만. `BrokeragePort`에 `placeOrder` 추가 금지
- 밸런스 수치 변경: `test` → `sim` 전후 비교 → 기획서 갱신 요청(이재용). 추측 금지, 실행 결과로 보고
- 이벤트 방향(부호) 변경은 사료 근거를 PR에 첨부 (`game/AGENTS.md`)
