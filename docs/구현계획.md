## 3. 회피카드 구현 방식 — 결정 필요 (구조를 바꾸는 유일한 항목)

뼈대의 가격 모델은 섹터별 **글로벌 배율**(시장 공유)이라, "자기 존만 -5%로 제한"을 표현할 수 없다 (§14.2의 지적 그대로).

| 방식 | 내용 | 트레이드오프 |
|---|---|---|
| (a) 존별 배율 | 플레이어 존마다 가격 배율 분리, 회피가 자기 존의 하락 적용만 가로챔 | 기획서 문언 그대로. 상태 모델 변경 큼, "내 평가금액 ≠ 시장가" 표시 필요 |
| **(b) 보험금 지급 (추천)** | 시장가는 공유 유지. 발동 시 "막아준 손실액"(-20%와 -5%의 차액)을 **현금으로 지급** | 상태 모델 유지, 옛 엔진의 `savedAmount` 패턴 재활용, "보험금" 개념이 교육적으로도 직관적. 단 기획서 §4.3 문언 수정 필요 |

발동 시점의 총자산은 두 방식이 동일하다. (b)로 가면 기획서 §4.3을 고쳐야 하므로 이재용 결정 사항.
