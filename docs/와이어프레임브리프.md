# 와이어프레임 브리프 — 키움 가족 모의투자 리그

> 이 문서만 보고 와이어프레임을 그릴 수 있는 자기완결 브리프. (원본: `기획서.md` v4, `기능명세.md` v3)

## 서비스 한 줄

부모와 자녀(초등 고학년~중학생)가 **각자 모의투자**를 하고, AI가 두 사람의 투자 생각과 행동을 분석해 연결해주는 **가족형 모의투자 리그**. 리듬: "평일에는 각자 투자하고, 주말에는 AI가 우리 가족의 투자 생각을 연결해준다."

## 디자인 규칙 (강제)

- **폼팩터**: 모바일 390×844. 영웅문S# 증권앱 안의 가족대회 전용 UX라는 설정.
- **컬러**: Deep Navy `#001E5A`(헤더·핵심 정보·주요 카드) / Magenta `#D70082`(CTA·선택 상태·강조) / Light Gray `#BEBEBE`(배경·구분선·비활성) / Base White. — 키움증권 공식 키컬러.
- **증권앱 관례 (영웅문 친숙함 — 절대 어기지 말 것)**:
  - 등락 색상: **상승/수익 = 빨강 `#E8322E`, 하락/손실 = 파랑 `#1668DC`** (국내 증권앱 표준. 해외식 초록/빨강 금지)
  - 구조: 네이비 헤더 + 흰 바탕 콘텐츠 (증권앱 기본 골격)
  - 숫자: 가격·수익률은 고정폭(tabular) 느낌으로 크고 명확하게, 등락엔 ▲▼ 기호 병용
- **톤**: 위 골격 위에 금융앱스럽지 않은 살 — 큰 라운드 카드, 친근한 말투(자녀 화면 반말 "~해볼까?", 부모 화면 존댓말). 별·말풍선·스티커·컨페티 포인트. (구조는 증권앱, 표면은 아이 친화 — 이 조합이 "영웅문 안의 가족 서비스" 컨셉)
- **캐릭터**: 영웅이(상승장 소)·키웅이(친근한 곰) — AI 선생님 아바타, 투자편지 인트로, 빈 화면. 와이어프레임에서는 원형 플레이스홀더+라벨.
- **듀얼 뷰**: 상단에 데모용 계정 전환 스위치(민지 ↔ 엄마).
- **AI 카피 원칙**: AI가 말하는 문구에 "사라/팔아라/오를 것" 류 금지 — 예시 카피 작성 시 설명·되물음 형태로.

## 화면 목록 (7 + 개설 플로우)

### 1. 홈 (자녀 뷰 / 부모 뷰)
- 시즌 진행바 "4주차 / 8주"
- **우리 가족 현재 순위** 카드 (예: "12위 / 340가족")
- 부모/자녀 각각 수익률 카드 (민지 +3.2% / 엄마 +1.8%)
- 모의투자 바로가기 CTA (Magenta)
- 이번 주 가족 투자편지 예고 배너: "💌 토요일에 도착해요! 이번 주 우리 가족 궁합은 몇 %일까요?"
- 시즌 리워드 안내 카드 (가족 숙박권·Robux 등 아이콘)
- 부모 뷰 전용: 로보마켓 프리미엄 체험권 배너
- 하단 탭: 홈 / 투자 / 투자편지 / 선생님

### 2. 종목 탐색 → 종목 상세
- 탐색: 검색바 + 업종 칩 + 리스트(종목명·현재가·등락)
- 상세: 종목명·현재가·라인 차트 / 내가 가진 주식·수익률 / **아이 눈높이 설명 카드 2개**: "이 회사는 무슨 일을 해?" "최근 무슨 일이 있었어?" / **AI 투자 선생님 플로팅 버튼**(키웅이) / 하단 고정 매수(Magenta)·매도

### 3. 매수 플로우
- ① 현재가 + 수량 선택 + 예상 주문금액
- ② **"왜 사고 싶어?"** 선택 칩 5개: 앞으로 성장할 것 같아서 / 좋은 뉴스를 봐서 / 제품·서비스가 잘될 것 같아서 / 가격이 싸다고 생각해서 / 그냥 관심 있는 회사라서 + 내 생각 한 줄(선택 입력)
- ③ 매수 실행 → 완료 (컨페티, "기록 완료! AI가 기억해둘게")

### 4. 매도 플로우
- 보유수량·평가손익 → 수량 선택 → **"왜 팔려고 해?"** 칩 5개: 충분히 올랐다고 생각해서 / 앞으로 떨어질 것 같아서 / 다른 회사에 투자하고 싶어서 / 손실이 더 커질까 걱정돼서 / 기타 + 한 줄(선택) → 실행

### 5. AI 투자 선생님 (채팅)
- 키웅이 아바타 헤더 "무엇이든 물어봐!"
- 종목 맥락 카드 (대화 상단): "지금 보고 있는 종목: 삼성전자"
- 예시 질문 칩: "PER이 뭐야?" "반도체가 뭐야?" "이 회사는 어떻게 돈을 벌어?" "오늘 왜 주가가 올랐어?"
- 시연 대화: 아이 "삼성전자 지금 사도 돼?" → AI "내가 대신 정해주진 않을게. 왜 사고 싶은지 먼저 생각해볼까? 앞으로 삼성전자가 잘될 것 같은 이유가 뭐야?"

### 6. 주간 투자편지 (세로 스크롤 스토리)
- 인트로: 키웅이 + "이번 주 우리 가족 투자편지가 도착했어요 💌"
- **개인 리포트**: 유형 카드 — "이번 주 민지는 **뉴스 사냥꾼형**!" / 지표 요약(관심 업종·투자 빈도·포트폴리오 구성·수익률) / 잘한 점·놓친 점 각 1~2개
- **가족 비교**: 민지|엄마 나란히 카드
- **가족 투자궁합**: 큰 % 숫자 "76%" + "민지는 '앞으로 잘될까?'를 많이 생각했고, 엄마는 '지금 잘하고 있을까?'를 더 많이 확인했어요"
- CTA: "가족 투자토크 하러 가기" (Magenta)

### 7. 가족 투자토크
- 질문 카드: "인기는 많은데 아직 돈을 못 벌고 있는 회사라면 우리 가족은 투자할까?"
- 내 답변 입력 → 제출 → 대기: "엄마가 아직 답을 안 썼어요 🔒"
- 동시 공개 뷰: 두 답변 나란히 + AI 정리 카드("아이는 미래 성장 가능성을, 부모는 현재 수익성을 더 중요하게 봤어요. 다음엔 인기+실제 수익을 함께 확인해보세요.")
- 다음 주 미션 카드

### 8. (플로우만) 가족리그 개설 4스텝
부모: 리그 만들기 → 자녀 초대(코드) → 자녀 수락+법정대리인 동의 → 프리셋 선택(입문형: 한 종목 최대 30% / 성장형: 40%) → 가상금 1,000만 원 지급 완료

## 화면 간 연결

```
홈 → 종목 탐색 → 상세 → 매수/매도(+이유 기록) → 홈
홈/상세 → AI 선생님
홈(편지 배너) → 투자편지 → 투자토크 → (완료) 홈
```

## 산출물 요청

- 화면별 모바일 와이어프레임. lo-fi여도 **카피·수치는 위 예시 그대로** ("76%", "뉴스 사냥꾼형", 실제 질문 문구) — 발표 목업으로 바로 쓸 수 있게.
- 자녀 뷰 기준 우선, 홈만 부모 뷰 변형 1장 추가.
