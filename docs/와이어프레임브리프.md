# 와이어프레임 브리프 — 영웅 키움

> 이 문서만 보고 와이어프레임을 그릴 수 있는 자기완결 브리프. 원본: `docs/영웅키움_기획_통합문서_v2.md` v2.6(제품 마스터) §9·§10·§11·§12·§16·§17. 기능 구현 상세는 각 `web/features/*/SPEC.md`를 따른다.
> 갱신: 2026-08-11 — F10 선제 도움 신호 유형 3종과 챗봇 사용자 흐름을 통합문서 v2.6 및 기능 `SPEC.md` 기준으로 동기화.

## 서비스 한 줄

부모와 자녀(초등 고학년)가 **각자의 가상 지갑으로 모의투자**하고, AI가 그 행동을 읽어 **성장 기록**으로 돌려주는 가족형 리그. 막히는 순간엔 눈높이 챗봇 **키웅이**가 옆에 있다.

## 디자인 규칙 (강제)

- **폼팩터**: 모바일 390×844. 영웅문S# 증권앱 안의 신규 메뉴라는 설정.
- **컬러**: Deep Navy `#001E5A`(헤더·핵심 정보·주요 카드) / Magenta `#D70082`(CTA·선택 상태·강조) / Light Gray `#BEBEBE`(배경·구분선·비활성) / Base White. — 키움증권 공식 키컬러.
- **증권앱 관례 (영웅문 친숙함 — 절대 어기지 말 것)**:
  - 등락 색상: **상승/수익 = 빨강 `#E8322E`, 하락/손실 = 파랑 `#1668DC`** (국내 증권앱 표준. 해외식 초록/빨강 금지)
  - 구조: 네이비 헤더 + 흰 바탕 콘텐츠
  - 숫자: 가격·수익률은 고정폭(tabular) 느낌으로 크고 명확하게, 등락엔 ▲▼ 기호 병용
- **톤**: 위 골격 위에 금융앱스럽지 않은 살 — 큰 라운드 카드, 친근한 말투(자녀 화면 해요체 "~해볼까요?", 부모 화면 존댓말). 별·말풍선·스티커·컨페티 포인트.
- **캐릭터**: **키웅이(곰)** = 챗봇 아바타, 전 화면 우하단 플로팅. 와이어프레임에선 원형 플레이스홀더+이름 라벨. **영웅이(소)** = 포스터·보조 그래픽 전용, 앱 화면엔 등장하지 않는다.
- **듀얼 뷰**: 상단에 데모용 계정 전환 스위치(민지 ↔ 엄마). 부모 뷰는 별도 화면이 아니라 같은 화면의 전환 상태다.
- **AI 카피 원칙**: "사라/팔아라/오를 것/목표가/손절가" 류 전면 금지, 훈계·정답 금지. 챗봇은 **자유 입력창이 있다**(v5의 '자유 입력 없음'은 폐기). 추천 요구는 고정 거절 문구로 받는다.
- **데모 시점**: 4주 시즌 중 **3주차**. 모든 화면에 2주치 축적 데이터가 이미 있는 상태로 그린다 (빈 화면 금지).

## 화면 목록 (4 + 전역 1 + 플로우 2)

### 1. 홈 (자녀 뷰 / 부모 뷰)

- 네이비 헤더 + 계정 스위처(민지 ↔ 엄마)
- 시즌 진행바 **"3주차 / 4주"**
- **우리 가족 현재 순위** 카드: "우리 리그 **4위** / 42가족"
- 부모·자녀 각각 수익률 카드: 민지 ▲+3.2% / 엄마 ▲+1.8%
- **내 포트폴리오 요약**: 보유종목 3 · 평가손익 ▲+32,000원 · 현금 412,000원
- 모의투자 바로가기 CTA (Magenta)
- 아카이브 바로가기 배너: **"이번 주 성향 리포트가 나왔어요!"**
- 시즌 리워드 안내 카드 (가족 숙박권·Robux 아이콘)
- **부모 뷰 전용**: 로보마켓 프리미엄 체험권 배너 + 코칭 알림 1종 *"차단하기보다 투자 이유를 먼저 물어보시겠습니까?"*
- 첫 진입 튜토리얼 코치마크 3장: ① 홈 구성·순위 ② 매매 진입 ③ **키웅이 소개** — "궁금한 건 언제든 키웅이한테 물어봐" (오버레이 1장만 와이어프레임)
- 하단 탭 3개: **홈 / 투자 / 아카이브** (v5의 '펫' 탭 삭제)
- 우하단 플로팅 키웅이 버튼 (전 화면 공통)

### 2. 종목 탐색 → 종목 상세

- **탐색**: 검색바 + 업종 칩 + 리스트(종목명·현재가·등락). 유니버스는 국내 우량주 51종.
- **상세**: 종목명·현재가·라인 차트 / 내가 가진 주식·수익률 / **아이 눈높이 설명 카드 2개** — "이 회사는 무슨 일을 해요?" "최근 무슨 일이 있었어요?" / 하단 고정 매수(Magenta)·매도
- 챗봇 추천 칩(시트 열었을 때, 이 화면 맥락): "이 회사는 뭐 하는 회사야?" / "PER이 뭐야?" / "차트 보는 법 알려줘"

### 3. 주문 — 매수 (질문식 매매 **3탭** 내장, 스킵 불가)

- **① 수량·금액**: 금액 단위 입력 지원("10만원어치" → 수량 자동 계산) + 예상 주문금액 + 수수료·세금 실제 수준 안내 문구 + "매도 후 30분 재매수 제한" 안내
- **② 근거 태깅**(필수, 1탭) — **"왜 사고 싶어?"** 칩 5개: 뉴스에서 봤어 / 차트가 좋아 보여 / 친구·가족이 추천했어 / 이 회사(제품)를 잘 알아 / 그냥 느낌이 좋아
- **③ 확신도**(필수, 1탭) — **"키웅이가 궁금해해요 — 얼마나 자신 있어요?"** 4단계 탭 버튼: 😕 잘 모르겠어요 / 🙂 조금 / 😄 꽤 / 🤩 완전. 슬라이더 아님. 캡션 **"정답은 없어요!"** 병기
- **④ 예상 보유기간**(필수, 1탭) — **"얼마나 갖고 있을 생각이야?"** 3개: 이번 주만 / 시즌 끝까지 / 모르겠어요 *(v2 신설 — 속도 축·계획-행동 일치 분석의 재료)*
- **⑤ 내 생각 한 줄** (선택 입력)
- **⑥ 체결 완료**: 컨페티 + **"기록 완료! 키웅이가 기억해둘게요"**
- **선제 발화 오버레이 (같은 화면 변형 1장)**: 매수·매도 확인창에서 취소가 번갈아 3회 반복되면 키웅이 말풍선 **"매수와 매도가 헷갈려?"** + 카드 2장 `[직접 질문] [괜찮아]`. 신호 유형은 이 항목·5분 초과 체류·손실 실현 종목 반복 조회의 3종만 사용한다.

### 3-b. 주문 — 매도

- 보유수량·평가손익 → 수량 선택 → **"왜 팔려고 해?"** 칩 5개: 목표한 만큼 올랐어 / 더 떨어질까 봐 걱정돼 / 다른 종목이 더 좋아 보여 / 그냥 불안해 / 기타 + 한 줄(선택) → 실행
- 매도엔 확신도·보유기간을 묻지 않는다.

### 4. 아카이브 (탭 4개)

1. **성향 리포트** (주간, 각자)
   - 유형 라벨 카드: **"이번 주 민지는 재빨리 개척자형!"** (기간 표기 — 고정 낙인 방지)
   - **성향 5축 게이지 5개** (각 0~100, 양끝 라벨 병기 — 우열 없음):
     집중–분산 `한우물형 ↔ 골고루형` / 속도 `진득이형 ↔ 재빨리형` / 신중함 `직진형 ↔ 돌다리형` / 손실 대응 `버티기형 ↔ 갈아타기형` / 탐험심 `익숙함형 ↔ 개척자형`
   - 근거 태깅 분포 (뉴스 40% · 느낌 30% …) + 확신도 패턴 ("확신 낮은 매수 2번")
   - LLM 서술 블록: 스타일 요약 2~3문장 + 잘한 점·아쉬운 점 각 1~2개 (관찰 톤)
   - 캡션 **"정답은 없어요!"** 상시 병기
2. **수익률**: 수익률 추이 라인 + 보유·평가손익 (숫자만, AI 서술 없음)
3. **가족 비교**: 두 사람 5축 **막대 병치** + 중립 서술 1줄 — *"민지는 재빨리, 엄마는 진득하게. 스타일이 달라요."* 상단에 "양쪽이 공개에 동의했어요" 표기
4. **시즌 기록**: 시즌 초 ↔ 3주차 5축 비포/애프터 + 수익률 결산 + 시즌 말 목업 카드 1장
   - **부모 뷰에서만**: 친화도 스코어 추이 그래프 + 캡션 *"시뮬레이션 데이터입니다"* — 자녀 뷰엔 이 수치를 절대 노출하지 않는다

### 전역. 플로팅 챗봇 키웅이 (와이어프레임 4장)

- **(a) 닫힘**: 우하단 원형 버튼(키웅이 얼굴). 모든 화면 위에 떠 있다.
- **(b) 열림**: 바텀시트 챗 UI — 첫 인사 + **화면 맥락 기반 추천 질문 칩 3개** + 대화 영역 + 자유 입력창 + 상시 고지 **"키웅이는 AI 도우미야"**
  - 답변 위에 **처리 상태 타임라인 칩**: `무슨 질문인지 보는 중` → `기록 찾는 중` → `안전 점검 통과!` — 모델의 내부 사고과정이 아니라 수작성 상태 문구다.
  - 답변 아래에는 기본적으로 `계속 질문`을 유지하고, 필요한 경우에만 허용 목록의 `[관련 화면 보기]` 버튼 1개를 제안한다. 화면 이동은 사용자 탭 후 실행한다.
- **(c) 고정 거절**: 사용자 "뭐 사면 돼?" → **"종목은 내가 골라줄 수 없어! 대신 고를 때 뭘 보면 좋은지 알려줄게 🐻"**
- **(d) 선제 발화**: 시트가 닫힌 상태에서 키웅이 옆에 상황 설명이 포함된 고정 말풍선 + 카드 2장 `[직접 질문] [괜찮아]`. LLM은 호출하지 않는다.

### 플로우 A. 온보딩 — 가족 팀 결성 (플로우 와이어프레임만, 데모는 완료 상태로 시작)

부모 영웅문S# 로그인 → **[가족 팀 만들기]** → 자녀 명의 미성년 계좌 조회
→ **있음**: 바로 연결 / **없음**: 키움 미성년 비대면 개설 플로우로 안내 후 복귀
→ 가족 초대 코드 발급 → 자녀가 코드로 합류 (가입·개인정보 동의는 **부모 화면 안 법정대리인 동의**)
→ 프리셋 선택 (입문형: 단일종목 ≤30% / 성장형: ≤40%)
→ **1인당 가상 100만원** 지급 → 시즌 개막 대기

### 플로우 B. 시즌 결산 카드 1장 (발표 슬라이드용, 앱 구현 대상 아님)

5축 비포/애프터 + 친화도 추이 + 수익률 결산 + 시상 3종(🏆 가족 종합 / 🧒 개인 / 🧭 행동 부문)을 한 장에.

## 화면 간 연결

```
홈 → 투자(탐색) → 종목 상세 → 매수(수량→근거→확신도→보유기간→체결) → 홈
                            └→ 매도(수량→근거→실행) → 홈
홈/상세/주문/아카이브 (전 화면) → 플로팅 키웅이 → 바텀시트 → 닫기/관련 화면 보기/계속 질문
확정 신호 3종 감지 → 키웅이 고정 말풍선 → [직접 질문]이면 바텀시트 / [괜찮아]면 해당 신호 세션 뮤트
홈 → 아카이브 → [성향 리포트 / 수익률 / 가족 비교 / 시즌 기록]
```

## 산출물 요청

- 화면별 모바일 와이어프레임. lo-fi여도 **카피·수치는 위 예시 그대로** ("키웅이", "재빨리 개척자형", 확신도 4단계 문구, 선제 발화 문구) — 발표 목업으로 바로 쓸 수 있게.
- 자녀(민지) 뷰 기준 우선. 홈과 아카이브 시즌 기록은 부모 뷰도 함께.
- 챗봇은 닫힘/열림/거절/선제발화 4장 전부 필요 — 안전 구조가 발표의 증거다.
