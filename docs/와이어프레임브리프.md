# 와이어프레임 브리프 — 키움 가족 모의투자 리그

> 이 문서만 보고 와이어프레임을 그릴 수 있는 자기완결 브리프. (원본: `기획서.md` v5, `기능명세.md` v4, `펫서비스기획.md`)

## 서비스 한 줄

부모와 자녀(초등 고학년~중학생)가 **각자 모의투자**를 하고, 그 행동을 관찰한 **가족 공동 AI펫**이 두 사람의 투자 생각을 이어주는 가족형 리그. 리듬: "평일에는 각자 투자하고, 우리 가족의 생각은 펫이 이어준다."

## 디자인 규칙 (강제)

- **폼팩터**: 모바일 390×844. 영웅문S# 증권앱 안의 가족대회 전용 UX라는 설정.
- **컬러**: Deep Navy `#001E5A`(헤더·핵심 정보·주요 카드) / Magenta `#D70082`(CTA·선택 상태·강조) / Light Gray `#BEBEBE`(배경·구분선·비활성) / Base White. — 키움증권 공식 키컬러.
- **증권앱 관례 (영웅문 친숙함 — 절대 어기지 말 것)**:
  - 등락 색상: **상승/수익 = 빨강 `#E8322E`, 하락/손실 = 파랑 `#1668DC`** (국내 증권앱 표준. 해외식 초록/빨강 금지)
  - 구조: 네이비 헤더 + 흰 바탕 콘텐츠 (증권앱 기본 골격)
  - 숫자: 가격·수익률은 고정폭(tabular) 느낌으로 크고 명확하게, 등락엔 ▲▼ 기호 병용
- **톤**: 위 골격 위에 금융앱스럽지 않은 살 — 큰 라운드 카드, 친근한 말투(자녀 화면 반말 "~해볼까?", 부모 화면 존댓말). 별·말풍선·스티커·컨페티 포인트.
- **펫**: 가족 공동 AI펫 1마리 — 데모 이름 "통통이"(교체 가능). 와이어프레임에서는 원형 플레이스홀더+표정 라벨(예: 🙂 좋음 / 🤔 갸우뚱 / ☀️ 밝음 / 😔 시무룩). 홈·펫 화면·오늘의 순간 카드에 등장.
- **듀얼 뷰**: 상단에 데모용 계정 전환 스위치(민지 ↔ 엄마).
- **AI 카피 원칙**: 펫이 말하는 문구에 "사라/팔아라/오를 것" 류 금지, 훈계·정답 금지 — 항상 되묻기 또는 선택지로 마무리. 펫에게 자유롭게 말을 거는 입력창은 **없다** (자유 입력 없음 확정).

## 화면 목록 (7 + 개설 플로우 + 성장기록 목업)

### 1. 홈 (자녀 뷰 / 부모 뷰)
- **펫 "통통이" 상주** (헤더 아래, 표정 = 컨디션. 탭하면 화면 5로)
- 첫 진입 튜토리얼 코치마크 3장: ① 홈 구성·순위 ② "얘는 우리 가족이 함께 키우는 통통이야" ③ 매매 진입 (오버레이 1장만 와이어프레임)
- 시즌 진행바 "4주차 / 8주"
- **우리 가족 현재 순위** 카드 (예: "12위 / 340가족")
- 부모/자녀 각각 수익률 카드 (민지 +3.2% / 엄마 +1.8%)
- 모의투자 바로가기 CTA (Magenta)
- 주간 질문 예고 배너: "통통이가 토요일에 우리 가족 질문을 가져와요!"
- 시즌 리워드 안내 카드 (가족 숙박권·Robux 등 아이콘)
- 부모 뷰 전용: **오늘의 순간 카드**(화면 6 요약형) + 로보마켓 프리미엄 체험권 배너
- 하단 탭: 홈 / 투자 / 펫 / 아카이브

### 2. 종목 탐색 → 종목 상세
- 탐색: 검색바 + 업종 칩 + 리스트(종목명·현재가·등락)
- 상세: 종목명·현재가·라인 차트 / 내가 가진 주식·수익률 / **아이 눈높이 설명 카드 2개**: "이 회사는 무슨 일을 해?" "최근 무슨 일이 있었어?" / 하단 고정 매수(Magenta)·매도
- (오래 머물면 펫이 구석에서 갸우뚱하는 상태 변화 — 와이어프레임에선 코너 펫 아이콘+🤔 표기)

### 3. 매수 플로우 (질문식 매매)
- ① 현재가 + 수량 선택 + 예상 주문금액
- ② **"왜 사고 싶어?"** 근거 칩 5개: 뉴스에서 봤어 / 차트가 좋아 보여 / 친구·가족이 추천했어 / 이 회사(제품)를 잘 알아 / 그냥 느낌이 좋아 + 내 생각 한 줄(선택 입력)
- ③ **확신도**: 펫이 묻는 프레이밍 — "통통이가 궁금해해. 얼마나 자신 있어?" 4단계 탭 버튼: 😕 잘 모르겠어 / 🙂 조금 / 😄 꽤 / 🤩 완전 (정답·점수 없음 캡션: "정답은 없어!")
- ④ 매수 실행 → 완료 (컨페티, "기록 완료! 통통이가 기억해둘게")
- ⑤ **펫 리액션** (확신도 '잘 모르겠어' 선택 시): 통통이 🤔 + 말풍선 배지 → 열면 "확신이 낮아 보이는데, 이유가 있어?" + 선택지 3개(뉴스가 헷갈려서 / 그냥 사보고 싶어서 / 다시 생각해볼래)

### 4. 매도 플로우
- 보유수량·평가손익 → 수량 선택 → **"왜 팔려고 해?"** 칩 5개: 목표한 만큼 올랐어 / 더 떨어질까 봐 걱정돼 / 다른 종목이 더 좋아 보여 / 그냥 불안해 / 기타 + 한 줄(선택) → 실행

### 5. 펫 화면 (가족 공동)
- 통통이 크게 (레벨 2 · 컨디션 ☀️ 좋음) + "우리 가족이 함께 키우는 통통이"
- **감지 순간 말풍선 목록** (최근 순): "확신이 낮아 보이는데, 이유가 있어?" (열람/응답 상태 표시)
- **투명성 표시**: "통통이가 오늘 엄마한테 물어다 준 이야기 1개" (민지 뷰에도 동일 노출)
- **주간 질문 카드**: "어떤 기준으로 종목을 골랐어?" → 내 답변 입력 → 제출 → 대기 "엄마가 아직 안 썼어요 🔒" → **둘 다 답하면 동시 공개** (두 답변 나란히 + 펫 정리: "민지는 새로움을, 엄마는 익숙함을 골랐네!")
- 성장 게이지: "이번 주 우리 가족 소통 +3 → 통통이가 밝아졌어요 ☀️"

### 6. 부모 '오늘의 순간' (부모 뷰)
- 펫이 카드를 물어오는 연출: "통통이가 오늘의 순간을 가져왔어요"
- 카드: "오늘 민지가 확신이 낮은데도 ○○전자를 샀어요. 이유는 '그냥 느낌이 좋아서'래요."
- 대화 제안 1줄: "'어떤 느낌이었어?'라고 물어보시는 건 어떨까요?" (존댓말)
- 하단: "민지 화면에도 이 카드가 표시됩니다" 안내 (투명성 원칙)

### 7. 아카이브
- 탭 3개: 성향 리포트 / 수익률 / 가족 성장기록
- **성향 리포트** (민지): 유형 카드 "이번 주 민지는 **뉴스 사냥꾼형**!" / 근거 태깅 분포(뉴스 40%·느낌 30%…) / 확신도 패턴("확신 낮은 매수 2번") / 잘한 점·놓친 점 각 1~2개
- **수익률**: 수익률 추이 라인 + 보유·평가손익 (숫자 중심, AI 서술 없음)
- **가족 성장기록**: 시즌 초↔4주차 비교 지표 4개(근거 구체성 / 업종 다양성 / 확신도-행동 일치 / 주간 질문 참여) + **펫 비포/애프터** (Lv.1 😐 → Lv.2 ☀️) + 시즌 말 완성본 목업 카드 1장

### 8. (플로우만) 가족리그 개설 + 펫 작명
부모: 리그 만들기 → 자녀 초대(코드) → 자녀 수락+법정대리인 동의 → 프리셋 선택(입문형: 한 종목 최대 30% / 성장형: 40%) → 가상금 1,000만 원 지급 → **부모·자녀가 함께 펫 이름 짓기** (첫 공동 행위 — 입력 필드 하나에 두 아바타가 같이 있는 연출)

## 화면 간 연결

```
홈 → 종목 탐색 → 상세 → 매수/매도(근거+확신도) → [펫 리액션] → 홈
홈(펫 탭) → 펫 화면 → 주간 질문 → 동시 공개 → (완료) 홈
부모 홈 → 오늘의 순간 → (권장) 주간 질문 답변
홈/펫 → 아카이브
```

## 산출물 요청

- 화면별 모바일 와이어프레임. lo-fi여도 **카피·수치는 위 예시 그대로** ("통통이", "뉴스 사냥꾼형", 확신도 4단계 문구, 오늘의 순간 카드 문구) — 발표 목업으로 바로 쓸 수 있게.
- 자녀 뷰 기준 우선, 홈·오늘의 순간은 부모 뷰 포함.
- 시즌 말 가족 성장기록 목업 카드 1장 (§7 — 앱 구현 대상 아님, 발표 슬라이드용).
