# 이재용 — AI 명령 프롬프트 가이드 (통합 오너 · 게임 룰 엔진)

> 이 문서를 Claude/Codex에 그대로 복사·붙여넣기 해서 쓴다.

## 0. 사용법

1. 새 대화에서 §1 온보딩을 한 번 보낸다.
2. AI가 "읽었음"이라고 요약하면 §3에서 지금 할 작업 블록을 보낸다.
3. AI가 계획을 제시하면 이상 없을 때 "진행해"라고 한다.
4. 만들면 §5 자가검증을 보낸다.

## 1. 온보딩 프롬프트 (대화 시작 시 1회)

```
너는 "물려주는 계좌 — 영웅문 주니어"의 개발을 돕는다. 나는 이재용, 통합 오너이자
전략시뮬게임 룰 엔진 담당이다. 설명은 쉽고 명확하게.
먼저 아래 파일을 읽고 "읽었음"과 함께 ① 내가 할 일 ② 지금 미완인 것 ③ 꼭 지킬 핵심 규칙을
정리해줘. 아직 만들지 마.
읽을 파일: 1.CLAUDE.md 2.docs/team/_공통_AI규칙.md(헌장) 3.docs/team/이재용/이재용-담당업무.md
4.docs/mvp-backlog.md 5.docs/game-design.md
환경: 게임 테스트는 game 폴더에서 npm test / npm run sim. 작업 폴더: game/src, game/tests + 루트 진입점 문서.
```

## 2. 고정 규칙

```
[고정 규칙]
1. 룰은 game/src에만 쓴다. game/ui는 엔진을 import만 한다 — 룰 재구현 금지.
2. 수치·룰을 바꾸면 npm test → npm run sim 순으로 돌리고, docs/game-design.md 11절 스냅샷을 갱신한다.
3. 교육 메시지 3종(분산>몰빵, 정직>불법, 시그널활용>무시)이 sim에서 역전되면 그 변경은 되돌린다.
4. 백로그에 없는 기능을 추가하지 않는다. 필요하면 백로그에 제안으로 적고 나에게 확인받는다.
5. 모르는 값은 지어내지 말고 "TODO: 확인 필요" 표시.
6. 한국어 파일은 편집도구/UTF-8로만. main 직접 push 금지(브랜치→PR).
```

## 3. 작업별 명령 프롬프트

### 3-1. T5 마감 여부 판정

```
[작업] game/src/difficulty.ts와 game/ui/src의 난이도 선택 UI가 docs/mvp-backlog.md T5 요구사항을
어디까지 충족했는지 확인해줘. T5 검증 조건은 "npm run sim에 티어 매치업 추가 — 고정 기준 봇 대비
승률이 쉬움 > 보통 > 어려움 순으로 단조 감소"다.
[제약] 판정만 해라. 아직 코드를 바꾸지 마.
[검증] npm run sim 실제 실행 결과를 근거로 제시.
[산출물] 충족/미충족 항목 표 + 남은 작업 목록.
```

### 3-2. 핫스팟 겹침 감사

```
[작업] 지금 활성 세션과 열린 PR이 공유 핫스팟을 겹쳐 잡고 있는지 확인해줘.
[검증] uv run python scripts/git_session_manager.py status 실행 + gh pr list.
핫스팟 목록은 .claude/skills/git-session-manager/references/team-git-policy.md.
[산출물] 겹침 있으면 파일·세션·소유자 표. 없으면 "겹침 없음".
```

### 3-3. 공용 연결 PR

```
[작업] <팀원>이 만든 <신규 화면>을 web/app/layout.tsx의 내비게이션에 연결해줘.
[제약] 신규 화면 파일 자체는 수정하지 않는다 — 연결만. 다른 트랙 파일도 건드리지 않는다.
[검증] cd web; npm run typecheck.
[산출물] 계획 먼저 → "진행해" 하면 구현.
```

## 4. 막히면 그대로 보내기

- 한 번에 하나: `지금은 [이것]만 하자. 다른 건 건드리지 마.`
- 가짜 값 방지: `이 값 추측이야 근거 있어? 추측이면 TODO로 바꿔줘.`
- 검증: `방금 만든 걸 실제로 실행해서 결과를 보여줘.`

## 5. 자가검증 프롬프트 (PR 전)

```
방금 만든 걸 점검하고 표로 보고해줘 (실제로 실행/테스트해서):
1. game/ui나 web/에 룰을 재구현하지 않았나?
2. npm test, npm run sim 결과가 뭔가? 교육 메시지 3종 유지됐나?
3. 수치가 바뀌었으면 docs/game-design.md 11절 스냅샷을 갱신했나?
4. 백로그 범위 밖 기능을 넣지 않았나?  5. 한국어 안 깨졌나?
아니오가 있으면 고친 뒤 다시 보고해.
```
