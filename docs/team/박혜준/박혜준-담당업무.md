# 박혜준 — 담당업무 (뉴스 · 수집과 눈높이 번역 파이프라인)

## 1. 역할

경제 뉴스를 **아이가 읽을 수 있는 형태로 바꿔서 저장**하는 뒤쪽 절반을 담당한다.
화면은 강소정이 만든다.

## 2. 이 기능이 왜 있나

기획안 §1의 조사 결과: 초등 학부모 69%가 "경제교육 중"이라고 답하지만 내용은 저축 습관(65.8%)·
용돈 관리(50.1%)에 몰려 있고 **경제뉴스는 14.1%, 투자는 6.2%로 급락**한다.
아이가 세상과 자기 주식을 연결할 통로가 없다.

기획안 §5의 "판단 근거 유형"에 **뉴스형**이 들어 있다. 아이가 제안서에 "뉴스에서 봤는데"라고
쓸 수 있으려면 먼저 읽을 뉴스가 있어야 한다. 이 트랙은 제안서 트랙의 입력을 만든다.

## 3. 반드시 지킬 제약 — 런타임 LLM 금지

헌장 §1: **아이에게 나가는 텍스트를 런타임 LLM으로 생성하지 않는다.** 미성년 대상 투자권유 리스크다.
그런데 "눈높이 번역"은 본질적으로 LLM 작업이다. 충돌을 이렇게 푼다.

```
[배치·오프라인]  원문 수집 → LLM 눈높이 번역 → 사람 검수 → DB 저장
[런타임]         저장된 검수 완료 문구만 서빙. 요청 시점에 LLM 호출 없음
```

**아이 화면에 뜨는 문장은 전부 사람이 한 번 본 문장이어야 한다.** 검수 안 된 항목은 노출하지 않는다.

## 4. 작업 경로

| 경로 | 내용 |
|---|---|
| `web/lib/news/` | 수집·번역·검수 상태 로직 |
| `web/app/api/news/` | Route Handler — 검수 완료 뉴스 목록·상세 |
| `web/scripts/` 내 뉴스 배치 | 수집·번역 배치 (파일명은 `news-` 접두어로) |

`web/lib/db.ts`(스키마)는 핫스팟이다. 뉴스 테이블을 추가하려면 이재용에게 계약 PR을 요청한다.

- **뉴스 소스** — NAVER 검색 API / 언론사 RSS / 키움 제공 뉴스 중 무엇인가. 라이선스와

  매핑하면 "네가 가진 삼성전자 뉴스"가 가능해지고, 제안서와 직접 연결된다.

## 6. 경계

- `web/app/kid/news`(화면)는 강소정 경계다. 나는 API 계약까지 만들고 넘긴다.
- `web/lib/rules.ts`·`kiwoom.ts`·`stocks.ts`·`llm.ts`는 실제투자 트랙 경계다. 읽기만 한다.
- `game/`은 다른 트랙이다.

## 7. 검증

```powershell
cd web; npm run typecheck
cd web; npm test
cd web; npm run dev        # 별도 터미널
cd web; npm run verify     # 기획안 조항 검증
```

**뉴스 기능을 추가할 땐 `web/scripts/verify.ts`에 체크를 먼저 쓰고 구현한다.**
최소한 "검수 안 된 뉴스는 API가 반환하지 않는다"는 체크가 있어야 한다.
