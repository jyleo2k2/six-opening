# 이호연 — 담당업무 (전략시뮬게임 화면)

## 1. 역할

주식 카드 배틀의 **화면 전부**를 담당한다. 세로 430px 기준 모바일 UI로, 아이가 1분 안에
첫 턴을 스스로 진행할 수 있어야 한다.

룰은 `game/src` 엔진이 전부 갖고 있다. 화면은 엔진 함수를 호출하고 결과를 그리기만 한다.
**엔진 룰을 화면에서 다시 구현하면 밸런스 검증 루프가 통째로 무너진다.**

## 2. 작업 경로

| 경로 | 내용 |
|---|---|
| `game/ui/src/useMatch.ts` | 매치 진행 훅 — 엔진 호출 순서를 `runGame`과 동일하게 유지 |
| `game/ui/src/App.tsx` | 화면 전부 (핫스팟 — 큰 조립 루트라 나 혼자 쓴다) |
| `game/ui/src/cardMeta.ts` | 카드 효과 문구 (엔진 config에서 파생) |
| `game/ui/src/eventMessages.ts` | `GameEvent` → 한 줄 한국어 피드백 |
| `game/ui/src/progression.ts` | 별점·골드·랭크·localStorage 영속 |
| `game/ui/src/styles.css` | 스타일 |
| `game/ui/scripts/*.mjs` | Playwright 검증 스크립트 |

## 3. 지금 상태

`docs/mvp-backlog.md`가 작업 지시서다.

- T1~T4 완료 — 판정 피드백 UI, 매치 종료 정산, 멀리건 화면까지 붙어 있다.
- **T6 온보딩 (첫 판 튜토리얼)** 이 다음 UI 과제다. 현재 첫 화면에 카드·종목·에너지·뉴스가
  한꺼번에 등장해서 초등 고학년이 스스로 시작하기 어렵다.
- T9 도감 / T10 덱빌딩은 Tier 2 — Tier 1 사람 게이트 통과 후에만 착수.

## 4. 엔진과의 계약

`game/ui`가 호출하는 엔진 함수는 8개뿐이다.

```
createGame · startTurn · playCard · legalPlays · marketPhase · resolveTimeout · assets · holdingsValue
```

여기에 T4에서 `mulligan`이 추가됐다. 이 시그니처가 바뀌어야 하면 **이재용에게 계약 PR을 먼저
요청하고**, 병합된 뒤에 화면을 고친다. 내가 `game/src`를 직접 고치지 않는다.

`@engine/*` alias가 `game/src/*`를 가리킨다(`game/ui/vite.config.ts`, `tsconfig.json`).

## 5. 경계

- `game/src`는 이재용 경계다. 룰·밸런스 수치를 화면에서 바꾸지 않는다.
- `web/`은 다른 트랙이다. 읽기만 한다.
- `docs/game-design.md`·`docs/mvp-backlog.md`는 핫스팟 — 고칠 땐 이재용과 조율한다.

## 6. 검증

```powershell
cd game/ui; npm run build          # tsc --noEmit + vite build
cd game/ui; npm run dev            # 별도 터미널
cd game/ui; npm run e2e            # 1판 완주 스모크
cd game/ui; npm run verify:t2      # 판정 피드백
cd game/ui; npm run verify:t3      # 매치 종료 정산
cd game/ui; npm run verify:t4      # 멀리건
```

Vite dev 서버가 IPv6(`::1`)에만 바인딩될 수 있다. e2e가 `127.0.0.1`을 거부하면
`$env:E2E_URL = "http://localhost:5178/"`를 지정하고 실행한다.

**UI를 바꿨으면 위 verify 스크립트가 전부 그린이어야 PR을 올린다.**
