# 강소정 — 담당업무 (뉴스 · 아이 화면)

## 1. 역할

아이가 뉴스를 읽는 **화면 전부**를 담당한다. 데이터는 박혜준이 만든 API에서 받는다.

## 2. 이 화면이 지켜야 할 것

기획안이 아이 화면에 대해 못 박은 원칙들이 뉴스에도 그대로 적용된다.

- **아이 화면의 언어는 아이 언어다.** 기획안 3-3의 예시처럼 "삼성전자 3주 = 네 폰을 만든 회사,
  지금 자전거 1대 값" 수준으로 내려온다. 어른용 경제 기사 톤을 그대로 쓰지 않는다.
- **읽고 끝나면 안 된다.** 뉴스는 제안서로 가는 통로다. 기사를 읽은 뒤 **"이거 사고 싶어?"**로
  제안서 작성에 연결되는 동선이 있어야 한다(기획안 §5 판단 근거 유형 "뉴스형").
- **투자 권유로 읽히면 안 된다.** "이 종목이 오를 것"류 표현이 화면에 뜨지 않는다.
  뜬다면 그건 데이터 쪽 문제이므로 박혜준에게 넘긴다.
- 화면에 뜨는 문장은 **전부 검수 완료된 저장 문구**다. 화면에서 텍스트를 가공·생성하지 않는다.

## 3. 작업 경로

| 경로 | 내용 |
|---|---|
| `web/app/kid/news/` | 뉴스 목록·상세 화면 |
| `web/app/kid/news/*.module.css` 또는 인라인 | 화면 스타일 |

화면은 `"use client"`로 두고 데이터는 `web/app/api/news`에서 fetch한다.
모션은 `motion`, 바텀시트는 `vaul`, 토스트는 `sonner`를 쓴다(`web/AGENTS.md`).

## 4. 경계

- **`web/app/layout.tsx`는 핫스팟이다.** 내비게이션에 뉴스 탭을 붙이는 일은 이재용이 별도 PR로 한다.
  나는 `web/app/kid/news` 아래 신규 파일만 만들고, 연결이 필요하면 PR 본문에 적는다.
- `web/lib/news`·`web/app/api/news`는 박혜준 경계다. API 응답 모양이 부족하면 직접 고치지 말고
  박혜준에게 요청한다.
- `web/app/kid`의 다른 화면(홈·제안서·카드앨범)은 실제투자 트랙 경계다.
- 제안서로 연결하는 동선은 **링크만 건다.** 제안서 화면 자체는 김경렬 경계다.

## 6. 검증

```powershell
cd web; npm run typecheck
cd web; npm run dev        # 별도 터미널
cd web; npm run verify
```

화면 작업은 타입체크로 다 못 잡는다. **dev 서버에 띄워서 실제로 눌러보고 스크린샷으로 확인한다.**
430px 세로 기준에서 텍스트가 겹치거나 잘리지 않는지 본다.
