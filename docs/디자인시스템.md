# 디자인 시스템 — 통일성 강제 규칙 (전 화면 공통)

와이어프레임·구현 전 단계에 적용. 위반 = 리뷰 반려. 원본 근거: `영웅키움_기획_통합문서_v2.md` v2.6 §12-C·§16, `와이어프레임브리프.md`.

## 1. 컬러 토큰 (이 8개 외 임의 색 금지)

| 토큰 | 값 | 용도 |
|---|---|---|
| `navy` | `#001E5A` | 헤더, 핵심 정보, 주요 카드 배경 (키움 키컬러) |
| `magenta` | `#D70082` | CTA 버튼, 선택 상태, 강조 포인트 (키움 키컬러) |
| `gray` | `#BEBEBE` | 구분선, 비활성 |
| `bg` | `#F6F7FA` | 화면 배경 (흰 카드가 뜨도록) |
| `white` | `#FFFFFF` | 카드·콘텐츠 배경 |
| `up` | `#E8322E` | **상승·수익 (빨강 — 국내 증권앱 관례)** |
| `down` | `#1668DC` | **하락·손실 (파랑)** |
| `ink` | `#1A2233` | 본문 텍스트 |

- 등락색 반전(해외식 초록/빨강) **절대 금지**. 수익률·등락엔 반드시 `up`/`down` + ▲▼ 기호.
- Tailwind config에 위 토큰만 등록하고 임의 hex 사용을 리뷰에서 걸러낸다.

## 2. 레이아웃·형태

- 모바일 390px 기준, max-width 430px 중앙 정렬. 데스크톱 대응 안 함 (폰 프레임 데모).
- 골격: **네이비 헤더 + 밝은 배경 + 흰 카드** (증권앱 구조 = 영웅문 친숙함).
- 카드 라운드 16px, 버튼 라운드 12px, 칩 라운드 999px. 그림자는 연하게 1단계만.
- 하단 탭바 3개 고정: 홈 / 투자 / 아카이브. 주문은 탭이 아니라 종목 상세에서 진입한다.
- 상단에 데모용 계정 스위처(민지↔엄마) 상시 노출. 우하단에 플로팅 챗봇 버튼(키웅이 얼굴) 상시 노출.

## 3. 타이포·숫자

- 폰트: Pretendard 로드, 폴백 `'Segoe UI','Malgun Gothic',sans-serif`.
- 가격·수익률 숫자는 `font-variant-numeric: tabular-nums`, 본문보다 크고 굵게.
- 위계: 화면 제목 18~20 bold / 카드 제목 15~16 semibold / 본문 14 / 캡션 12.

## 4. 말투 (카피 규칙)

- 자녀(민지) 뷰: **해요체 + 다정** ("~해볼까요?", "기록 완료! 키웅이가 기억해둘게요")
  - 말끝은 `~예요`·`~해요`·`~하면 돼요`로 맺는다. **`~합니다`체와 `~하세요` 지시체는 금지** — 딱딱하거나 훈계로 들린다.
  - 예: "주주는 회사의 작은 조각을 가진 사람이에요. 주문 전에는 수량을 확인하면 돼요."
  - **입력 인식용 사전은 반말을 유지한다.** 아이는 여전히 `ㅇㅇ`·`몰라`·`오를까`처럼 반말로 친다(`shared`의 구어 사전과 라우팅 패턴).
- 부모 뷰: 존댓말 ("물어보시는 건 어떨까요?"). 챗봇은 화자를 구분하지 않으므로 부모도 자녀와 같은 해요체를 받는다 — 해요체 자체가 정중하므로 별도 분기를 두지 않는다.
- AI 문구 금지어: 사야/팔아야/매수 기회/목표가/손절가/오를 것/내릴 것/확실 — 방향성 언어 전면 금지.
- 챗봇 발화 원칙: 훈계·정답·추천 금지, 3문장 이내. 선제 도움은 확정 신호 3종의 **고정 스크립트**(LLM 미사용)가 상황을 설명하고 카드 2장 `[직접 질문] [괜찮아]`으로 끝낸다. 자유 답변은 승인된 지식 범위의 사실 설명으로 끝내며, 필요할 때만 허용 목록의 `[관련 화면 보기]` 버튼 1개를 제안한다. 화면 이동은 사용자 탭 후 실행한다. 확신도 UI엔 "정답은 없어요!" 캡션 병기.
- 유형 라벨은 "이번 주 민지는 **재빨리 개척자형**!" 형식 (기간 표기 — 고정 낙인 방지).
- 성향 5축은 양끝 라벨을 함께 적어 우열이 없음을 보인다(`진득이형 ↔ 재빨리형`). 실력 점수·등급·채점 표현 금지. 친화도 스코어 수치는 부모 뷰에만 노출한다.

## 5. 캐릭터·그래픽

- **키웅이(곰)**: 챗봇 아바타 겸 전 화면 우하단 플로팅 버튼. 선제 발화 말풍선·간단 모션을 사용하며, 에셋 확보 전에는 원형 플레이스홀더+이름 라벨로 시작한다.
- **영웅이(소)**: 포스터·발표 자료용 보조 그래픽 전용. 앱 화면에는 넣지 않는다.
- 장식은 별·말풍선·컨페티만, 화면당 1~2개 포인트. 체결 완료 순간에만 컨페티.

## 6. 컴포넌트 소유권 (`web/shared/ui/` + 기능 폴더)

현재 `web/shared/ui/index.tsx`가 실제로 내보내는 공용 컴포넌트는 `Button(primary=magenta/secondary=navy선)` · `Card` · `TabBar` · `ScreenHeader` · `PhoneShell` 5종이다. 정적 프로토타입 화면은 `web/public/ui/app.html`, 기능 전용 React UI는 해당 기능 폴더가 소유하므로 이 목록에 없는 이름을 공용 구현 완료로 간주하지 않는다.

`Chip(선택형 — 근거 태깅·보유기간·추천 질문·사고과정)` · `PriceText(등락색+▲▼ 자동)` · `ProgressBar(시즌 진행·성향 비교)` · `CoachAvatar(키웅이 — 플로팅 버튼 겸용)` · `SpeechBubble` · `BottomSheet` · `ChatComposer(텍스트 입력·종료·뮤트)` · `ConfidenceSelector(확신도 4단계 탭)` · `ConfettiBurst`는 필요 시 승격할 **공용 후보**이지 현재 `shared/ui` 계약이 아니다.

- F10의 챗봇 바텀시트는 현재 `web/features/f10-chatbot/F10ChatbotDemo.tsx`와 `lib/bottom-sheet.ts`가 소유하는 기능 전용 UI다. 렌더된 휴대폰 화면 높이의 80%, 상단 여백 탭·핸들 하향 드래그 닫기 계약은 F10 `SPEC.md`를 따른다.
- 같은 UI 계약을 실제로 쓰는 두 번째 소비자가 생기면 `web/shared/AGENTS.md`에 따라 공용 타입·구현·테스트를 먼저 정의한 뒤 `shared/ui`로 승격한다. 기능 폴더에 공용 이름의 사본을 만들지 않는다.
- 성향 비교를 공용화할 때는 `ProgressBar`를 병치한다. **레이더 차트는 만들지 않는다** (막대 병치로 충분 — 필요해지면 그때 추가).
