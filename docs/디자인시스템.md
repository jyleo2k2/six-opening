# 디자인 시스템 — 통일성 강제 규칙 (전 화면 공통)

와이어프레임·구현 전 단계에 적용. 위반 = 리뷰 반려. 원본 근거: `기획서.md` §16, `와이어프레임브리프.md`.

## 1. 컬러 토큰 (이 8개 외 임의 색 금지)

| 토큰 | 값 | 용도 |
|---|---|---|
| `navy` | `#001E5A` | 헤더, 핵심 정보, 주요 카드 배경 (키움 키컬러) |
| `magenta` | `#D70082` | CTA 버튼, 선택 상태, 강조 포인트 (키움 키컬러) |
| `gray` | `#BEBEBE` | 구분선, 비활성 |
| `bg` | `#F6F7FA` | 화면 배경 (흰 카드가 뜨도록) |
| `white` | `#FFFFFF` | 카드·콘텐츠 배경 |
| `up` | `#E8322E` | **상승·수익 (빨강 — 국내 증권앱 관례)** |
| `down` | `#1668DC` | **하락·손실 (파랑)** |
| `ink` | `#1A2233` | 본문 텍스트 |

- 등락색 반전(해외식 초록/빨강) **절대 금지**. 수익률·등락엔 반드시 `up`/`down` + ▲▼ 기호.
- Tailwind config에 위 토큰만 등록하고 임의 hex 사용을 리뷰에서 걸러낸다.

## 2. 레이아웃·형태

- 모바일 390px 기준, max-width 430px 중앙 정렬. 데스크톱 대응 안 함 (폰 프레임 데모).
- 골격: **네이비 헤더 + 밝은 배경 + 흰 카드** (증권앱 구조 = 영웅문 친숙함).
- 카드 라운드 16px, 버튼 라운드 12px, 칩 라운드 999px. 그림자는 연하게 1단계만.
- 하단 탭바 4개 고정: 홈 / 투자 / 펫 / 아카이브.
- 상단에 데모용 계정 스위처(민지↔엄마) 상시 노출.

## 3. 타이포·숫자

- 폰트: Pretendard 로드, 폴백 `'Segoe UI','Malgun Gothic',sans-serif`.
- 가격·수익률 숫자는 `font-variant-numeric: tabular-nums`, 본문보다 크고 굵게.
- 위계: 화면 제목 18~20 bold / 카드 제목 15~16 semibold / 본문 14 / 캡션 12.

## 4. 말투 (카피 규칙)

- 자녀(민지) 뷰: 반말 + 다정 ("~해볼까?", "기록 완료! 통통이가 기억해둘게")
- 부모 뷰: 존댓말 ("물어보시는 건 어떨까요?")
- AI 문구 금지어: 사야/팔아야/매수 기회/목표가/손절가/오를 것/내릴 것/확실 — 방향성 언어 전면 금지.
- 펫 발화 원칙: 훈계 금지·정답 제공 금지 — 항상 되묻기 또는 선택지로 마무리 (펫서비스기획 §7). 확신도 UI엔 "정답은 없어!" 캡션 병기.
- 유형 라벨은 "이번 주 민지는 **뉴스 사냥꾼형**!" 형식 (기간 표기 — 고정 낙인 방지).

## 5. 캐릭터·그래픽

- **가족 AI펫**(데모명 "통통이"): 서비스의 얼굴 — 홈 상주, 펫 화면, 오늘의 순간 카드. 표정 = 상태 표현(🙂 좋음 / 🤔 갸우뚱 / ☀️ 밝음 / 😔 시무룩), 연출은 표정 교체+간단 모션 수준. 에셋 확보 전엔 원형 플레이스홀더+이름 라벨. 기존 마스코트 영웅이(소)·키웅이(곰)는 펫 디자인 통합 검토 대상(기획서 §15-7) — 포스터·보조 그래픽용.
- 장식은 별·말풍선·컨페티만, 화면당 1~2개 포인트. 체결 완료·주간 질문 동시 공개 순간에만 컨페티.

## 6. 공용 컴포넌트 (web/shared/ui/ — 이것만 조합해서 화면 구성)

`Button(primary=magenta/secondary=navy선)` · `Card` · `Chip(선택형 — 근거 태깅·선택지)` · `PriceText(등락색+▲▼ 자동)` · `ProgressBar(시즌 진행·펫 성장 게이지)` · `TabBar` · `PetAvatar(표정·컨디션 상태)` · `SpeechBubble(펫 말풍선)` · `ConfidenceSelector(확신도 4단계 탭)` · `ConfettiBurst`

없는 컴포넌트가 필요하면 `web/shared/AGENTS.md`의 변경 요청 로그로 요청(`docs/하네스.md` 공용 변경 절차) — 기능 폴더 안에 사본 만들지 말 것.
