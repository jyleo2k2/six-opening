# 디자인 시스템 — 현재 구현 기준

> 갱신: 2026-08-14 · 기준: `web/app/globals.css`, `web/shared/ui/index.tsx`, `web/public/ui/app.html`
>
> 새 UI는 React 토큰과 공용 컴포넌트를 우선 사용한다. 기존 정적 프로토타입은 별도 스타일 체계를 쓰므로, 현재 상태와 새 코드 규칙을 구분한다.

## 1. UI 표면이 두 개다

| 표면 | 기술 | 소유 | 현재 스타일 방식 |
|---|---|---|---|
| 메인 앱 | iframe의 정적 HTML | `web/public/ui/app.html` | 대규모 인라인 스타일, 임의 hex·그라디언트 포함 |
| React 오버레이 | Next.js + Tailwind | F10·F11 및 `web/shared/ui` | `globals.css`의 Tailwind 테마 토큰 |

메인 앱을 이미 토큰 기반 React UI로 구현했다고 가정하지 않는다. `app.html`에는 테마 밖 색상이 다수 있고 F9 레이더 차트도 실제로 존재한다. 기존 화면을 수정할 때는 주변 시각 언어를 유지하고, 새 React UI는 아래 토큰을 사용한다.

## 2. React 테마 토큰

`web/app/globals.css`의 실제 `@theme` 계약이다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `navy` | `#001E5A` | 헤더, 핵심 정보, 보조 CTA |
| `magenta` | `#D70082` | 주 CTA, 선택 상태 |
| `gray` | `#BEBEBE` | 구분선, 비활성 |
| `bg` | `#F6F7FA` | React 화면 배경 |
| `ink` | `#1A2233` | 본문 텍스트 |
| `up` | `#E8322E` | 상승·수익 |
| `down` | `#1668DC` | 하락·손실 |
| `trade-child` | `#0F8A68` | 차트의 자녀 체결 마커 |
| `trade-parent` | `#16233F` | 차트의 부모 체결 마커 |
| `shadow-card` | `0 8px 24px rgb(0 30 90 / 0.08)` | React 카드 그림자 |

흰색은 Tailwind 기본 `white`를 쓴다. 국내 증권앱 관례에 맞춰 상승은 빨강, 하락은 파랑이다. 체결 마커는 등락으로 오독하지 않도록 `trade-child`·`trade-parent`를 쓴다.

## 3. 실제 레이아웃

### 3.1 메인 정적 프로토타입

- 바깥 iPhone 프레임: 450×920
- 실제 콘텐츠 영역: 402×874, 좌측 24px·상단 23px
- 작은 브라우저에서는 450×920 기준으로 전체를 축소한다.
- 상태바 높이: 59px
- 메인 하단 탭: **홈 / 모의투자 / 아카이브 / 랭킹** 4개
- F10 플로팅 버튼과 F11 가족 기록 버튼은 iframe 밖 고정 오버레이이다.
- 메인 앱 공통 부모↔자녀 스위처는 없다.

### 3.2 React 화면

`PhoneShell`은 `max-width: 430px`, 최소 화면 높이, `bg` 배경을 사용한다. F11은 이 셸로 전체 오버레이를 만들고, F10은 별도 기능 UI를 사용한다.

현재 공용 `TabBar`는 포트폴리오 / 투자 기록 / 배우기 3개 항목이며 모두 `/`로 연결된다. 이는 메인 iframe의 4탭 내비게이션과 다른 별도 계약이다.

## 4. 형태와 타이포그래피

### React 공용 컴포넌트

- 카드: 16px 라운드, 흰 배경, `shadow-card`
- 버튼: 최소 높이 48px, 12px 라운드
- 주 버튼: magenta 배경 + 흰 글자
- 보조 버튼: 흰 배경 + navy 테두리·글자
- 칩형 버튼: 필요한 기능에서 999px 라운드 사용
- 화면 헤더: 최소 높이 78px, navy 배경, 흰 글자

### 글꼴과 숫자

- 글꼴: Pretendard → Segoe UI → Malgun Gothic → sans-serif
- `app.html`은 Pretendard 400·500·600·700·800·900 로컬 에셋을 로드한다.
- 가격·수익률·수량은 가능하면 `tabular-nums`를 사용한다.
- React 화면의 기본 위계는 제목 20px bold, 카드 본문 12~15px 범위다.

정적 프로토타입은 화면별 인라인 수치를 사용하므로 위 React 크기 체계를 전 화면에 적용했다고 설명하지 않는다.

## 5. 말투와 금융 표현

- 자녀 대상 문구는 해요체와 짧은 문장을 쓴다.
- 훈계·채점·정답처럼 들리는 표현을 피한다.
- 종목 추천, 매매 시점, AI 생성 목표가, 손절가, 수익률 전망은 금지한다.
- 사용자가 직접 세우는 보유 계획의 목표가는 허용하되 AI 조언처럼 표현하지 않는다.
- 상승·하락에는 색만 의존하지 말고 텍스트나 ▲▼ 기호를 함께 쓴다.
- 유형·캐릭터는 기간성 관찰로 표현하고 고정 낙인이나 실력 등급으로 부르지 않는다.

현재 매매 기록 화면에는 확신도 선택 UI가 없다. 관련 캡션이나 `ConfidenceSelector`를 구현 완료 기능으로 문서화하지 않는다.

## 6. 그래픽과 차트

- 키웅이: F10 플로팅 버튼과 챗봇 화면의 캐릭터
- 영웅이: 현재 앱 공용 컴포넌트 계약이 아님
- 체결 완료 화면: 컨페티 장식을 사용
- TradingView 차트: 자녀/부모의 B·S SVG 체결 마커를 표시
- F9 아카이브: 5개 능력치를 SVG 레이더 차트로 표시

차트 체결 마커는 표시 전용이며 클릭 상호작용이 없다. F9 레이더를 “금지” 또는 “미구현”으로 설명하지 않는다.

## 7. 공용 컴포넌트 계약

`web/shared/ui/index.tsx`가 실제로 내보내는 것은 아래 5개뿐이다.

| 컴포넌트 | 현재 역할 |
|---|---|
| `Button` | primary / secondary 버튼 |
| `Card` | 흰 카드 컨테이너 |
| `TabBar` | React 3탭 내비게이션 |
| `ScreenHeader` | 뒤로가기 선택형 navy 헤더 |
| `PhoneShell` | 최대 430px React 화면 셸 |

`Chip`, `PriceText`, `ProgressBar`, `CoachAvatar`, `SpeechBubble`, `BottomSheet`, `ChatComposer`, `ConfidenceSelector`, `ConfettiBurst`는 현재 공용 export가 아니다. 두 번째 실제 소비자가 생길 때 타입·구현·테스트와 함께 공용 승격을 검토한다.

## 8. 현재 정합성 부채

1. 메인 정적 화면과 React 오버레이가 서로 다른 프레임·탭·스타일 계약을 쓴다.
2. `app.html`은 토큰 대신 많은 인라인 색상과 그라디언트를 사용한다.
3. F11의 `TabBar`는 모두 `/` 링크라 메인 iframe 내비게이션을 직접 제어하지 않는다.
4. 메인 자녀 이름 `김찬영`과 F11 라벨 `민지`가 다르다.
5. F9 UI가 없는 `starGrade`·`emoji` 필드를 읽어 별과 캐릭터 이모지가 비어 있다.
