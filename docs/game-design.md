# 주식 카드 배틀 (가칭) — 게임 설계안 v1.0

> 작성일: 2026-08-05
> 상태: 코어 설계 확정, MVP 착수 전

---

## 1. 한 줄 컨셉

**"자산이 곧 HP다."** 초등 고학년~중학생을 위한 턴제 주식 카드 배틀 — 카드 이름이 전부 주식 용어이고, 시장은 나와 상대가 공유한다.

## 2. 타깃

| 타깃 | 소구점 |
|---|---|
| 초등 고학년~중학생 (전략게임 성향) | 카드 배틀 + 덱빌딩 + 수집. "교육 게임"이 아니라 "진짜 게임"으로 보여야 함 |
| 부모 (구매 결정자) | 금융 교육 타이틀. 도감 = 학습 진도표. 사행성 요소 완전 배제 |

## 3. 벤치마크 → 채택 요소

| 게임 | 가져온 것 |
|---|---|
| 클래시로얄 | 모바일 세로 UI, 코스트 개념, 수집 메타, 프리셋 이모지 |
| 하스스톤 | PvP 매치 구조, 랜덤 손패 + 턴 드로우, 에너지 램프, 승리 → 골드 |
| Slay the Spire | 함정 카드(비밀), 다음 턴 이벤트 예고(적 의도 표시의 번역) |
| 문명5 | 턴제, "한 턴만 더" 훅 |

## 4. 코어 룰: 매치 구조

```
양측: 시작 현금 100만 골드 / 덱 22장에서 랜덤 손패 4장 / 매 턴 1드로우 (손패 상한 7)
중앙: 공유 시장판 — 종목 4개 (삼성전자·카카오·크래프톤·교촌에프앤비)
에너지: 램프형 (1라운드 1 → 최대 5)
자산 = 현금 + 보유 주식 평가액 + 공매도 미실현 손익
매 라운드 정산: 월드 이벤트(2라운드마다, 1라운드 전 예고) → 노이즈(±5%) +
  시장 드리프트(+3%) → 공매도 청산 → 생활비 1.5만 차감(부족 시 강제 매도)
```

수치는 셀프플레이 시뮬레이터로 조정된 값 (11절 스냅샷 참고).

**완주 목표: 5~10분** (클래시로얄 기준). 턴 수는 10~15 유지하되 턴당 템포를 짧게 — 연출 최소화, 정산 동시 처리.

### 승리 조건 (3중)

1. **마진콜**: 상대 자산이 시작 자금의 반토막(50만) 이하로 하락 — "자산 0"은 수학적으로 거의 불가능해 죽은 룰이 되므로 반토막 라인으로 조정. 마진콜/신용위기 용어 교육 겸용
2. 목표 금액(150만) 선점
3. 15라운드 종료 시 자산 많은 쪽

### 핵심 원칙: 시장은 공용

이벤트 카드는 상대를 직접 때리지 않고 **시장을 때린다**. 내가 반도체 쇼크를 내면 반도체를 든 사람은 나든 상대든 전부 맞는다. → 카드를 내기 전에 내 포지션부터 정리해야 하는 긴장감이 전략의 핵심.

프레이밍: 이벤트 카드 = "특종 뉴스 선점" (어차피 올 뉴스의 타이밍을 내가 지배). "내가 재앙을 일으킨다"는 시장 조작 프레임 회피.

## 5. 카드 시스템

### 원칙

- **카드 이름 = 주식 용어.** 퀴즈 금지. 쓰다 보면 뜻을 알게 되는 구조.
- 카드 종류: **이벤트**(뉴스 선점) / **행동**(매수·매도·전략) / **함정**(조건 발동) / **재미(밈)**
- **재미(밈) 카드**: 릴스 찍기, 치킨 먹방, 몰빵 등 — 낮은 코스트, 가벼운 효과, 게임의 캐릭터성 담당. 강할 필요 없음(밸런스 하한 면제), 단 지배는 금지(승률 상한은 적용). 가능하면 실제 개념과 연결 (릴스 찍기 = 밈 주식·바이럴, 몰빵 = 집중투자의 위험).
- 시작 덱: 매수 / 매도 / 관망 — 3종. 1분 안에 시작 가능해야 함.
- 희귀도: 일반 / 희귀 / 영웅 / 전설. **강화는 없음** (PvP 양학 방지, 카드 파워 고정).
- 획득은 플레이 보상만. **과금 뽑기 절대 금지** (사행성 방어선).

### MVP 카드 15종 (확정)

| 카드 | 종류 | 코스트 | 효과 | 배우는 것 |
|---|---|---|---|---|
| 매수 | 행동 | 1 | 선택 종목 20만 매수 | 기본 매매 |
| 매도 | 행동 | 1 | 선택 종목 전량 매도 | 기본 매매 |
| 관망 | 행동 | 0 | 카드 1장 드로우 | 정보 수집도 행동이다 |
| 분산투자 | 행동 | 2 | 40만을 4종목에 균등 매수 | 분산 |
| 배당 | 행동 | 2 | 보유 평가액의 8%를 현금으로 | 배당 |
| 공매도 | 행동 | 2 | 20만 규모 숏 포지션, 2정산 후 청산 | 공매도 |
| 손절 예약 | 함정 | 1 | 보유 종목 12%↑ 급락 시 자동 매도 (피해 절반) | 손절/스탑로스 |
| 반도체 쇼크 | 이벤트 | 3 | 반도체 섹터 -25% | 섹터 리스크 |
| 플랫폼 규제 | 이벤트 | 3 | 플랫폼 섹터 -20% | 규제 리스크 |
| 신작 대박 | 이벤트 | 2 | 게임 섹터 +20% | 호재/모멘텀 |
| 금리 인상 | 이벤트 | 4 | 전 종목 -10%, 다음 정산 시 현금 이자 +5% | 금리와 주가 |
| 내부자거래 | 불법 | 2 | 즉시 +25만, 의혹 +1 (정산마다 의혹×15% 확률 적발 → 자산 40% 몰수) | 불법의 대가 |
| 릴스 찍기 | 재미 | 1 | 선택 종목 70% 확률 +15%, 30% "노잼" 무효과 | 밈 주식/바이럴 |
| 치킨 먹방 | 재미 | 1 | 식품 섹터 +10% | 소비 트렌드 |
| 몰빵 | 재미 | 2 | 전 현금을 선택 종목에 올인 | 집중투자의 위험 |

### 대표 콤보 (재미 = 교육)

| 콤보 | 효과 | 배우는 것 |
|---|---|---|
| 공매도(반도체) → 반도체 쇼크 | 상대 떡락 + 나는 수익 | 공매도 |
| 분산투자 상태로 쇼크 받기 | 피해 1/n 감소 | 분산 = 방어 스탯 |
| 예약매도 (함정) | 급락 시 자동 매도 발동 | 손절 / 스탑로스 |
| 호재 뉴스 → 보유 섹터 부양 | 버프 | 재료 / 모멘텀 |
| 특정 섹터 사는 척 | 상대 공격 카드 낭비 유도 | 심리전 (순수 재미) |

### 불법 카드

- 내부자거래 / 작전(주가조작) / 허위공시 = 즉발 고수익 + **의혹 게이지** 누적
- 게이지 상승 → "금융감독원 조사" 이벤트 확률 증가 → 적발 시 자산 대량 몰수
- 밸런스 원칙: **기댓값 마이너스.** 몇 번은 달콤하고 계속 쓰면 반드시 망함 — 설교 없이 몸으로 배움
- 적발 시 도감에 '전과 기록' 표시

## 6. 기업 · 이벤트 (법적 검토 완료)

| 요소 | 결정 | 근거 |
|---|---|---|
| 기업 | **실명 기업** — 삼성전자(반도체), 카카오(플랫폼), 크래프톤(게임), 하이브(엔터), 교촌에프앤비(식품) 등 | 아이들이 아는 진짜 기업이어야 와닿음 (사용자 결정. 법적 리스크 검토·전달 완료 — 아래 완화 장치로 노출 최소화) |
| 이벤트 | **실제 역사 사건 기반** — IMF 외환위기, 2008 금융위기, 코로나 폭락, 반도체 슈퍼사이클… | KCIE 투자게임과 동일 방식(사실 재생)이라 법적으로 안전. "진짜 뉴스"의 와닿음 확보 + 경제사 교육 |
| 가격 모델 | 이벤트 기반 + 노이즈 + **우상향 드리프트(+3%/정산)** | 매판 다른 경험. 드리프트는 "장기 투자는 우상향" 교육 메시지이자 현금 홀딩 응징 장치 |

### 실명 사용 리스크 완화 장치

1. **이벤트는 섹터 단위로만 발동** — "반도체 쇼크"가 반도체 섹터를 때리고 삼성전자는 그 소속으로 영향받는 구조. 특정 기업 저격 카드("삼성전자 스캔들" 류) 금지.
2. **기업 고유의 허구 악재 창작 금지** — 부정적 이벤트는 실제 역사 사건 또는 일반 시장 이벤트(금리 인상, 원자재 급등)만.
3. **명칭만 사용, 로고·CI 미사용** — 상표권 노출 축소.
4. **면책 고지** — "본 게임은 교육용 시뮬레이션이며, 등장하는 가격 변동·이벤트는 실제 기업과 무관한 가상 시나리오입니다."
5. 불법 카드(내부자거래 등)는 **플레이어의 행동**이지 기업의 행동이 아님 — 기업을 가해자로 묘사하지 않음.

## 7. 도감 (교육 허브)

- 카드 획득 → 도감 등록. **도감 = 용어 사전 + 학습 진도표** (부모용 리포트를 따로 만들 필요 없음)
- **매치 중 ? 버튼 = 한 줄 툴팁만** ("배당: 회사가 번 돈을 주주에게 나눠주는 것"). 몰입 유지.
- **숏폼 해설 영상은 도감에서 시청** — 시청 시 소소한 보상(코스메틱 등). 숙제가 아니라 보너스 파밍.
- 역사 이벤트 카드에는 실화 해설 첨부 ("이 사건은 실제로 2020년에…")
- 1차 제작 범위: 전 카드 툴팁 + **핵심 용어 10개만 영상**. 반응 보고 확장.

## 8. 보상 · 메타

- 승리 → **골드** (하스스톤 방식)
- 골드 사용처: 아바타 꾸미기 / 카드 스킨 / 도감 꾸미기 — **현금성·환금성 완전 배제**
- 랭크: PvP 등급 (새싹 개미 → … → 전설의 투자왕). 랭크업 = 새 카드·시나리오 해금
- AI 시나리오 모드: 별 3개 평가(수익률 기반) — 재도전 동기

## 9. 안전 · 규제 체크리스트

- [ ] 과금 뽑기 없음 — 카드 획득은 플레이만
- [ ] 게임 재화 ↔ 현금 연결 없음
- [ ] 채팅 없음 — 프리셋 이모지만
- [ ] 불법 행위 카드는 기댓값 마이너스로 밸런싱 (도박·불법 미화 방지)
- [ ] 실명 기업 완화 장치 준수 — 섹터 단위 이벤트, 기업 고유 허구 악재 금지, 로고 미사용, 면책 고지 (6절)

## 10. 개발 로드맵

### Phase 1 — MVP (싱글 AI 대전)

멀티 인프라 없이 재미부터 검증. 재미없으면 서버 짤 이유도 없음.

```
범위: 실명 종목 4개 (삼성전자·카카오·크래프톤·교촌에프앤비) + 카드 15장 + AI 상대 1판 (15턴)
검증 질문: "카드 내는 맛이 있는가? 한 판 더 하고 싶은가?"
기반: game/ui/ (Vite + React — prototype/는 무관한 별도 앱이라 신규 구성. 2026-08-05)
```

### Phase 2 — 메타 + 콘텐츠

- 덱빌딩, 카드 수집, 골드/코스메틱, 도감(툴팁 전체 + 영상 10개)
- AI 시나리오 모드 (튜토리얼 + 카드 파밍)

### Phase 3 — 멀티

- 비동기 PvP (고스트 덱) → 실시간 PvP + 랭크

### 장기 확장 (제휴 카드)

- **역사 재현 모드**: 실제 과거 시세 데이터 그대로 재생 (KCIE 방식, KRX 데이터 라이선스 필요)
- **진짜 주식 보상**: 증권사 제휴 이벤트 형태 (자본시장법·미성년 계좌 이슈로 단독 구현 불가 — 제휴 전제)

## 11. 검증 루프 (제작 루프의 목표)

> 전제: 룰 엔진은 UI 없이 실행 가능(헤드리스)하게 만들고, AI vs AI 셀프플레이 시뮬레이터로 매 빌드 검증한다. 시뮬레이터 없으면 밸런스 검증이 전부 "느낌"이 된다.

```
[설계·수치 조정] → [구현] → ① 유닛 테스트 (룰 정합성)
                             ② 셀프플레이 시뮬레이션 → 밸런스 리포트
                             ③ (주기적) 사람 플레이테스트
                        → 리포트 보고 수치 조정 → 반복
```

### 자동 루프 — 매 빌드

| 목표 | 타깃 수치 (가설, 조정 대상) | 검증 |
|---|---|---|
| 룰 정합성 | 카드 1종 = 유닛 테스트 1개 이상, 회귀 그린 | 유닛 테스트 |
| 게임 길이 | 완주 5~10분 (시뮬 평균 10~15턴) | 셀프플레이 |
| 승리 조건 분포 | 파산/목표금액/턴종료 각 15% 이상 (죽은 룰 방지) | 셀프플레이 |
| 카드 밸런스 | 용어 카드 승률 기여 45~55%. 재미 카드는 하한 면제, 상한 55%만 | 셀프플레이 |
| 선공/후공 | 승률 차 5%p 이내 | 미러전 |
| 터틀 방지 | 현금 홀딩 봇 승률 < 35% (생활비 메커니즘 작동 확인) | 봇 대전 |

### 교육 메시지 = 메타 성립 — 매 빌드 ★

설계안의 교육 주장을 검증 가능한 가설로 취급한다. 어긋나면 **교육 버그**로 보고 수치를 고친다. 원칙: **교육 메시지가 웬만하면 이긴다.**

| 설계 주장 | 검증 |
|---|---|
| "분산투자 = 방어" | 분산 봇 승률 > 몰빵 봇 승률 |
| "불법은 결국 손해" | 불법 스팸 봇 승률 < 정직 봇 승률 |
| "시그널 읽기가 실력" | 예고 활용 봇 > 예고 무시 봇 |

### 수동 루프 — 주 1회, 룰 안정화 후

| 목표 | 측정 |
|---|---|
