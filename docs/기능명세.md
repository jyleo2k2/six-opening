## F0. 홈 & 가족리그 설정 (§6~§9)

> 진입·재방문의 중심. 순위·수익률·포트폴리오 요약이 한 화면에.

- **홈**: 우리 가족 현재 순위 / 부모·자녀 각각 수익률 / 내 포트폴리오 요약(보유·평가손익·현금) / 모의투자 바로가기 / 아카이브 바로가기("이번 주 성향 리포트가 나왔어요!") / 시즌 진행바(3주차/4주) / 부모 뷰: 로보마켓 체험권 배너 + 시즌 리워드 안내
- **튜토리얼**: 첫 진입 시 코치마크 3장 (① 홈 구성·순위 ② 매매 진입 ③ 키웅이 소개 — "궁금한 건 언제든 키웅이한테 물어봐") — 데모 시작 장면 겸용
- **개설 플로우**(와이어프레임만, 데모는 완료 상태 시작): 부모 리그 만들기 → 초대 코드 → 자녀 수락(법정대리인 동의 — 형식) → 프리셋(입문형 ≤30% / 성장형 ≤40%) → 가상금 1,000만 지급
- 건별 승인 없음. 한도 초과 주문 차단+안내. 위험행동 시 부모 코칭 알림 1종(데모): "차단하기보다 투자 이유를 먼저 물어보시겠습니까?"

## F2. 모의투자 (§10)

> 각자 독립 포트폴리오 자유 매매. 행동 데이터의 원천. 시세는 키움 REST API.

- 종목 탐색(검색·업종 칩) → **종목 상세**: 현재가·차트·내 보유/수익률 + **아이 눈높이 설명**("이 회사는 무슨 일을 해?" / "최근 무슨 일이 있었어?") + 매수/매도 버튼
- **주문**: 수량 → 예상 금액 확인(수수료·세금 실제 수준 안내) → **F3 질문식 기록(플로우 내장)** → 체결. 데모는 시장가 즉시 체결, 지정가는 설계만(§10). 동일 종목 매도 후 30분 재매수 제한 — 데모는 안내 문구 표시
- **행동 이벤트 수집** (F9 스코어링 + F10 선제 신호 입력): 거래 로그(종목·수량·시각·실현손익), 종목 상세 체류시간, 조회 종목 수, 주문 화면 UI 이벤트(탭 전환·확인창·수량 수정). 수집 항목은 온보딩에서 고지(§15-6)
- 포트폴리오(보유종목): 보유·평가손익·현금 — 홈 요약과 동일 데이터

## F3. 질문식 매매 기록 (§10)

> 주문 직전 근거 태깅+확신도+한 줄, 2탭. '제안서'가 아니라 스코어링 엔진·리포트용 생각 데이터.

- **매수 근거** 선택(필수): 뉴스에서 봤어 / 차트가 좋아 보여 / 친구·가족이 추천했어 / 이 회사(제품)를 잘 알아 / 그냥 느낌이 좋아 — 근거 유형 5축(뉴스·차트·추천·지식·느낌)
- **확신도**(매수 시 필수): 키웅이가 묻는 프레이밍 "키웅이가 궁금해해 — 얼마나 자신 있어?" 4단계 탭: 잘 모르겠어(25) / 조금(50) / 꽤(75) / 완전(100). 슬라이더 아님. "정답은 없어!" 캡션 병기 — 채점 아님(§10)
- **매도 근거** 선택(필수): 목표한 만큼 올랐어 / 더 떨어질까 봐 걱정돼 / 다른 종목이 더 좋아 보여 / 그냥 불안해 / 기타
- 내 생각 한 줄(선택). 체결 완료 화면: "기록 완료! 키웅이가 기억해둘게" (컨페티)
- 확신도 값·근거 유형이 F9 스코어링(신중함 축의 확신도-행동 일치, 태깅 분포)의 핵심 입력. **F10 선제 신호에는 미사용** — 선제 발화는 판단이 아니라 사용법 헤맴만 본다

## F9. 아카이브 — 스코어링 기반 성향·리포트 (§11)

> 스코어링 엔진이 행동을 5축으로 계산하고, LLM이 서술만 붙인다.

### 스코어링 엔진 (룰·통계 — LLM 아님, §11.1)

- 입력: F2 거래 로그·탐색 이벤트·포트폴리오 스냅샷 + **F3 근거 태깅·확신도**. **F10 챗봇 대화는 미반영**(§21 — 질문은 성향이 아니다).
- **성향 5축** (각 0~100, 주간 스냅샷): 집중–분산(종목·업종 집중도) / 속도(보유기간·회전율) / 신중함(주문 전 체류·조회 대비 주문 + **확신도-행동 일치**) / 손실 대응(하락 구간 보유·손절·추가매수) / 탐험심(새 종목·업종 시도율)
- **유형 라벨**: 두드러진 상위 2축 조합 → 수작성 라벨 매트릭스(8~12종)에서 매핑. 주간 갱신. 예: 민지 "재빨리 개척자형" / 엄마 "돌다리 분석가형"
- 데모: 시드 2주치 + 시연 중 실거래를 합산해 실시간 재계산 (스코어가 눈앞에서 움직이는 게 발표 증거)

### 화면 구성

1. **성향 리포트** (주간, 각자): 5축 게이지 + 유형 라벨 카드 + 근거 태깅 분포·확신도 패턴('느낌' 비중 추이 등) + Luna 서술(스타일 요약 2~3문장, 잘한 점·아쉬운 점 각 1~2개 — 관찰 톤, 훈계 금지) + "정답은 없어!" 캡션 + 데이터 적으면 "아직 관찰 초기" 병기
2. **수익률 리포트**: 수익률 추이·평가손익 (정량 그대로, LLM 서술 없음)
3. **가족 비교** [잠정, §15-3]: 두 사람 5축 나란히(레이더 또는 막대 병치) + 중립 서술 1줄 — "민지는 재빨리, 엄마는 진득하게. 스타일이 달라요"
4. **시즌 기록**: 시즌 초↔현재 축 변화 비포/애프터 + 수익률 결산. 데모는 3주차 중간 기록 + 시즌 말 목업 카드 1장
- 파이프라인: 엔진 지표·유형 라벨 JSON → Luna 성향 서술 → **공통 출력 필터(§13)** → 화면

## F10. 플로팅 AI 챗봇 "키웅이" (§12)

> "투자 정답 AI"가 아니라 사용법·기초 개념·화면 맥락을 설명하는 **눈높이 도우미**다. 물어보면 답하고(자유 입력+추천 칩), 헤매면 먼저 짧게 말 건다(고정 스크립트). 추천·예측은 구조적으로 거절한다.

### A. 반응형 (사용자가 먼저 묻기)

1. **진입**: 전 화면 우하단 플로팅 버튼(키웅이 얼굴) → 바텀시트 챗 UI. 첫 오픈 인사 + 현재 화면 맥락 기반 **추천 질문 칩 3개** (종목 상세: "이 회사는 뭐 하는 회사야?"·"PER이 뭐야?" / 주문: "시장가가 뭐야?" / 홈: "매수 어떻게 해?")
2. **컨텍스트 주입(읽기 전용)**: {현재 화면·종목·화면에 표시된 보유 수치}. 수치는 엔진/API 값만 인용하고 Luna가 수치를 만들면 버그
3. **라우팅**: ① 용어 사전 매칭(~30개) ② 사용법 FAQ 매칭(~15개) ③ 미스 시 `gpt-5.6-luna`의 `responses.create({ stream: true })` 호출 ④ `response.output_text.delta`를 문장 단위 버퍼링 ⑤ **공통 출력 필터(§13)** 통과분만 SSE 표시 ⑥ 차단·실패·타임아웃 → 고정 폴백("키웅이가 잠깐 낮잠 중이야! 조금 있다 다시 물어봐 줘 🐻")
4. **처리 상태 타임라인**: 처리 단계를 칩+한 줄 고정 문구로 순차 표시 — 경로("무슨 질문인지 보는 중") → 사전 → 답변(스트리밍) → **안전 점검("안전 점검 통과!")**. 같은 SSE 스트림의 메타 이벤트로 전송하며 문구는 전부 수작성(생성 아님)
5. **입력 분류(가드)**: 추천 요구("뭐 사?"·"오를까?") → 고정 거절+기준 안내 "종목은 내가 골라줄 수 없어! 대신 고를 때 뭘 보면 좋은지 알려줄게 🐻" / 오프토픽·유해·개인정보 → 고정 우회 "나는 투자 이야기만 할 수 있어!" / 과몰입·정서적 위기 표현 → 대화 안전 종료 + 보호 안내 고정 스크립트 / 전 대화 로깅
6. **응답 원칙**: 3문장 이내·쉬운 말·비유·이모지. 종목 추천·매매 시점·가격·예측·훈계 금지. AI 고지 상시 표시("키웅이는 AI 도우미야")

### B. 선제 도움 신호 — 사용법 도움 3종

발화 문구는 신호별 **고정 스크립트(LLM 미사용)**. 발화 문구가 상황을 설명하며, 반응 카드는 2장 고정: **직접 질문 / 괜찮아**. 수치는 전부 **[가정] 초기 운영값** — 30세션 검증으로 조정(§19 PoC-2). **부모 미전달** — 아이 본인에게만(감시 프레임 차단).

| # | 신호 조건 | 고정 발화 | 카드 예 |
|---|---|---|---|
| 1 | 매수/매도 버튼을 누른 뒤 확인창 "매수하시겠습니까?"에서 "아니요"를 눌러 취소한 행동이 매수·매도 순으로 3회 연속 반복 | "매수와 매도가 헷갈려?" | [직접 질문] [괜찮아] |
| 2 | 주문 또는 종목 상세 화면 체류시간이 **5분 초과** | "어디에서 막혔는지 같이 볼까?" | [직접 질문] [괜찮아] |
| 3 | 해당 종목에서 **-10% 이하 손실을 실현**한 매도 체결 직후부터 5분간, 같은 종목 상세 화면에 **4회 이상 재진입** | "방금 본 종목이 계속 신경 쓰여?" | [직접 질문] [괜찮아] |

- **발화 제한**: 선제 발화 간 최소 3분 · 동일 신호 10분 내 재발화 금지 · 세션 최대 2회 · [괜찮아] 선택 시 해당 신호는 세션 내 재발화 금지 · 30분 무활동 = 새 세션.
- **제외 유지**: 주문 확인창 뒤로가기 반복 / 주문 수량 반복 수정 / 차트 기간 반복 변경(탐색과 구분 불가) / 여러 종목 빠른 조회(정상 탐색) / 순위·손실 확인 후 주문(감시 느낌 위험) / 주문 오류 반복(오류 문구가 직접 설명).

입력: 사용자 메시지 + 화면 컨텍스트 + UI·행동 이벤트(선제 신호용) / 출력: 대화 로그(입력 분류·필터 결과 포함), 선제 발화 로그(신호·수용/괜찮아 — §18 안전·활성 지표) / **부모 전달·F9 스코어링 반영 금지**

## 데이터 흐름

```
F0 리그 설정(프리셋) ─────┐
F2 거래 로그·탐색 이벤트 ──┼→ 스코어링 엔진(룰·통계 → 5축·유형 JSON) → F9 아카이브: LLM 서술 → 공통 필터 → 화면
F3 근거 태깅·확신도 ──────┘
F2 주문 UI 이벤트 → F10 선제 신호(룰) → 고정 발화 + 카드 (LLM 미사용)
F10 챗봇 자유 질문: 입력 + 화면 컨텍스트 → 사전/FAQ 매칭 → Luna 스트림 → 문장 버퍼·공통 필터 → SSE 화면
                    └ 대화·발화 로그는 스코어링 미반영, 안전·활성 지표로만 집계
```

## 데모 골든 패스 (발표 시연 순서)

1. **홈**(민지 뷰, 3주차): 튜토리얼 코치마크 → 가족 순위·각자 수익률·포트폴리오 요약
2. 민지: 종목 탐색 → 상세(아이 눈높이 설명) → **챗봇**: 추천 칩 "PER이 뭐야?" 탭 → 눈높이 답변(스트리밍)
3. 매수·매도 버튼을 번갈아 누르고 확인창에서 취소를 3회 반복 → **키웅이 선제 발화** "매수와 매도가 헷갈려?" + [매수·매도 설명] 카드 → 차이 확인 (선제 도움 시연)
4. **질문식 기록**: 근거 "그냥 느낌이 좋아" + 확신도 25 → 체결 컨페티 "기록 완료! 키웅이가 기억해둘게"
5. 챗봇에 "뭐 사면 돼?" → **고정 거절+기준 안내** 시연 (안전 구조가 발표 증거 — 통합문서 v2 §12·§13)
6. **아카이브**: 민지 성향 5축 게이지 + "재빨리 개척자형" + 태깅 분포('느낌' 비중) → 방금 거래가 스코어에 반영된 것 확인
7. 엄마 전환: 엄마 리포트 → **가족 비교** 카드 "민지는 재빨리, 엄마는 진득하게" (+부모 뷰: 로보마켓 배너)
8. (슬라이드) 스코어링 엔진·필터 로그 / 선제 신호 설계·발화 제한 / 리워드·계좌 정책·로보마켓 / 컴플라이언스 쟁점
