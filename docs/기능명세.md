# 키움 가족 모의투자 리그 — 기능 명세 (데모 MVP) v7

> v7 우선: 한국 기업 주식 50종목, 3개월 시즌, 독립 포트폴리오와 가족 대시보드 비교를 적용한다. F10 챗봇은 불안 행동 감지로 먼저 시작하며, 열린 채팅에서 종목 공개 정보·자녀 본인 아카이브·서비스/금융 기초에만 답한다. 추천·시점·가격·수익률 전망·훈계와 부모 공유는 금지한다.

## F0. 홈 & 가족리그 설정 (§5.1·§7)

> 진입·재방문의 중심. 순위·수익률·포트폴리오 요약이 한 화면에.

- **홈**: 우리 가족 현재 순위 / 부모·자녀 각각 수익률 / 내 포트폴리오 요약(보유·평가손익·현금) / 모의투자 바로가기 / 아카이브 바로가기("이번 주 성향 리포트가 나왔어요!") / 시즌 진행바(4주차/8주) / 부모 뷰: 로보마켓 체험권 배너 + 시즌 리워드 안내
- **튜토리얼**: 첫 진입 시 코치마크 3장 (① 홈 구성·순위 ② 매매 진입 ③ 키웅이 소개 — "궁금한 건 언제든 키웅이한테 물어봐") — 데모 시작 장면 겸용
- **개설 플로우**(와이어프레임만, 데모는 완료 상태 시작): 부모 리그 만들기 → 초대 코드 → 자녀 수락(법정대리인 동의 — 형식) → 프리셋(입문형 ≤30% / 성장형 ≤40%) → 가상금 1,000만 지급
- 건별 승인 없음. 한도 초과 주문 차단+안내. 위험행동 시 부모 코칭 알림 1종(데모): "차단하기보다 투자 이유를 먼저 물어보시겠습니까?"

## F2. 모의투자 (§5.1~5.2)

> 각자 독립 포트폴리오 자유 매매. 행동 데이터의 원천. 시세는 키움 REST API.

- 종목 탐색(검색·업종 칩) → **종목 상세**: 현재가·차트·내 보유/수익률 + **아이 눈높이 설명**("이 회사는 무슨 일을 해?" / "최근 무슨 일이 있었어?") + 매수/매도 버튼
- **주문**: 수량 → 예상 금액 확인(수수료·세금 실제 수준 안내) → **F3 질문식 기록(플로우 내장)** → 체결. 데모는 시장가 즉시 체결, 지정가는 설계만(§5.2). 동일 종목 매도 후 30분 재매수 제한 — 데모는 안내 문구 표시
- **행동 이벤트 수집** (F9 스코어링 + F10 선제 신호 입력): 거래 로그(종목·수량·시각·실현손익), 종목 상세 체류시간, 조회 종목 수, 주문 화면 UI 이벤트(탭 전환·확인창·수량 수정). 수집 항목은 온보딩에서 고지(§12-6)
- 포트폴리오(보유종목): 보유·평가손익·현금 — 홈 요약과 동일 데이터

## F3. 질문식 매매 기록 (§5.3 — 08-10 팀 조율로 유지 확정)

> 주문 직전 근거 태깅+확신도+한 줄, 2탭. '제안서'가 아니라 스코어링 엔진·리포트용 생각 데이터.

- **매수 근거** 선택(필수): 뉴스에서 봤어 / 차트가 좋아 보여 / 친구·가족이 추천했어 / 이 회사(제품)를 잘 알아 / 그냥 느낌이 좋아 — 근거 유형 5축(뉴스·차트·추천·지식·느낌)
- **확신도**(매수 시 필수): 키웅이가 묻는 프레이밍 "키웅이가 궁금해해 — 얼마나 자신 있어?" 4단계 탭: 잘 모르겠어(25) / 조금(50) / 꽤(75) / 완전(100). 슬라이더 아님. "정답은 없어!" 캡션 병기 — 채점 아님(§6.2)
- **매도 근거** 선택(필수): 목표한 만큼 올랐어 / 더 떨어질까 봐 걱정돼 / 다른 종목이 더 좋아 보여 / 그냥 불안해 / 기타
- 내 생각 한 줄(선택). 체결 완료 화면: "기록 완료! 키웅이가 기억해둘게" (컨페티)
- 확신도 값·근거 유형이 F9 스코어링(신중함 축의 확신도-행동 일치, 태깅 분포)의 핵심 입력. **F10 선제 신호에는 미사용** — 선제 발화는 판단이 아니라 사용법 헤맴만 본다

## F9. 아카이브 — 스코어링 기반 성향·리포트 (§6.2·6.3)

> 스코어링 엔진이 행동을 5축으로 계산하고, LLM이 서술만 붙인다.

### 스코어링 엔진 (룰·통계 — LLM 아님, §6.5)

- 입력: F2 거래 로그·탐색 이벤트·포트폴리오 스냅샷 + **F3 근거 태깅·확신도**. **F10 챗봇 대화는 미반영**(§6.2 — 질문은 성향이 아니다).
- **성향 5축** (각 0~100, 주간 스냅샷): 집중–분산(종목·업종 집중도) / 속도(보유기간·회전율) / 신중함(주문 전 체류·조회 대비 주문 + **확신도-행동 일치**) / 손실 대응(하락 구간 보유·손절·추가매수) / 탐험심(새 종목·업종 시도율)
- **유형 라벨**: 두드러진 상위 2축 조합 → 수작성 라벨 매트릭스(8~12종)에서 매핑. 주간 갱신. 예: 민지 "재빨리 개척자형" / 엄마 "돌다리 분석가형"
- 데모: 시드 3주치 + 시연 중 실거래를 합산해 실시간 재계산 (스코어가 눈앞에서 움직이는 게 발표 증거)

### 화면 구성

1. **성향 리포트** (주간, 각자): 5축 게이지 + 유형 라벨 카드 + 근거 태깅 분포·확신도 패턴('느낌' 비중 추이 등) + LLM 서술(스타일 요약 2~3문장, 잘한 점·아쉬운 점 각 1~2개 — 관찰 톤, 훈계 금지) + "정답은 없어!" 캡션(§6.2) + 데이터 적으면 "아직 관찰 초기" 병기
2. **수익률 리포트**: 수익률 추이·평가손익 (정량 그대로, LLM 서술 없음)
3. **가족 비교** [확인 필요 §15-7]: 두 사람 5축 나란히(레이더 또는 막대 병치) + 중립 서술 1줄 — "민지는 재빨리, 엄마는 진득하게. 스타일이 달라요"
4. **시즌 기록**: 시즌 초↔현재 축 변화 비포/애프터 + 수익률 결산. 데모는 4주차 중간 기록 + 시즌 말 목업 카드 1장
- 파이프라인: 엔진 지표 JSON → LLM 서술·라벨 문장 생성 → **공통 출력 필터(§6.6)** → 화면

## F10. 플로팅 AI 챗봇 "키웅이" (§6.4)

> 아이 눈높이로 사용법·기초 개념·화면 맥락을 알려주는 도우미. 물어보면 답하고(자유 입력+추천 칩), 헤매는 신호가 보이면 먼저 짧게 돕는다(고정 스크립트). 추천·예측은 구조적으로 거절.

### A. 반응형 (사용자가 먼저 묻기)

1. **진입**: 전 화면 우하단 플로팅 버튼(키웅이 얼굴) → 바텀시트 챗 UI. 첫 오픈 인사 + 현재 화면 맥락 기반 **추천 질문 칩 3개** (종목 상세: "이 회사는 뭐 하는 회사야?"·"PER이 뭐야?" / 주문: "시장가가 뭐야?" / 홈: "매수 어떻게 해?")
2. **컨텍스트 주입**: {현재 화면, 보고 있는 종목, 내 보유 여부} — 시세·보유 수치는 엔진/API 값만 인용(§6.5)
3. **라우팅**: ① 용어 사전 매칭(~30개 수작성: 주식·ETF·수익률·분산투자·시장가·지정가·상한가…) ② 사용법 FAQ 매칭(~15개) ③ 미스 시 LLM 스트리밍 — 도메인 제한 시스템 프롬프트(지식 범위 3종 §6.4) ④ 응답은 **공통 출력 필터(§6.6)** 통과 후 표시 ⑤ 실패·타임아웃 → 고정 폴백("키웅이가 잠깐 낮잠 중이야! 조금 있다 다시 물어봐 줘 🐻")
4. **입력 분류(가드)**: 추천 요구("뭐 사?"·"오를까?") → 고정 거절+기준 안내 "종목은 내가 골라줄 수 없어! 대신 고를 때 뭘 보면 좋은지 알려줄게 🐻" / 오프토픽·유해·개인정보 → 고정 우회 "나는 투자 이야기만 할 수 있어!" / 전 대화 로깅
5. **응답 원칙**: 3문장 이내·쉬운 말·비유·이모지. 종목 추천·매매 시점·가격·예측·훈계 금지. AI 고지 상시 표시("키웅이는 AI 도우미야")

### B. 선제 도움 신호 (MVP 4종 — 사용법 헤맴만, 판단 개입·감시 아님)

발화 문구는 신호별 **고정 스크립트(LLM 미사용)**. 반응 카드 3장 고정: **상황 설명 / 자유 질문 / 괜찮아**. 같은 종목·같은 주문 세션 안에서만 계산. 수치는 전부 **[가정] 초기 운영값** — 30세션 검증으로 조정(§13 PoC-2).

| # | 신호 조건 | 고정 발화 | 카드 예 |
|---|---|---|---|
| 1 | 매수↔매도 30초 내 3회 전환 (최초 선택 제외 — 1회 실수·2회 비교 허용, 3회부터 패턴) | "매수와 매도 차이가 헷갈려?" | [매수·매도 설명] [직접 질문] [괜찮아] |
| 2 | 주문 확인창 열기→뒤로 가기, 2분 내 2회 (첫 재확인은 정상) | "주문 전에 확인하고 싶은 게 있어?" | [주문 단계 설명] [직접 질문] [괜찮아] |
| 3 | 주문 수량 45초 내 3회 재수정 (오타 1회·재계산 1회 허용) | "몇 주 살지 계산해볼까?" | [예상 금액 계산] [직접 질문] [괜찮아] |
| 4 | 활성 장기 체류 — 주문 화면 90초 / 종목 상세 180초 (읽기 시간 감안 2배) | "어디에서 막혔는지 같이 볼까?" | [화면 안내] [직접 질문] [괜찮아] |

- **수량 수정 카운트**: 키 입력 횟수가 아니라 **입력 후 0.7초 이상 멈춘 값을 1회 수정으로 계산** — `100` 타이핑을 3회 수정으로 오인하지 않기 위함.
- **체류 유효 조건 (모두 만족)**: 앱 전면 / 최근 30초 내 탭·스크롤·키 입력 있음 / 주문 완료·화면 이동 같은 진행 행동 없음 / 마지막 조작 2초 후 발화.
- **발화 제한**: 선제 발화 간 최소 3분 · 동일 신호 10분 내 재발화 금지 · 세션 최대 2회 · [괜찮아] 선택 시 해당 신호는 세션 내 재발화 금지 · 30분 무활동 = 새 세션.
- **제외 신호**: 차트 기간 반복 변경(탐색과 구분 불가) / 여러 종목 빠른 조회(정상 탐색) / 순위·손실 확인 후 주문(감시 느낌 위험) / 주문 오류 반복(오류 문구가 직접 설명). '주문 취소·정정 반복'은 지정가 설계 복귀로 보류 후보 [추후 — 데이터 확보 후].
- 근거 **[사실]**: FCA 연구 노트·ICO 아동 설계 지침(§17)은 중립 개입 방향 뒷받침, 수치는 미제공 → 수치 [가정].

## 데이터 흐름

```
F0 리그 설정(프리셋) ─────┐
F2 거래 로그·탐색 이벤트 ──┼→ 스코어링 엔진(룰·통계 → 5축·유형 JSON) → F9 아카이브: LLM 서술 → 공통 필터 → 화면
F3 근거 태깅·확신도 ──────┘
F2 주문 UI 이벤트 → F10 선제 신호(룰) → 고정 발화 + 카드 (LLM 미사용)
F10 챗봇 자유 질문: 입력 + 화면 컨텍스트 → 사전/FAQ 매칭 → (미스 시) LLM 스트리밍 → 공통 필터 → 화면
                    └ 대화·발화 로그는 스코어링 미반영, 안전·활성 지표로만 집계
```

## 데모 골든 패스 (발표 시연 순서)

1. **홈**(민지 뷰, 4주차): 튜토리얼 코치마크 → 가족 순위·각자 수익률·포트폴리오 요약
2. 민지: 종목 탐색 → 상세(아이 눈높이 설명) → **챗봇**: 추천 칩 "PER이 뭐야?" 탭 → 눈높이 답변(스트리밍)
3. 매수 진입 → 주문 화면에서 수량을 3번 고침 → **키웅이 선제 발화** "몇 주 살지 계산해볼까?" + [예상 금액 계산] 카드 → 계산 확인 (선제 도움 시연)
4. **질문식 기록**: 근거 "그냥 느낌이 좋아" + 확신도 25 → 체결 컨페티 "기록 완료! 키웅이가 기억해둘게"
5. 챗봇에 "뭐 사면 돼?" → **고정 거절+기준 안내** 시연 (안전 구조가 발표 증거 — §12-8)
6. **아카이브**: 민지 성향 5축 게이지 + "재빨리 개척자형" + 태깅 분포('느낌' 비중) → 방금 거래가 스코어에 반영된 것 확인
7. 엄마 전환: 엄마 리포트 → **가족 비교** 카드 "민지는 재빨리, 엄마는 진득하게" (+부모 뷰: 로보마켓 배너)
8. (슬라이드) 스코어링 엔진·필터 로그 / 선제 신호 설계·발화 제한 / 리워드·계좌 정책·로보마켓 / 컴플라이언스 쟁점
