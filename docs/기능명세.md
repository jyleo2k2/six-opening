## 4. F0 홈·가족리그

F0는 진입과 재방문의 중심 화면이다.

- 우리 가족 현재 순위
- 부모·자녀 각각의 수익률
- 내 포트폴리오 요약: 보유, 평가손익, 현금
- 모의투자와 아카이브 바로가기
- “이번 주 성향 리포트가 나왔어요!” 알림
- 시즌 진행바: 3주차/4주
- 부모 뷰: 로보마켓 체험 배너와 시즌 리워드 안내
- 전 화면 공통 민지↔엄마 스위처

### 4.1 튜토리얼

첫 진입에는 코치마크 3장을 제공한다.

1. 홈 구성과 순위
2. 매매 진입
3. 키웅이 소개 — “궁금한 건 언제든 키웅이한테 물어봐”

### 4.2 온보딩 — 와이어프레임만

부모 리그 만들기 → 초대 코드 → 자녀 수락과 법정대리인 동의 → 구성원별 가상 100만원 지급 순서다.

건별 부모 승인은 없다. **단일종목 한도도 없다 [확정 2026-08-13]** — 부모·자녀 모두 한 종목에 지갑 전액을 넣을 수 있다. 잔액 초과 주문만 차단하고 이유를 안내한다.

## 5. 기능 간 데이터 흐름

```text
F0 리그 설정 ───────────────────────────────┐
F2 매수 직전 유효 열람(탭 진입 + 10초 이상) ─┼→ shared/engine → F9 능력치 5개·캐릭터·정확 레벨 JSON → Luna 서술 → 공통 필터 → F9 화면
F2 보유 섹터·현금비중·체결 후 5거래일 적중 ──┘
F3 근거·확신도·예상 보유기간 → 거래 기록 저장 (F9 캐릭터 판정 입력 아님)

F2 주문·상세 이벤트 → F10 선제 신호 3종 → 고정 발화
F10 자유 질문 → 사전·FAQ·승인 조회 → 필요한 경우 Luna 1회 → 전체 출력 게이트 → SSE
F10 구조화 메타 로그(대화 원문 제외) → 안전·활성 지표만 사용, F9 스코어링·부모 전달 금지
```

## 6. 데모 골든 패스

1. 홈에서 튜토리얼, 가족 순위, 수익률, 포트폴리오를 확인한다.
2. 민지가 종목을 탐색하고 상세의 추천 질문 “PER이 뭐야?”를 키웅이에게 묻는다.
3. 매수·매도 확인창 취소를 번갈아 3회 반복해 키웅이의 고정 선제 도움을 확인한다.
4. 매수 근거 “그냥 느낌이 좋아”, 확신도 25, 예상 보유기간을 기록하고 체결한다.
5. “뭐 사면 돼?” 질문이 고정 거절되는 것을 확인한다.
6. 아카이브에서 새 거래가 능력치 오각형과 캐릭터·정확 레벨에 반영된 것을 확인한다.
7. 엄마로 전환해 엄마 리포트와 중립적인 가족 비교를 확인한다.
8. 발표 슬라이드에서 스코어링 엔진·필터 로그·선제 신호·컴플라이언스 쟁점을 설명한다.
