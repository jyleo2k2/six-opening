## F8. 행동 분석 기반 가족 AI펫 — **메인 기능** (§6, 원안 `펫서비스기획.md`)

> 아이의 투자 행동을 관찰해, 그 결과를 대화가 아니라 가족이 함께 키우는 펫의 상태로 표현한다. **자유 입력 없음** — 펫이 먼저 감지·발화하고, 아이는 열람+선택지로 반응한다.

### 구성

1. **상시 존재**: 홈에 펫이 항상 떠 있음 (상태·컨디션 반영 표정). 탭하면 펫 화면으로.
2. **감지→리액션** (§6.3): 행동 프로파일 엔진(규칙, 상시)이 트리거 판단 → 임계치 통과 시만 LLM이 문구 생성 → 펫 애니메이션(갸우뚱 등)+열어볼 수 있는 말풍선. 강제 팝업 아님.
   - MVP 트리거 2종: **확신도 급락**(평소 대비 크게 낮은 확신도로 매수 시도, 예: 25) / **긴 망설임**(종목 상세 5분+ 체류 또는 확신도 100인데 체류 이례적으로 김)
   - 되묻기 원칙: 정답·훈계 금지, 항상 질문 또는 선택지로 마무리 — "확신이 낮아 보이는데, 이유가 있어?" + 선택지("뉴스가 헷갈려서" / "그냥 사보고 싶어서" / "다시 생각해볼래")
3. **오늘의 순간** (부모 화면, 일 1회, §6.4): 이례 순간 1건만 번역 전달 — "오늘 민지가 확신이 낮은데도 ○○을 샀어요. '그냥 사보고 싶어서'라고 해요." + 대화 시작 제안 1줄.
   - **투명성**: 같은 카드가 민지 화면에도 표시 — "통통이가 오늘 엄마한테 이 얘기를 물어다 줬어."
4. **주간 질문** (§6.5): 주간 데이터 기반 질문 1개 → 각자 답변(상대 답 비공개, "엄마가 아직 안 썼어요 🔒") → **둘 다 답하면 동시 공개** → 펫이 공통점/차이 정리.
5. **성장 시스템** (§6.6): 성장 단계(레벨)+컨디션 = 소통량 함수(주간 질문 양측 응답, 순간 열람). 수익률 무관. 둘 다 답하면 밝아지고 한쪽 무응답이면 시무룩.

### 파이프라인 (§6.9 — 발표 기술 증거)

```
행동 이벤트(확신도·태깅·체류) → [행동 프로파일 엔진: 규칙·통계, 상시] → 임계치?
→ (통과 시만) [LLM: 펫 문구·순간 번역·주간 질문 생성] → [출력 필터: 추천·시점·가격·훈계 차단 + 로깅] → 화면
```

LLM은 수치를 계산하지 않는다. 판단력 채점 없음. 필터는 F8·F9 공통.

### 데이터

입력: F2 거래 로그, F3 근거·확신도, 체류·탭 이벤트 / 출력: 펫 상태, 감지 순간 로그, 주간 질문·답변. 엔진이 단일 진실 원천.

## F0. 홈 & 가족리그 설정 (§5.1·§7)

> 진입·재방문의 중심. 펫이 상주한다.

- **홈**: 펫(상태 표정, 탭→F8 펫 화면) / 우리 가족 현재 순위 / 부모·자녀 각각 수익률 / 모의투자 바로가기 / 주간 질문 예고("통통이가 토요일에 질문을 가져와요!") / 부모 뷰: '오늘의 순간' 카드 + 로보마켓 체험권 배너 / 시즌 리워드 안내 / 시즌 진행바(4주차/8주)
- **튜토리얼**: 첫 진입 시 코치마크 3장 (① 홈 구성·순위 ② 펫 소개 — "얘는 우리 가족이 함께 키우는 통통이야" ③ 매매 진입) — 데모 시작 장면 겸용
- **개설 플로우**(와이어프레임만, 데모는 완료 상태 시작): 부모 리그 만들기 → 초대 코드 → 자녀 수락(법정대리인 동의 — 형식) → 프리셋(입문형 ≤30% / 성장형 ≤40%) → 가상금 1,000만 지급 → **펫 이름 함께 짓기**(첫 공동 행위)
- 건별 승인 없음. 한도 초과 주문 차단+안내. 위험행동 시 부모 코칭 알림 1종(데모): "차단하기보다 투자 이유를 먼저 물어보시겠습니까?"

## F2. 모의투자 (§5.1·5.2)

> 각자 독립 포트폴리오 자유 매매. 데이터 원천. 시세는 키움 REST API.

- 종목 탐색(검색·업종 칩) → **종목 상세**: 현재가·차트·내 보유/수익률 + **아이 눈높이 설명**("이 회사는 무슨 일을 해?" / "최근 무슨 일이 있었어?") + 매수/매도
- 종목 상세의 체류시간·탭 전환이 F8 관찰 데이터로 수집됨 (§6.2)
- 주문: 수량 → 예상 금액 → **F3 질문식 기록**(플로우 내장) → 시장가 즉시 체결
- 포트폴리오(보유종목): 보유·평가손익·현금

## F3. 질문식 매매 기록 (§5.3)

> 주문 직전 근거 태깅+확신도+한 줄. '제안서'가 아니라 펫·아카이브용 생각 데이터.

- **매수 근거** 선택(필수): 뉴스에서 봤어 / 차트가 좋아 보여 / 친구·가족이 추천했어 / 이 회사(제품)를 잘 알아 / 그냥 느낌이 좋아 — 근거 유형 5축(뉴스·차트·추천·지식·느낌)
- **확신도**(매수 시 필수): 펫이 묻는 프레이밍 "통통이가 궁금해해 — 얼마나 자신 있어?" 4단계: 잘 모르겠어(25) / 조금(50) / 꽤(75) / 완전(100). 슬라이더 아님 — 탭 1회. 정답·채점 없음 문구 병기.
- **매도 근거** 선택(필수): 목표한 만큼 올랐어 / 더 떨어질까 봐 걱정돼 / 다른 종목이 더 좋아 보여 / 그냥 불안해 / 기타
- 내 생각 한 줄(선택). 체결 완료 화면: "기록 완료! 통통이가 기억해둘게" (컨페티)
- 확신도 값·근거 유형이 F8 트리거와 F9 성향 리포트의 핵심 입력

## F9. 아카이브 (§6.7)

> AI 성향 리포트 + 수익률 리포트 → 가족 성장기록.

1. **AI 성향 리포트** (주간, 부모·자녀 각각): 근거 태깅 분포 / 확신도 패턴(평균·행동 일치) / 관심 업종 / 투자 빈도 / 포트폴리오 구성 + **유형 라벨**(재미 요소, 주간 갱신: 민지 "뉴스 사냥꾼형" 등, 엄마 "분석가형" 등) + 잘한 점·놓친 점 각 1~2개
2. **수익률 리포트**: 수익률 추이·평가손익 (정량엔진 산출 그대로, LLM 서술 없음)
3. **가족 성장기록** (시즌 뷰): 시즌 초↔현재 비교 — 근거 구체성('느낌' 비중 변화) / 업종 다양성 / 확신도-행동 일치 / 주간 질문 참여 + **펫 성장 비포/애프터**. 데모는 4주차 기준 중간 기록 + 시즌 말 목업 카드 1장.
- LLM은 서술만: 엔진 지표 JSON → 서술·라벨 생성 → 공통 필터 → 화면

## 데모 골든 패스 (발표 시연 순서)

1. **홈**(민지 뷰, 4주차): 튜토리얼 코치마크 → 펫 "통통이" 소개·가족 순위·수익률
2. 민지: 종목 탐색 → 상세(아이 눈높이 설명, 체류) → 매수 → **질문식 기록**: 근거 "그냥 느낌이 좋아" + 확신도 25
3. **펫 리액션**: 통통이 갸우뚱 → 말풍선 열람 "확신이 낮아 보이는데, 이유가 있어?" → 선택지 응답
4. 엄마 전환: **오늘의 순간** 카드 "오늘 민지가 확신이 낮은데도 ○○을 샀어요" → (민지 화면에도 동일 표시 — 투명성 시연)
5. **주간 질문**: "어떤 기준으로 종목을 골랐어?" → 각자 답 → 동시 공개 → 펫 정리 → **펫 컨디션 밝아짐**(성장 연출)
6. **아카이브**: 민지 성향 리포트("뉴스 사냥꾼형") → 수익률 → 가족 성장기록(펫 비포/애프터)
7. (슬라이드) 분리 구조·필터 로그 / 리워드·계좌 정책·로보마켓 / 컴플라이언스 쟁점

## 미결정 (다음 단계 이관)

1. **키움 REST API** 앱키 발급·모의투자 환경 범위 → 기술스택 단계. 발급 전 픽스처.
2. 시드 데이터 시나리오(민지=뉴스·느낌 반응형, 엄마=실적 확인·안정형 — 성향 리포트·펫 감지 순간과 일치하게) → 구현 직전.
3. 펫 캐릭터 에셋 — 신규 vs 기존 마스코트(곰·소) 통합(§15-7). 데모는 플레이스홀더+이름 라벨.
4. 펫 트리거 임계치 수치(확신도 기준·체류 기준) — 시드 데이터에 맞춰 구현 직전 확정.
5. 가족 순위 산식(합산 vs 평균) — 데모는 "12위 / 340가족" 식 목업 표기로 충분.
