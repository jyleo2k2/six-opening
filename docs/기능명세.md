## F8. 행동 분석 기반 AI 투자코치 — **메인 기능** (§6)

> 각 사용자의 투자 행동을 관찰하는 **선발화·선택지형 AI 코치**. 자유 입력은 없고, 코치가 먼저 감지·발화하면 사용자는 열람+선택지로만 반응한다. 부모에게 자녀 행동을 전달하거나 가족 관계를 점수화하지 않는다.

### 구성

1. **상시 존재**: 홈에 AI 코치가 항상 떠 있음. 탭하면 코치 이력 화면으로.
2. **감지→리액션**: 행동 프로파일 엔진(규칙, 상시)이 트리거 판단 → 임계치 통과 시만 LLM이 문구 생성 → 열어볼 수 있는 말풍선. 강제 팝업 아님.
   - MVP 트리거 2종: **확신도 급락**(평소 대비 크게 낮은 확신도로 매수 시도, 예: 25) / **긴 망설임**(종목 상세 5분+ 체류 또는 확신도 100인데 체류 이례적으로 김)
   - 되묻기 원칙: 정답·훈계 금지, 항상 질문 또는 선택지로 마무리 — "확신이 낮아 보이는데, 이유가 있어?" + 선택지("뉴스가 헷갈려서" / "그냥 사보고 싶어서" / "다시 생각해볼래")
3. **개별 반응 이력**: 사용자가 열람한 코치 발화·선택 응답만 개인 화면에 기록한다. 부모·자녀 간 행동 데이터는 AI 경로로 공유하지 않는다.

### 파이프라인 (§6.9 — 발표 기술 증거)

```
행동 이벤트(확신도·태깅·체류) → [행동 프로파일 엔진: 규칙·통계, 상시] → 임계치?
→ (통과 시만) [LLM: AI 코치 문구 생성] → [출력 필터: 추천·시점·가격·훈계 차단 + 로깅] → 개인 화면
```

LLM은 수치를 계산하지 않는다. 판단력 채점 없음. 필터는 F8·F9 공통.

### 데이터

입력: F2 거래 로그, F3 근거·확신도, 체류·탭 이벤트 / 출력: 개인 코치 발화·선택 응답 로그. 엔진이 단일 진실 원천.

## F0. 홈 & 가족리그 설정 (§5.1·§7)

> 진입·재방문의 중심. AI 코치가 상주한다.

- **홈**: AI 코치(탭→F8 코치 이력) / 우리 가족 현재 순위 / 부모·자녀 각각 수익률·기여도 / 모의투자 바로가기 / 로보마켓 체험권 배너 / 시즌 리워드 안내 / 시즌 진행바(6주차/3개월)
- **튜토리얼**: 첫 진입 시 코치마크 3장 (① 가족 대시보드·순위 ② AI 코치 소개 — "고민될 때 먼저 물어볼 거야" ③ 매매 진입) — 데모 시작 장면 겸용
- **개설 플로우**(와이어프레임만, 데모는 완료 상태 시작): 부모 리그 만들기 → 자녀 계좌 확인·초대 코드 → 자녀 수락(법정대리인 동의 — 형식) → 가상금 1,000만 지급
- 건별 승인 없음. 한도 초과 주문 차단+안내. 위험행동은 해당 사용자의 AI 코치가 선택지형 되묻기로 안내한다.

## F2. 모의투자 (§5.1·5.2)

> 각자 독립 포트폴리오 자유 매매. 데이터 원천. 시세는 키움 REST API.

- 종목 탐색(검색·업종 칩) → **종목 상세**: 현재가·차트·내 보유/수익률 + **아이 눈높이 설명**("이 회사는 무슨 일을 해?" / "최근 무슨 일이 있었어?") + 매수/매도
- 종목 상세의 체류시간·탭 전환이 F8 관찰 데이터로 수집됨 (§6.2)
- 주문: 수량 → 예상 금액 → **F3 질문식 기록**(플로우 내장) → 시장가 또는 지정가 체결. 수수료·세금은 실제 수준으로 안내한다.
- 포트폴리오(보유종목): 보유·평가손익·현금

## F3. 질문식 매매 기록 (§5.3)

> 주문 직전 근거 태깅+확신도+한 줄. '제안서'가 아니라 펫·아카이브용 생각 데이터.

- **매수 근거** 선택(필수): 뉴스에서 봤어 / 차트가 좋아 보여 / 친구·가족이 추천했어 / 이 회사(제품)를 잘 알아 / 그냥 느낌이 좋아 — 근거 유형 5축(뉴스·차트·추천·지식·느낌)
- **확신도**(매수 시 필수): 펫이 묻는 프레이밍 "통통이가 궁금해해 — 얼마나 자신 있어?" 4단계: 잘 모르겠어(25) / 조금(50) / 꽤(75) / 완전(100). 슬라이더 아님 — 탭 1회. 정답·채점 없음 문구 병기.
- **매도 근거** 선택(필수): 목표한 만큼 올랐어 / 더 떨어질까 봐 걱정돼 / 다른 종목이 더 좋아 보여 / 그냥 불안해 / 기타
- 내 생각 한 줄(선택). 체결 완료 화면: "기록 완료! 통통이가 기억해둘게" (컨페티)
- 확신도 값·근거 유형이 F8 트리거와 F9 성향 리포트의 핵심 입력

## F9. 아카이브 (§6.7)

> AI 성향 리포트 + 수익률 리포트 → 개인 투자 기록. 가족 대시보드는 수익률·기여도 비교만 제공한다.

1. **AI 성향 리포트** (주간, 부모·자녀 각각): 근거 태깅 분포 / 확신도 패턴(평균·행동 일치) / 관심 업종 / 투자 빈도 / 포트폴리오 구성 + **유형 라벨**(재미 요소, 주간 갱신: 민지 "뉴스 사냥꾼형" 등, 엄마 "분석가형" 등) + 잘한 점·놓친 점 각 1~2개
2. **수익률 리포트**: 수익률 추이·평가손익 (정량엔진 산출 그대로, LLM 서술 없음)
3. **시즌 투자 기록** (개인 뷰): 시즌 초↔현재 비교 — 근거 구체성('느낌' 비중 변화) / 업종 다양성 / 확신도-행동 일치. 데모는 6주차 기준 중간 기록 + 시즌 말 목업 카드 1장.
- LLM은 서술만: 엔진 지표 JSON → 서술·라벨 생성 → 공통 필터 → 화면

## 데모 골든 패스 (발표 시연 순서)

1. **홈**(민지 뷰, 6주차): 튜토리얼 코치마크 → AI 코치 소개·가족 순위·각자 수익률·기여도
2. 민지: 종목 탐색 → 상세(아이 눈높이 설명, 체류) → 매수 → **질문식 기록**: 근거 "그냥 느낌이 좋아" + 확신도 25
3. **AI 코치 리액션**: 말풍선 열람 "확신이 낮아 보이는데, 이유가 있어?" → 선택지 응답
4. 엄마 전환: 자신의 독립 포트폴리오와 가족 대시보드의 수익률·기여도 비교 확인
5. **아카이브**: 민지 성향 리포트("뉴스 사냥꾼형") → 수익률 → 개인 시즌 투자 기록
6. (슬라이드) 분리 구조·필터 로그 / 리워드·계좌 개설 참가 정책·로보마켓 / 컴플라이언스 쟁점

## 미결정 (다음 단계 이관)

1. **키움 REST API** 앱키 발급·모의투자 환경 범위 → 기술스택 단계. 발급 전 픽스처.
2. 시드 데이터 시나리오(민지=뉴스·느낌 반응형, 엄마=실적 확인·안정형 — 성향 리포트·AI 코치 감지와 일치하게) → 구현 직전.
3. AI 코치 캐릭터 에셋 — 신규 vs 기존 마스코트(곰·소) 통합. 데모는 플레이스홀더+이름 라벨.
4. AI 코치 트리거 임계치 수치(확신도 기준·체류 기준) — 시드 데이터에 맞춰 구현 직전 확정.
5. 가족 순위 산식(합산 vs 평균) — 데모는 "12위 / 340가족" 식 목업 표기로 충분.
