## F1. 주간 AI 리포트 패키지 — **메인 기능** (§6.2·6.3·6.5)

> 주 1회 '가족 투자편지'로 도착: 개인 투자리포트 → 가족 비교 → 투자궁합. 시즌 말 성장리포트.

### 구성

1. **개인 리포트** (부모·자녀 각각)
   - 분석 지표: 관심 업종 / 매수·매도 이유 분포 / 투자 빈도 / 위험요인 고려 여부 / 중시 요소(성장성·실적·뉴스) / 포트폴리오 구성 / 수익률
   - **이번 주 유형 라벨**(재미 요소, 매주 갱신): 민지 "뉴스 사냥꾼형" 등 / 엄마 "분석가형" 등
   - 이번 주 잘한 점·놓친 점 (각 1~2개)
2. **가족 비교**: 두 사람의 관점 차이와 공통점 → 투자토크(F4) 질문으로 연결
3. **가족 투자궁합**: "이번 주 우리 가족 투자궁합 76%" + 관점 한 줄 대비 ("민지는 '앞으로 잘될까?'를, 엄마는 '지금 잘하고 있을까?'를 봤어요"). 실제 행동·이유 데이터 기반
4. **(시즌 말) 성장리포트**: 시즌 초↔말 변화 — 데모는 목업 1장

### 파이프라인 (§6.6 — 발표 기술 증거)

```
거래·이유·토크 로그 → [정량엔진: 지표 JSON 계산 (룰)] → [LLM: 서술·라벨·궁합·질문 생성]
→ [출력 필터: 추천·시점·가격 표현 차단 + 탐지 로깅] → 화면
```
LLM은 숫자를 계산하지 않고, 정량엔진 산출만 입력받는다. 필터는 F1·F4·F7 공통. 데이터 적은 초기엔 "아직 관찰 초기" 문구.

### 화면

투자편지 인트로(키웅이, "이번 주 우리 가족 궁합은 몇 %일까요?") → 개인 리포트(유형 카드+지표+잘한점/놓친점) → 가족 비교 → **궁합 결과(큰 %)** → "투자토크 하러 가기" CTA

### 데이터

입력: F2 거래 로그, F3 이유 기록, F4 토크 로그 / 출력: 리포트 JSON. 정량엔진이 단일 진실 원천.

## F0. 홈 & 가족리그 설정 (§5.1·§7)

> 진입·재방문의 중심. 팀공유 홈 구성 그대로.

- **홈**: 우리 가족 현재 순위 / 부모·자녀 각각 수익률 / 모의투자 바로가기 / 이번 주 가족 투자편지 예고("💌 토요일 도착! 이번 주 궁합은 몇 %일까요?") / 부모 뷰: 로보마켓 체험권 배너 / 시즌 리워드 안내 / 시즌 진행바(4주차/8주)
- **개설 플로우**(와이어프레임만, 데모는 완료 상태 시작): 부모 리그 만들기 → 초대 코드 → 자녀 수락(법정대리인 동의 — 형식) → 프리셋(입문형 ≤30% / 성장형 ≤40%) → 가상금 1,000만 지급
- 건별 승인 없음. 한도 초과 주문 차단+안내. 위험행동 시 부모 코칭 알림 1종(데모): "차단하기보다 투자 이유를 먼저 물어보시겠습니까?"

## F2. 모의투자 (§5.1·5.2)

> 각자 독립 포트폴리오 자유 매매. 데이터 원천.

- 종목 탐색(검색·업종 칩) → **종목 상세**: 현재가·차트·내 보유/수익률 + **아이 눈높이 설명**("이 회사는 무슨 일을 해?" / "최근 무슨 일이 있었어?") + **AI 선생님 호출 버튼**(종목 맥락 전달) + 매수/매도
- 주문: 수량 → 예상 금액 → **F3 이유 기록**(플로우 내장) → 시장가 즉시 체결
- 포트폴리오: 보유 종목·평가손익·현금

## F3. 매수·매도 이유 기록 (§5.3)

> 주문 직전 선택형+한 줄. '제안서'가 아니라 AI 분석용 생각 데이터.

- **매수**: 왜 사고 싶은지 선택(성장할 것 같아서 / 좋은 뉴스를 봐서 / 제품·서비스가 잘될 것 같아서 / 가격이 싸다고 생각해서 / 그냥 관심 있는 회사라서) + 내 생각 한 줄(선택)
- **매도**: 왜 팔려고 하는지 선택(충분히 올랐다고 생각해서 / 앞으로 떨어질 것 같아서 / 다른 회사에 투자하고 싶어서 / 손실이 더 커질까 걱정돼서 / 기타) + 내 생각 한 줄(선택)
- 선택형 필수, 서술 선택. 체결 완료 화면: "기록 완료! AI가 기억해둘게" (컨페티)

## F4. 가족 투자토크 (§6.4)

> AI가 두 사람의 실제 투자 차이로 주 1회 질문 생성, 동시 공개. 채팅 아님.

- Flow: AI 질문 1개(주간 데이터 기반) → 각자 답변(상대 답 비공개, "엄마가 아직 안 썼어요 🔒") → **둘 다 답하면 동시 공개** → AI 공통점/차이 정리 → 궁합(F1) + 다음 주 미션 카드
- 시연 질문: "인기는 많은데 아직 돈을 못 벌고 있는 회사라면 우리 가족은 투자할까?"

## F7. AI 투자 선생님 (§6.1)

> 아이용 교육 챗봇. 로보마켓의 아이 버전 포지션(§8).

- 진입: 홈 탭 + 종목 상세(맥락 자동 전달 — "지금 삼성전자 보고 있구나!")
- 예시 질문 칩: "PER이 뭐야?" / "반도체가 뭐야?" / "이 회사는 어떻게 돈을 벌어?" / "오늘 왜 주가가 올랐어?"
- **원칙**: "사라/팔아라" 직접 답 금지 → 쉬운 설명+되물음. "사도 돼?" → "내가 대신 정해주진 않을게. 왜 사고 싶은지 먼저 생각해볼까?"
- 구현: 시스템 프롬프트(원칙+아이 눈높이+키웅이 페르소나) + F1 공통 필터 + 전 응답 로깅(§12-8)
- UI: 키웅이 아바타, 둥근 말풍선

## 데이터 흐름

```
F0 리그 설정(프리셋·한도) ─┐
F2 거래 로그 ─────────────┼→ 정량엔진(지표 JSON) ─┬→ F1 리포트·궁합 (LLM 서술 → 필터)
F3 이유 기록 ─────────────┤                        └→ F4 질문 생성 (LLM → 필터)
F4 토크 답변 로그 ─────────┘
F7 선생님: 종목 맥락+질문 → LLM → 공통 필터 → 응답 (지표와 무관, 필터·로깅만 공유)
```

## 데모 골든 패스 (발표 시연 순서)

1. **홈**(민지 뷰, 4주차): 가족 순위·수익률·투자편지 예고
2. 민지: 종목 탐색 → 상세(아이 눈높이 설명) → **AI 선생님** "이 회사 어떻게 돈 벌어?" → "사도 돼?" 회피 원칙 시연 → 매수 + **이유 기록**
3. 엄마 전환: 같은 종목 다른 판단(관망 or ETF 매수)
4. **투자편지**: 민지 리포트("뉴스 사냥꾼형") → 가족 비교 → **궁합 76%**
5. **투자토크**: 질문 → 각자 답 → 동시 공개 → AI 정리
6. (슬라이드) 분리 구조·필터 로그 / 리워드·계좌 정책·로보마켓 / 성장리포트 목업

## 미결정 (다음 단계 이관)

1. **시세 데이터 방식** → 기술스택 단계. 추천: 과거 리플레이.
2. LLM 모델·호출 구조(서버 경유) → 기술스택 단계.
3. 시드 데이터 시나리오(민지=뉴스 반응·단기형, 엄마=실적 확인·안정형 — 리포트·궁합 결과와 일치하게) → 구현 직전.
4. 캐릭터 에셋(영웅이·키웅이) — 직접 제작 or 플레이스홀더.
5. 가족 순위 산식(합산 vs 평균) — 데모는 "12위 / 340가족" 식 목업 표기로 충분.
