# 키움 가족 모의투자 리그 — 전체 기획서

> 기준 커밋: GitHub `main` `bfea45a` (2026-08-10). 이 문서는 `기획서.md`와 `기능명세.md`의 발표·협업용 통합본이다.

## 서비스 정의

부모와 자녀가 **각자의 포트폴리오로 모의투자**하고, 가족 대시보드에서 수익률·기여도·순위를 함께 비교·확인하는 가족형 모의투자 리그다. 부모는 교사가 아니라 같은 팀의 투자 파트너이며, 자녀는 독립적으로 판단하고 거래한다.

대상은 키움 계좌를 보유한 부모와 초등 고학년~중학생 자녀다. 부모와 자녀 모두 계좌를 개설한 뒤 가족팀으로 참가한다. 목표는 아이의 첫 투자 경험, 가족의 금융 대화, 키움의 세대 고객 연결이다.

## 문제와 기회

- 아이는 투자·경제를 직접 경험하며 배울 기회가 부족하다.
- 부모는 투자 전문가가 아닐 수 있어 교육 부담을 느낀다.
- 기존 청소년 금융 서비스는 용돈·결제 중심이고, 모의투자는 개인 수익률 경쟁 중심이다.
- 키움의 그룹 모의투자, 영웅문S#, 미성년 계좌 인프라는 가족형 리그로 확장할 기반이다.

차별점은 가족이 함께 주문하거나 서로를 감시하는 데 있지 않다. 각자 판단을 기록하고, 같은 가족 대시보드에서 투자 결과를 비교·확인하는 데 있다.

## 확정 원칙

| 영역 | 결정 |
|---|---|
| 투자 구조 | 부모·자녀의 독립 포트폴리오와 가족 대시보드 비교 |
| AI | 불안 행동을 감지해 먼저 말을 걸고, 승인된 지식 범위에서 자연어 대화하는 AI 투자코치 |
| AI 제외 범위 | 부모 전달 카드, 주간 질문·동시 공개, 펫 성장·컨디션, 판단력 채점 |
| 시즌 | 3개월 1시즌, 동일 가상금 시작, 종료 시 시드 리셋·개인/가족 리포트 |
| 투자 범위 | **한국 기업 주식 50종목만** 제공 |
| 거래 안전 | 15~20분 지연시세, 시장가·지정가, 수수료·세금 안내, 매도 후 30분 재매수 제한 |
| 참가 | 부모와 자녀 모두 키움 계좌 개설 후 참가 |

## 사용자 여정

1. 부모가 영웅문S#에서 가족 리그를 만들고 자녀를 초대한다.
2. 자녀 계좌와 법정대리인 동의를 확인하고 동일 가상금을 지급한다.
3. 부모와 자녀가 각자 종목을 탐색·매수·매도한다.
4. 주문 전 근거와 확신도를 기록한다.
5. AI 코치가 행동 신호를 감지해 먼저 "고민 있어?"라고 말을 걸고, 자녀가 열면 자연어 대화를 시작한다.
6. 가족 대시보드에서 가족·개인 수익률, 기여도, 순위를 확인한다.
7. 주간 아카이브와 시즌 투자 기록을 개인별로 확인한다.

## 핵심 기능

### F0. 홈·가족 리그

- 가족 순위·수익률, 부모·자녀별 수익률·기여도, 시즌 진행률
- AI 코치 진입, 모의투자 바로가기, 리워드·로보마켓 체험권 안내
- 리그 개설: 부모 생성 → 자녀 계좌 확인·초대 → 수락·동의 → 가상금 지급
- 단일 종목 한도 프리셋 적용, 주문별 부모 승인 없음

### F2. 모의투자

- 한국 기업 주식 50종목의 검색·업종 필터·상세·포트폴리오
- 종목 상세: 현재가, 간단 차트, 보유·수익률, 아이 눈높이 기업 설명
- 키움 REST API 우선, 장외·장애 시 캐시와 픽스처 사용
- 시장가·지정가 주문, 데모는 시장가 즉시 체결

### F3. 질문식 매매 기록

- 매수 근거(필수): 뉴스, 차트, 친구·가족 추천, 회사·제품 지식, 느낌
- 매수 확신도(필수): 25·50·75·100의 네 단계. 정답·채점 없음
- 매도 이유(필수): 목표 달성, 하락 우려, 다른 종목 선호, 불안, 기타
- 선택 한 줄 메모. 모든 기록은 AI 코치와 아카이브의 입력값

### F8. 행동 분석 기반 AI 투자코치

- 개인별 코치이며, 선발화 말풍선을 열면 텍스트 입력 채팅을 제공한다.
- 거래·근거·확신도·상세 체류시간·탭 전환을 관찰한다.
- 확신도 급락, 긴 망설임, 말과 행동의 불일치에서만 반응한다.
- 강제 팝업 대신 열람 가능한 말풍선으로 "고민 있어?", "궁금한 거 있어?"라고 시작한다.
- 자연어 질문은 한국 기업 50종목의 공개 정보, 자녀 본인의 성향 분석·아카이브, 서비스·금융 기초에만 답한다.
- 추천·시점·가격·수익률 전망·훈계는 차단하고, 코치 반응과 대화 원문은 개인별로만 기록한다.

### F9. 아카이브

- 개인 AI 성향 리포트: 근거 분포, 확신도 패턴, 관심 업종, 투자 빈도, 유형 라벨
- 수익률 리포트: 보유·평가손익·수익률 추이
- 시즌 투자 기록: 근거 구체성, 업종 다양성, 확신도와 행동 일치의 변화
- 가족 대시보드는 비교용, 아카이브는 개인 투자 기록용으로 역할을 분리한다.

## AI 안전 구조

`행동 이벤트 → 규칙 기반 행동 프로파일 엔진 → 임계치 통과 시 LLM → 출력 필터 → 개인 화면`

- 행동 엔진이 모든 수치 계산과 트리거 판정을 담당한다.
- LLM은 선발화·승인된 범위의 채팅 답변·아카이브 서술만 생성하며, 종목 카탈로그·개인 아카이브·서비스 규칙을 서버에서 조회한다.
- 모든 출력은 공통 필터를 거친다. 종목 추천, 매수·매도 시점, 목표가·손절가, 수익률 전망, 훈계 표현은 차단·로그 기록한다.
- AI는 투자자문이 아닌 관찰·메타인지 보조다.

## 리그·보상·안전장치

- 가족 단위 순위를 제공하되, 단일 종목 한도·질문식 매매·재매수 쿨다운으로 수익률 경쟁의 부작용을 줄인다.
- ETF·ETN, 파생상품, 신용·미수, 공매도, 가상자산, 초저유동성 상품은 제외한다.
- 아이용 리워드, 가족 경험형 리워드, 부모 로보마켓 체험권을 검토한다.
- 경품과 수익률 순위의 사행성·규제 적정성은 법무 검토 대상이다.

## KPI·PoC

최상위 지표는 최근 30일 내 부모와 자녀가 각각 한 번 이상 활동한 **월간 활성 가족 팀 수**다.

| 지표 | 초기 목표 |
|---|---|
| 초대 발송 → 자녀 가입 전환 | 40% |
| 자녀 D28 리텐션 | 30% |
| 매수 이유 태깅률 | 80% |
| AI 코치 개입 후 대화 지속률 / 뮤트율 | 50% / 20% 미만 |
| 부모 월간 리포트 열람률 | 60% |
| 모의 90일 완주 후 전환 | 15% |

- 부모 30명 인터뷰·사전예약 랜딩으로 가족 참여 수요를 확인한다.
- 자녀 15명 대상으로 4주 프로토타입을 운영해 D28 리텐션을 검증한다.
- 위저드오브오즈 방식으로 AI 코치의 선제 개입에 대한 거부감과 뮤트율을 확인한다.

## MVP·기술 원칙

데모는 부모 1명과 초등 고학년 자녀 1명, 3개월 시즌 6주차 시드 데이터를 사용한다. 한 기기에서 계정 스위처로 시연한다.

- 화면: 홈, 종목 상세, 매수 기록, 매도 기록, AI 코치 이력, 가족 대시보드, 아카이브
- 스택: Next.js App Router, TypeScript, Tailwind CSS, zustand + localStorage
- 시세: 키움 REST API와 폴백 캐시. 발표 전에는 픽스처 우선 구현
- LLM과 시세 키는 서버 전용. 모든 AI 출력은 `shared/llm` 필터를 경유
- 구현 검증: `npm run build`

## 컴플라이언스·미결정

- 투자자문 경계, 미성년 개인정보·법정대리인 동의, 가족 결과 공유 범위, 경품 규제, 계좌 개설 표현, 자동 성향 분류 고지는 법무 검토가 필요하다.
- 키움 REST API의 앱키 발급과 모의투자 지원 범위를 구현 전에 확인한다.
- 실제 50종목 목록과 리밸런싱 주기, 순위 산식, AI 트리거 임계치, 캐릭터 에셋은 다음 단계에서 확정한다.
