## 1. 서비스 정의

**키움 가족 모의투자 리그**는 부모와 자녀가 각자 모의투자하고, 거래·탐색·기록 행동을 기반으로 각자의 투자 성향을 읽어주는 가족형 서비스다. 자녀 옆에는 눈높이 AI 챗봇 **키웅이**가 상주한다.

> “아이는 그냥 투자해보면 된다 — 방법은 키웅이가 알려주고, 내 투자 스타일은 AI가 읽어준다.”

핵심은 가족이 함께 주문하거나 자녀를 감시하는 데 있지 않다. 부모와 자녀가 독립적으로 투자한 뒤, 성향 리포트와 가족 비교를 통해 서로의 스타일을 이해하고 대화 소재를 얻는 데 있다.

### 목표

- 아이가 경제·투자를 직접 경험하며 배운다.
- 부모가 투자 전문가가 아니어도 AI 도움을 받아 자녀와 투자 대화를 시작한다.
- 키움은 기존 부모 고객의 활동을 높이고, 자녀의 첫 투자 경험을 장기 고객 관계로 연결한다.

## 2. 사용자와 리그 구조

| 역할 | 하는 일 |
|---|---|
| 부모 | 키움 계좌 보유자. 자녀와 같은 가족팀으로 참여하되, 본인 포트폴리오를 별도로 운용한다. 아카이브에서 각자의 리포트와 가족 비교를 확인한다. |
| 자녀 | 초등 고학년~중학생. 부모의 건별 승인 없이 모의투자하고, 사용법·개념·기록 관련 질문을 키웅이에게 한다. |

### 기본 여정

1. 부모가 영웅문S#에서 가족 리그를 개설한다.
2. 자녀를 초대하고, 미성년자는 법정대리인 동의를 거친다. [사실 — 개인정보보호법 제22조의2]
3. 시즌 프리셋을 선택하고 전원에게 같은 가상금을 지급한다.
4. 각자 종목을 탐색하고 주문하며, 주문 과정에서 근거와 확신도를 기록한다.
5. 매주 행동 스코어링을 바탕으로 개인 리포트와 가족 비교를 갱신한다.
6. 시즌 종료 시 성향 변화와 수익률 결산을 기록하고 리워드를 제공한다.

### 시즌·투자 규칙

- **v7 우선 결정:** 3개월 시즌, 한국 기업 주식 50종목만 제공.
- 전원 동일 가상금으로 시작하며 부모 1명 + 자녀 1명 이상이 한 가족팀을 이룬다.
- 시장가·지정가 주문을 설계하고 실제 수준의 수수료·세금을 안내한다. 데모는 시장가 즉시 체결이다.
- 동일 종목을 매도한 뒤 30분간 재매수하지 못하게 해 단타를 억제한다.
- 부모가 복잡한 설정을 하지 않도록 단일 종목 비중 한도 프리셋을 제공한다. 건별 주문 승인은 없다.
- 레버리지·인버스 ETF, ETN, 파생상품, 신용·미수, 공매도, 가상자산, 초저유동성 상품은 제외한다.

> **정합성 메모 [미확정]:** 본문 일부에는 “8주·국내주식+일반 ETF 약 30종”이 남아 있다. 이 문서는 v7 우선 결정인 “3개월·한국 기업 주식 50종목”을 기준으로 하며, 상세 문서 정정이 필요하다.

## 3. 핵심 경험

### 3.1 질문식 매매 기록

주문 기록은 제안서나 채점이 아니라, 성향 분석의 재료다. 주문 시 두 번의 탭으로 끝나며 스킵할 수 없다.

- 매수 근거: 뉴스 / 차트 / 친구·가족 추천 / 회사·제품 지식 / 느낌
- 매도 근거: 목표만큼 올랐음 / 하락 우려 / 다른 종목 선호 / 불안 / 기타
- 매수 확신도: 잘 모르겠어(25) / 조금(50) / 꽤(75) / 완전(100)
- 선택 항목: 내 생각 한 줄

확신도에는 “정답은 없어!”를 함께 표시한다. 기록은 개인의 거래·탐색 데이터와 함께 스코어링 엔진의 입력이 되며, 챗봇 대화는 스코어링에 사용하지 않는다.

### 3.2 성향 스코어링과 아카이브

LLM이 점수나 수치를 만들지 않는다. 규칙·통계 기반 엔진이 거래 로그, 탐색 이벤트, 근거 태그, 확신도, 포트폴리오 스냅샷을 입력받아 매주 5개 축을 0~100으로 계산한다.

| 성향 축 | 관찰 데이터 | 우열 없는 표현 |
|---|---|---|
| 집중–분산 | 종목·업종 집중도 | 한우물형 ↔ 골고루형 |
| 속도 | 평균 보유기간·회전율 | 진득이형 ↔ 재빨리형 |
| 신중함 | 주문 전 탐색 깊이·확신도와 행동의 일치 | 직진형 ↔ 돌다리형 |
| 손실 대응 | 하락 구간에서의 보유·매도·추가매수 패턴 | 버티기형 ↔ 갈아타기형 |
| 탐험심 | 새 종목·업종 시도 비율 | 익숙함형 ↔ 개척자형 |

아카이브는 다음 네 가지를 제공한다.

1. 개인 성향 리포트: 5축 게이지, 유형 라벨, 근거·확신도 패턴, 관찰 톤의 서술
2. 수익률 리포트: 보유·평가손익·수익률 추이
3. 가족 비교: 두 사람의 5축 병치와 중립 문장. 양측 공개 동의가 전제다. [확인 필요]
4. 시즌 기록: 시즌 초·말 성향 변화와 수익률 결산

성향은 성적이 아니라 스타일이며, 유형 라벨은 고정 낙인을 피하기 위해 매주 갱신한다. 데이터가 적으면 “아직 관찰 초기”라고 표시한다.

### 3.3 플로팅 AI 챗봇 ‘키웅이’

키웅이는 “정답을 주는 투자 AI”가 아니라 이해·기록·성찰을 돕는 개인 코치다. 모든 화면의 우하단 버튼에서 바텀시트로 열며, 자유 입력과 화면별 추천 질문 칩 3개를 제공한다.

| # | 기능 | 수행 내용 | 실행 방식 |
|---:|---|---|---|
| 1 | 대화 시작 | “고민 있어?”, “궁금한 거 있어?”처럼 부담 없이 대화를 연다. | 사용자가 플로팅 버튼을 열거나, 도움 신호가 발생했을 때 제안한다. 무시·종료·뮤트가 가능하다. |
| 2 | 금융 개념 교육 | 수익률, 손익, 분산, 수수료·세금, 시장가·지정가 등 기초 개념을 쉬운 말·비유로 설명한다. | 자유 질문 또는 화면별 추천 질문 칩에 반응한다. |
| 3 | 서비스 사용 안내 | 리그 규칙, 거래 시간·방식, 종목 검색, 주문, 포트폴리오, 가족 대시보드 이용법을 안내한다. | 용어 사전과 사용법 FAQ를 우선 사용한다. |
| 4 | 종목 유니버스 안내 | 유니버스 안 종목의 사업 내용·업종·제품·공개된 과거 사실을 설명한다. | 현재 종목 맥락을 읽되, 예측·추천은 하지 않는다. |
| 5 | 투자 기록 되짚기 | “왜 이 종목을 골랐어?”, “처음 생각과 지금 생각이 같아?”처럼 거래 이유와 확신도를 돌아보게 돕는다. | 본인의 거래 로그와 질문식 매매 기록을 읽기 전용으로 참고한다. |
| 6 | 성향 분석 설명 | 5축 성향, 근거 태그 분포, 확신도 패턴, 거래 빈도·업종 분산·보유 패턴을 쉽게 풀어 설명한다. | 스코어링 엔진이 산출한 F9 JSON만 인용한다. |
| 7 | 아카이브 탐색 | 과거 매매 이유, 한 줄 메모, 수익률 추이, 시즌 기록을 찾아 비교·요약한다. | 자녀 본인의 아카이브 데이터만 조회한다. |
| 8 | 사용법 헤맴·불안 행동 도움 | 반복 취소·수량 수정·긴 망설임·낮은 확신도 주문·손실 직후 재접속에 짧은 도움을 제안한다. | 신호별 고정 스크립트와 카드로만 발화한다. LLM을 사용하지 않으며, 부모에게 전달하지 않는다. |
| 9 | 안전 대응 | 추천·매매 시점·목표가·수익률 전망 요구를 거절하고, 오프토픽·유해·개인정보 입력을 우회한다. 정서 위기 표현에는 대화를 안전 종료하고 보호 안내를 제공한다. | 입력 분류와 공통 출력 필터를 거친 고정 응답을 사용한다. |

키웅이는 화면 맥락, 현재 종목, 본인의 거래 로그·질문식 기록·성향 리포트 산출값만 읽기 전용으로 참조한다. 수치와 사실은 엔진·API 값만 인용한다.

#### 선제 도움

키웅이는 사용자가 요청하기 전에도 도움이 필요해 보이는 순간에 고정 스크립트로 짧게 말을 건다. LLM이 생성하지 않으며, 각 발화에는 `상황 설명 / 직접 질문 / 괜찮아` 카드가 따른다.

- 사용법 신호: 매수·매도 반복 전환, 주문 확인 후 반복 뒤로 가기, 수량 반복 수정, 주문·상세 화면 장기 체류
- 불안 행동 신호: 평소보다 낮은 확신도의 매수 시도, 평가손실 확대 직후 재접속, 주문 취소·정정 반복
- 제한: 발화 간 최소 3분, 같은 신호는 10분 이내 재발화하지 않음, 세션당 최대 2회, “괜찮아” 선택 시 해당 신호는 그 세션에서 다시 제시하지 않음

선제 도움은 거래를 재촉하거나 훈계하지 않는다. 발화와 대화는 부모에게 전달하지 않는다.

## 4. AI 안전 설계

```text
거래·탐색·기록 데이터 → 규칙 기반 스코어링 엔진 → 5축·유형 JSON
                                           └→ 아카이브 서술 LLM → 공통 출력 필터 → 화면

챗봇 질문 + 화면·개인 맥락 → 사전/FAQ → 필요 시 LLM → 공통 출력 필터 → 화면
주문 UI 이벤트 → 선제 신호 규칙 → 고정 발화 (LLM 미사용)
```

- LLM은 아카이브 서술과 승인된 범위의 챗봇 응답만 생성한다.
- 종목 추천, 매매 시점, 목표가·손절가, 수익률 전망, 훈계는 입력·출력에서 모두 차단하고 탐지 건수를 기록한다.
- 오프토픽·유해·개인정보 입력은 고정 응답으로 전환한다.
- 전 대화 로그와 필터 결과를 보관하되, 챗봇 대화는 성향 점수에 반영하지 않는다.
- 비상 시 챗봇을 사전·FAQ 전용 모드로 낮출 수 있는 차단 스위치를 둔다.

## 5. 리그·리워드·사업 구조

- 홈에는 가족 단위 순위와 부모·자녀 각자의 수익률을 보인다. 순위 산식은 합산·평균·참여 가중 중 운영 설계에서 확정한다. [미확정]
- 수익률 순위와 성향 리포트는 독립 축이다. 순위가 낮아도 개인 스타일은 읽힌다.
- 아이 리워드는 게임 재화·완구, 가족 리워드는 여행·여가 경험, 부모 혜택은 로보마켓 프리미엄 체험권을 제안한다. 경품 규제 검토가 필요하다.
- 자녀 실계좌 개설은 참가 조건이 아니라 추가 혜택과 연결하는 사업 퍼널이다.

사업 흐름은 `부모 고객 → 가족리그 개설 → 자녀 참여·주간 재방문 → 시즌 완주 → 자녀 계좌 개설·첫 입금 → 성년 이후 키움 이용`으로 설정한다.

## 6. MVP 범위와 데모 골든 패스

### 구현 화면

1. 홈: 가족 순위, 각자 수익률, 포트폴리오 요약, 시즌 진행, 첫 진입 튜토리얼
2. 종목 상세: 탐색과 아이 눈높이 기업 설명
3. 주문: 매수·매도 수량 → 확인 → 질문식 기록 → 체결
4. 아카이브: 5축 성향, 유형, 리포트, 가족 비교, 수익률, 시즌 기록
5. 전역 오버레이: 플로팅 챗봇 시트와 선제 도움 말풍선

부모 뷰는 별도 화면이 아니라 계정 스위처로 전환한다. 로보마켓 배너와 위험 행동 코칭 알림만 부모 전용이다.

### 데모 시연

1. 민지 홈에서 가족 순위·포트폴리오·튜토리얼을 확인한다.
2. 종목 상세에서 키웅이 추천 질문으로 금융 개념 설명을 본다.
3. 주문 수량을 반복 수정해 키웅이의 선제 도움을 시연한다.
4. 근거 ‘그냥 느낌이 좋아’와 확신도 25를 기록하고 체결한다.
5. “뭐 사면 돼?”라는 질문에 키웅이가 고정 거절과 판단 기준 안내를 하는 것을 보인다.
6. 아카이브에서 방금 행동이 반영된 성향 리포트와 가족 비교를 확인한다.

실제 영웅문S# 연동, 실계좌·실주문, 로보마켓 결제, 대규모 경품 운영, 해외주식, 음성 챗봇 등은 MVP 범위 밖이다.

## 7. 기술·디자인 원칙

### 기술

- Next.js App Router + TypeScript
- Tailwind CSS
- zustand + localStorage persist
- 키움 REST API 시세 우선, 마지막 성공 응답 캐시와 픽스처를 폴백으로 사용
- API 키는 서버 전용으로 두며, 공통 LLM 호출·출력 필터는 `web/shared/llm`을 경유
- 행동 이벤트는 클라이언트 스토어에 적재하고 `shared/engine`의 순수 함수로 판단
- 픽스처로 화면을 먼저 완성하고 실연동은 마지막에 전환

### 디자인

- 모바일 390px, 최대 폭 430px의 폰 프레임 데모
- `navy #001E5A`, `magenta #D70082`, `gray #BEBEBE`, `bg #F6F7FA`, `white`, `up #E8322E`, `down #1668DC`, `ink #1A2233`만 사용
- 국내 증권앱 관례에 따라 상승·수익은 빨강, 하락·손실은 파랑과 ▲▼ 기호를 사용
- 네이비 헤더, 밝은 배경, 흰 카드 구조. 카드 16px·버튼 12px·칩 999px 라운드
- 하단 탭은 홈 / 투자 / 아카이브 3개이며, 주문은 종목 상세에서 진입
- 자녀 뷰는 다정한 반말, 부모 뷰는 존댓말을 쓴다.
- 키웅이(곰)는 챗봇 아바타·플로팅 버튼으로 사용하고, 영웅이(소)는 포스터용 보조 그래픽으로만 쓴다.

## 8. KPI와 검증 계획

### KPI

최상위 지표는 **부모와 자녀가 모두 주 1회 이상 활동한 활성 가족 수**다. 활동은 거래, 아카이브 열람, 챗봇 질문 중 하나다.

- 획득: 자녀 초대율·수락률·리그 개설률
- 활성: 첫 주 주문 완료율, 질문식 기록률, 챗봇 유효 응답률, 선제 발화 수용률, 리포트·가족 비교 열람률
- 유지: 4주·8주 유지율, 시즌 재참여율
- 교육: 개념 재질문 감소, 업종 탐색 다양성, 확신도-행동 일치, ‘느낌’ 태그 비중 변화
- 사업: 자녀 신규계좌 개설·첫 입금, 로보마켓 체험→유료 전환
- 안전: 고위험 집중·거래 급증 비율, 금지 표현 탐지, 오프토픽 차단, AI 오류·가족 갈등 접수

목표 수치는 시즌 1의 베이스라인을 수집한 뒤 설정한다. [가정]

### PoC

- **PoC-1:** 부모 8~12명 인터뷰로 “주 30분 이내면 참여할 의향”과 리포트·가족 비교의 대화 유발 효과를 확인한다.
- **PoC-2:** 아동 관점 챗봇 질문 50개와 모의 행동 데이터 20가족분으로 안전성·사실 일치성을 검증한다.
- 선제 신호는 자녀 테스트 30세션에서 실제 도움이 필요한 순간과의 일치율을 측정하며, 70% 미만 신호는 기준을 높이거나 제거한다.

## 10. 발표 논리

1. 아이는 투자 경험이 부족하고 부모는 가르치는 데 부담을 느낀다.
2. 기존 가족 금융·모의투자 서비스는 순위·수익률 중심이고, 아이 눈높이 AI와 가족 단위 성향 이해는 공백이다. [사실 — 원본 리서치 기준]
3. 각자 투자하고 기록하면, 정량 엔진이 스타일을 읽고 키웅이가 막히는 순간을 돕는다.
4. 키움은 그룹 모의투자, 미성년 계좌 퍼널, 영웅문S# AI 방향, 로보마켓이라는 기반을 가진다. [사실 — 원본 리서치 기준]
5. 사업 효과는 부모 활성화와 자녀의 첫 투자 경험 선점, 즉 세대 고객 연결이다.
