# A. 경쟁사·근거 검증 대장

- 1차: 2026-08-09 (퍼핀·스윙스타·FCA/OSC·키움 인프라·Greenlight/Fidelity·갭 체크)
- 2차: 2026-08-09 (미검증 전량 재조사 — 국내 / 해외 가족·청소년 / 해외 모의투자·AI·저널, 에이전트 3방향 병렬. 전 항목 공식 페이지·신뢰 언론 교차 확인)
- 상태: **확인됨** / **부분확인** / **미발견**(탐색했으나 존재 확인 실패 — 부재 증명 아님)

## 0. 2차 검증 핵심 결론

1. **차별화 갭 유효**: "부모·자녀 투자행동(거래 로그) 비교·분석"은 국내 9건 + 영어권 4쿼리 재탐색 모두에서 미발견. 인접 서비스는 전부 통합조회(INDmoney·Addepar류), 감독형(Greenlight·Fidelity), 순위 비교(퍼핀)에 그침.
2. **추격 신호 존재**: 신한투자증권이 2026-04 보도자료에서 미성년(미국 지수형 ETF 중심) vs 부모(빅테크 개별주 중심) **성향 차이를 전사 통계로 발표** + '우리아이 자산관리 서비스' **구축 추진 중(미출시)**. 개인화 리포트로 먼저 제품화하면 선점, 신한이 1순위 잠재 추격자.
3. **브리프 교정 2건**: Bloom은 "교육 완료 시 개방" 게이트가 아니라 포인트 보상형(§4 교정). Step 크립토는 2024-05 전면 종료.
4. **설계 실증 확보**: StockTrak이 **단일종목 집중도 25% 상한 + 매매노트 의무화("Require Trading Notes" 기본 활성)**를 실제 운영 — 우리 시즌 설정·거래 전 기록 설계의 검증된 선례. Step이 "부모 위험등급 설정 → 자녀 등급 내 자율 매매" 모델 실증 — 코치 모드의 선례.

## 4. 브리프·기획서 교정 사항 (2차 검증으로 확정)

1. **Bloom ≠ 교육 게이트** — "교육 완료 시 개방" 사례로 인용 금지. 실존 사례는 Goalsetter(퀴즈 미응시 시 카드 동결)와 Schwab(교육 완료 $50 지급). → 기획서 §7 반영.
2. **Step 크립토 종료(2024-05)** — "크립토 포함 자율투자" 서술 금지. 살아있는 것은 "위험등급 내 주식 자율 매매" 모델. → 기획서 §4.4 반영.
3. **퍼핀 가상자산 없음** — 미국주식 전용. 브리프의 "미국 주식 및 가상자산" 절반 기각.
4. **스윙스타 = 자문형**(1차에서 이미 교정) — 행동 진단 사례가 아니라 진단→추천 자문 상품.
5. **PortfolioPilot 홍보 문구** — SEC가 허위 제재한 표현("최초의 규제받는 AI 자문")을 벤치마크 인용에 쓰지 말 것.
