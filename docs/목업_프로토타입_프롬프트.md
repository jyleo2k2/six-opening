# 영웅 키움 — 모의투자 플로우 목업 프로토타입 프롬프트 세트

> 목적: **클릭되는 단일 HTML 프로토타입**(홈 → 모의투자 → 종목 고르기 → 상세 → 매수/매도 → 포트폴리오 반영)을 AI 생성으로 만들기 위한 프롬프트 모음.
> 기준: `영웅키움_질문식매매_구현스펙_v1_1.md` + `디자인시스템.md`. 레드라인 교정 반영(확신도 숫자 비노출·인앱 캐릭터는 키웅이만·Q5 5버튼).
> 데이터(화이트리스트 50종·섹터 구성)는 **placeholder** — 나중에 JSON으로 교체.

## 사용법
1. **[S0 공통 블록]** 을 항상 프롬프트 맨 앞에 붙인다.
2. **[S1 앱 셸]** 을 먼저 생성 → 폰 프레임·4탭 네비·화면 라우터·상태 모델·빈 화면 스텁이 있는 단일 HTML이 나온다.
3. 이후 **[S2]~[S17]** 화면 프롬프트를 순서대로 "같은 파일의 해당 `<section id>`를 채워줘" 형식으로 적용한다.
4. 화면 id 규약: `#home #portfolio #invest #detail #buy1~#buy5 #sell1~#sell5 #archive #ranking`

## S0. 공통 시스템 블록 (모든 화면 프롬프트 앞에 붙임)

```
[공통 지시]
아동용 가족 모의투자 앱 '영웅 키움'의 클릭되는 목업 프로토타입을 만든다.

산출 규칙
- 단일 HTML 파일, CSS는 <style> 인라인, 로직은 <script> 인라인. 외부 폰트/이미지/JS 로드 금지(오프라인 렌더 가능).
- 폰 프레임: 폭 390px, max-width 430px, 중앙 정렬, 화면 배경 #F6F7FA. 데스크톱 대응 불필요.

디자인 토큰 (이 값만, 임의 hex 금지)
navy #001E5A(헤더·핵심·종목뱃지) / magenta #D70082(CTA·선택·강조) / gray #BEBEBE(구분선·비활성)
/ bg #F6F7FA / white #FFFFFF / up #E8322E(상승·수익=빨강) / down #1668DC(하락·손실=파랑) / ink #1A2233(본문)
- 카드 r16 / 버튼 r12 / 칩 r999. 그림자는 연하게 1단계. 폰트 Pretendard(폴백 'Segoe UI','Malgun Gothic',sans-serif).
- 숫자(가격·수익률)는 tabular-nums·크고 굵게. 등락은 반드시 up/down색 + ▲▼.
- 위계: 화면제목 18~20 bold / 카드제목 15~16 semibold / 본문 14 / 캡션 12.

캐릭터·장식
- 인앱 캐릭터는 키웅이(곰)만. 영웅이(소)는 앱 화면 금지(포스터 전용).
- 캐릭터 렌더 에셋 없음 → 둥근 이미지 플레이스홀더(연회색 박스 + '🐻 키웅이' 라벨). 실제 렌더는 후교체.
- 장식은 별·말풍선·컨페티만 화면당 1~2개. 컨페티는 '체결 완료'에서만.

카피·말투(자녀 뷰) — 전부 반말+다정("~해볼까?", "기록 완료! 키웅이가 기억해둘게").
방향성/추천 언어 전면 금지: 사야/팔아야/매수 기회/목표가·손절가/오를 것·내릴 것/확실.

레드라인(전 화면 공통)
- 확신도 숫자(0~100·%)를 아이 화면에 절대 표시하지 않는다 — 표정·문구만.
- 회고 카드의 수익률에 빨강/파랑 강조 금지(중립 ink색).
- 특정 선택지를 색·크기·순서로 우대하지 않는다(선택 '상태' 강조는 허용).
- '잘했어/아쉬워' 등 평가 문구·내부 코드값 노출 금지.
```

## S1. 앱 셸 · 네비게이션 · 상태 모델

```
[생성] 위 [공통 지시]에 따라, 아래를 갖춘 단일 HTML '앱 셸'을 만든다.

폰 프레임 & 화면 라우터
- <main> 안에 화면들을 <section id="..."> 로 두고, JS goTo(id)로 하나만 보이고 나머지는 숨긴다.
- 뒤로가기: 각 화면 상단 ← 는 history 스택(배열)로 직전 화면으로 복귀. 없으면 홈.
- 이번 셸에서는 아래 모든 화면의 '빈 스텁'을 만든다(제목만): 
  #home #portfolio #invest #detail #buy1 #buy2 #buy3 #buy4 #buy5 #sell1 #sell2 #sell3 #sell4 #sell5 #archive #ranking

하단 네비게이션 바(고정 4탭) — 단, 주문 위저드(#buy*, #sell*)와 #detail 에서는 숨긴다
- 홈(→#home) · 모의투자(→#invest) · 아카이브(→#archive) · 랭킹(→#ranking)
- 현재 탭은 magenta 강조. 아이콘은 이모지/인라인 SVG로 간단히.

상태 모델(JS 전역 state, localStorage 저장/복원)
state = {
  user: 'minji',              // 데모 자녀
  seedKRW: 1000000,           // 시즌 시드
  cashKRW: 970000,            // 지갑 현금(시드 - 기보유 매수분)
  currentPrices: { '005930': 76975, '005380': 210000 },  // mock 현재가(placeholder)
  role: 'child',              // 'child'(민지) | 'parent'(엄마) — 계정 스위처로 전환
  schoolLockEnabled: true,    // 부모 설정(기본 ON): 평일 09:00~16:00 자녀 매매 잠금
  holdings: [
    { symbol:'005930', name:'삼성전자', sector:'반도체', qty:0.41, amountKRW:30000, buyPrice:73170,
      buyTsLabel:'3주 전', reasonText:'뉴스를 보고', confidenceText:'꽤 자신 있게',
      planCode:'plan_season', planText:'시즌 끝까지', memo:'월드투어 시작한대' }
  ],
  records: []                 // 매수/매도 기록 누적
}
- 헬퍼: buy(order){ holdings에 추가 또는 평단 갱신, cashKRW 차감, records.push } 
        sell(order){ 해당 holding qty 차감/제거, cashKRW += 평가금액, records.push }
        pnlPct(h){ (currentPrice-buyPrice)/buyPrice*100 }  evalKRW(h){ qty*currentPrice }
- buy/sell 후 renderHome()·renderPortfolio() 재실행으로 화면이 상태를 반영한다.

운영 시간 · 학교 시간 잠금 (24시간 상시)
- 모의투자는 평일·주말 24시간 상시 가능. 장 열림/닫힘·휴장 개념·배지 없음.
- 주말(토·일): 시간 무관 항상 매매 가능(제약 없음).
- 학교 시간 잠금: role='child' && schoolLockEnabled && isSchoolTime()(평일 09:00~16:00) 이면 → '주문 실행'만 잠근다.
   · 잠그는 것: 종목 상세 [사러가기], 포트폴리오 [사러가기]/[팔러가기], 매수/매도 주문. (버튼 비활성 + 따뜻한 문구)
   · 열어두는 것: 종목 구경·상세 보기·챗봇 질문 등 학습은 그대로 허용.
   · 따뜻한 문구: "지금은 학교에서 공부할 시간! 매매는 하교하고 하자 🐻"
   · 부모(role='parent')는 항상 매매 가능. 부모가 schoolLockEnabled를 끄거나 시간 조정 가능(기본 ON).
- 헬퍼: isSchoolTime()=평일 09:00~16:00. canTrade()= role==='parent' || !schoolLockEnabled || !isSchoolTime().
- 데모/발표용: '학교 시간 강제 ON/OFF' 개발용 토글을 둬 시연 시 잠금 상태를 보여줄 수 있게 한다.

시드 근거: holdings에 삼성전자 1건을 넣어 매도 회고('사던 날의 나') 데모가 빈 화면이 되지 않게 한다.
```

## S7. 매수 BUY-2 `#buy2` — Q1 왜 좋아 보였어

```
[화면] 매수 2/5 #buy2  (이탈: 선택 후 [다음]→#buy3)
- 키웅이 말풍선(플레이스홀더 아바타 옆): "왜 이 회사가 좋아 보였어? 정답은 없어, 솔직한 게 최고야!"
- 버튼 택1, 6개 · 2열×3행 · 전부 동일 색·크기:
  📰 뉴스에서 봐서 / 📈 그래프가 좋아 보여서 / 🛒 내가 아는 회사·써본 거라서 /
```
