# 기술 스택 (확정 2026-08-09, 사용자 컨펌)

## 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 프레임워크 | **Next.js (App Router) + TypeScript** | 단일 레포·단일 실행. 서버 코드로 LLM/시세 키 보호. Vercel 배포 → 발표 때 QR로 실기기 시연 |
| 스타일 | Tailwind CSS | 디자인 토큰을 config로 강제(`docs/디자인시스템.md`), 병렬 작업 시 CSS 충돌 없음 |
| 상태 | zustand + localStorage persist | 데모 규모에 DB 과잉. 민지↔엄마 스위처·거래 로그·기록 전부 클라이언트 상태 |
| 시세 | **실시간 API (사용자 선택)** — 한국투자증권 KIS Developers REST | 국내주식 현재가·일봉. 무료, 모의투자 계정으로 신청 가능 |
| 시세 폴백 | **필수** — 마지막 성공 응답을 캐시에 저장, API 실패·장외 시간엔 캐시 서빙 | 발표 시각이 장외이거나 행사장 네트워크 불안일 때 데모가 죽으면 안 됨 |
| 차트 | lightweight-charts 또는 recharts 라인 1개 | 종목 상세에 간단 라인 차트만 |
| 배포 | Vercel (무료) | 환경변수로 키 관리. 로컬 시연 백업: `npm run dev` |

## LLM — AI 기능별 배정 (2026-08-09 분석)

비용은 데모 볼륨에서 무의미(전 조합 몇백 원대). 기준은 **지연·품질·무대 리스크**.

| AI 기능 | 모델 | 호출 패턴 | 이유 |
|---|---|---|---|
| F1 리포트·비교·궁합 | **claude-opus-5** | 주 1회 배치 — 데모는 사전 생성 가능 | 서술 품질이 발표 핵심 증거물. 지연 무관이므로 품질 최우선 |
| F4 토크 질문·관점 정리 | **claude-opus-5** | 주 1회, 극소 | 질문 품질이 PoC-2 통과 기준("대화하고 싶어지는가 ≥70%")과 직결 |
| F7 선생님 챗봇 | **claude-sonnet-5** | 실시간 스트리밍, 데모 중 최다 호출 | 무대에서 첫 토큰 지연이 체감 품질. 회피·되물음 품질 충분. (haiku-4.5로 더 내리면 빠르지만 안전 응답 품질이 무대 리스크) |
| 출력 필터 | LLM 아님 — 정규식·키워드 룰 | 전 출력 | 검사기에 LLM을 쓰면 검사기도 환각 리스크 |
| 정량 지표 | LLM 아님 — `shared/engine` 순수 함수 | 전 리포트 | 3층 구조 원칙 (LLM은 숫자를 만지지 않는다) |
| 시즌 성장리포트 | 목업 | — | 데모 범위 밖, 슬라이드 1장 |

- SDK: `@anthropic-ai/sdk` 서버 전용. 모델명은 기능별 상수로 두고 한 줄 교체 가능하게.
- 가격 참고: opus-5 $5/$25, sonnet-5 $2/$10(인트로, 2026-08-31까지, 이후 $3/$15), haiku-4.5 $1/$5 /MTok.

## 구조 원칙

- 앱은 `web/` 하위 (레포 루트는 기획 문서 유지)
- API 키(Anthropic, KIS)는 서버 코드에서만 — 클라이언트 번들 포함 금지
- LLM 프롬프트·생성 로직은 **각 기능 폴더의 server action**에, 공통 호출+필터는 `shared/llm`에. 컴포넌트에서 SDK 직접 호출 금지
- **픽스처 우선**: `shared/data/fixtures`의 목업으로 화면 먼저 완성, 실연동은 마지막 스위치

## 폴더 구조 (feature-sliced — 폴더가 소유권 경계, 가드 파일 선배치됨)

```
web/
  AGENTS.md · CLAUDE.md     # 앱 전역 규칙 (전 에이전트 자동 로드)
  app/                      # 라우팅 전용 — 오케스트레이터 소유, page.tsx는 features 재수출 1줄
    AGENTS.md · CLAUDE.md
    api/quote/[symbol]/     # KIS 프록시+폴백 캐시 (인프라)
    api/teacher/            # 예외: f7 소유 (스트리밍 route handler)
  features/
    f0-home/                # 홈: 순위·현황·편지 예고·탭바          (골든 패스 ①)
    f1-letter/              # 투자편지: 개인→비교→궁합 + 프롬프트    (골든 패스 ④)
    f2-trade/               # 탐색·종목 상세·매수/매도               (골든 패스 ②③)
    f3-reason/              # 이유 기록 폼 — f2가 import            (골든 패스 ②)
    f4-talk/                # 투자토크: 질문·동시 공개·정리 + 프롬프트 (골든 패스 ⑤)
    f7-teacher/             # 선생님 챗 UI + 시스템 프롬프트          (골든 패스 ②)
    (각 폴더에 AGENTS.md · CLAUDE.md — 소유권·스펙·완료 기준)
  shared/                   # 공용 — 오케스트레이터 소유, 기능 에이전트 수정 금지
    AGENTS.md · CLAUDE.md   # 변경 요청 로그 포함
    ui/                     # Button·Card·Chip·PriceText 등 10종 (디자인시스템 §6)
    engine/                 # 정량엔진 순수 함수
    llm/                    # 공통 호출 client + filter(금지 표현) + 모델 상수
    store/                  # zustand (계정·거래·기록)
    types/                  # 공용 타입 계약
    data/                   # stocks(종목+아이 설명)·seed(4주차)·fixtures(목업)
```
