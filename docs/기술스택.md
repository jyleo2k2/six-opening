## LLM — AI 기능별 배정 (2026-08-10 개정)

비용은 데모 볼륨에서 무의미(전 조합 몇백 원대). 기준은 **지연·품질·무대 리스크**. F8은 행동 감지로 먼저 시작하고, 이후 승인된 지식 범위 안에서 자연어 대화를 제공한다. 음성·무제한 일반 대화는 범위 밖이다.

| AI 기능 | 모델 | 호출 패턴 | 이유 |
|---|---|---|---|
| F8 AI 코치 선발화·대화 답변 | **claude-sonnet-5** | 행동 트리거 및 사용자 메시지마다 1회 | 짧은 대화 응답과 낮은 지연이 중요. 서버 도구가 제공한 근거만 사용 |
| F9 성향 리포트 서술·유형 라벨 | **claude-opus-5** | 주 1회 배치 — 데모는 사전 생성 가능 | 발표 핵심 증거물. 품질 최우선 |
| 출력 필터 | LLM 아님 — 정규식·키워드 룰 | 전 출력 | 검사기에 LLM을 쓰면 검사기도 환각 리스크 |
| 행동 프로파일 엔진·정량 지표 | LLM 아님 — `shared/engine` 순수 함수 | 상시 | LLM은 수치를 만들지 않고, 행동 감지 또는 사용자 대화 때만 서버에서 호출된다 |

- SDK: `@anthropic-ai/sdk` 서버 전용. 모델명은 기능별 상수로 두고 한 줄 교체 가능하게.
- 가격 참고: opus-5 $5/$25, sonnet-5 $2/$10(인트로, 2026-08-31까지, 이후 $3/$15) /MTok.
- 음성 파이프라인은 범위 밖이다. F8 대화는 텍스트 입력만 제공하며, `web/app/api/teacher/`의 구 실험 코드는 참조하지 않는다.

## 구조 원칙

- 앱은 `web/` 하위 (레포 루트·`docs/`는 기획 문서 유지)
- API 키(Anthropic, 키움)는 서버 코드에서만 — 클라이언트 번들 포함 금지
- LLM 프롬프트·생성 로직은 **각 기능 폴더의 server action**에, 공통 호출+필터는 `shared/llm`에. F8은 서버에서 종목 카탈로그·개인 아카이브·서비스 규칙만 조회한다. 컴포넌트에서 SDK 직접 호출 금지
- 행동 이벤트(확신도·체류·태깅)는 zustand 스토어에 적재 → `shared/engine`이 규칙 판정 — 트리거 판정은 클라이언트 규칙으로 충분, LLM 호출만 서버 경유
- **픽스처 우선**: `shared/data/fixtures`의 목업으로 화면 먼저 완성, 실연동(키움 시세·LLM)은 마지막 스위치

## 폴더 구조 (feature-sliced — 폴더가 소유권 경계, 가드 파일 선배치)

```
web/
  AGENTS.md · CLAUDE.md     # 앱 전역 규칙 (전 에이전트 자동 로드)
  app/                      # 라우팅 전용 — 오케스트레이터 소유, page.tsx는 features 재수출 1줄
    AGENTS.md · CLAUDE.md
    api/quote/[symbol]/     # 키움 시세 프록시+폴백 캐시 (인프라)
    api/teacher/            # [폐기] 구 F7 실험 코드 — 삭제 대기, 참조 금지
  features/
    f0-home/                # 홈: 펫 상주·순위·튜토리얼 코치마크        (골든 패스 ①)
    f2-trade/               # 탐색·종목 상세·매수/매도·보유              (골든 패스 ②)
    f3-reason/              # 질문식 기록: 근거 태깅+확신도 — f2가 import (골든 패스 ②)
    f8-pet/                 # AI 코치: 선발화·제한 범위 자연어 대화 + 프롬프트 (골든 패스 ③)
    f9-archive/             # 아카이브: 성향·수익률·성장기록 + 프롬프트    (골든 패스 ⑥)
    (각 폴더에 AGENTS.md · CLAUDE.md — 소유권·스펙·완료 기준)
  shared/                   # 공용 — 오케스트레이터 소유, 기능 에이전트 수정 금지
    AGENTS.md · CLAUDE.md   # 변경 요청 로그 포함
    ui/                     # Button·Card·Chip·PriceText·PetAvatar 등 (디자인시스템 §6)
    engine/                 # 행동 프로파일 엔진·정량 지표 순수 함수
    llm/                    # 공통 호출 client + filter(금지 표현) + 모델 상수
    store/                  # zustand (계정·거래·확신도·펫 상태)
    types/                  # 공용 타입 계약
    data/                   # stocks(종목+아이 설명)·seed(4주차·펫 Lv.2)·fixtures(목업)
```

※ 폐기된 기능 폴더: `f1-letter`·`f4-talk`·`f7-teacher` — 기능 ID와 함께 삭제, 재사용 금지 (기능명세 v4).
