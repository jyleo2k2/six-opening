## LLM — GPT-5.6 Luna 단일화 (2026-08-11 확정)

F9·F10 모두 **GPT-5.6 Luna**를 사용한다. 선제 도움은 고정 스크립트이며 LLM을 호출하지 않는다. 음성·무제한 일반 대화는 범위 밖이다.

**모델 스펙 [사실 — OpenAI 공식 모델 문서]**: `gpt-5.6-luna` · 입력 $0.20 / 출력 $1.20 per 1M 토큰 · 컨텍스트 1,050,000 · 최대 출력 128,000 · 지식 컷오프 2026-02-16 · Responses·Chat Completions·Batch 지원(Realtime 미지원) · 스트리밍·structured outputs·function calling·reasoning 지원.

| AI 기능 | 모델 | 호출 패턴 | 이유 |
|---|---|---|---|
| F10 챗봇 대화 답변 | **`gpt-5.6-luna`** | 사전·FAQ 미스 또는 승인된 조회 결과 설명이 필요할 때 `responses.create({ stream: true })` 최대 1회 | 에이전트 반복 호출 없이 짧은 답변을 만들고 실패 시 고정 폴백 |
| F9 성향 리포트 서술 | **`gpt-5.6-luna`** | 주 1회 `responses.create` — 데모는 사전 생성 가능 | 엔진 JSON을 근거로 서술만 생성. 유형 라벨·수치는 엔진 산출 |
| 출력 필터 | LLM 아님 — 정규식·키워드 룰 | 전 출력 | 검사기에 LLM을 쓰면 검사기도 환각 리스크 |
| 행동 프로파일 엔진·정량 지표 | LLM 아님 — `shared/engine` 순수 함수 | 상시 | LLM은 수치를 만들지 않고, 행동 감지 또는 사용자 대화 때만 서버에서 호출된다 |

### 구현 규칙

- SDK: **`openai`** 서버 전용, **Responses API**를 쓴다. API 키는 `OPENAI_API_KEY`만 사용한다.
- 모델 ID는 `shared/llm`의 단일 상수 `gpt-5.6-luna`로 둔다. 별도 프로바이더 추상화는 만들지 않는다. **별칭 `gpt-5.6`은 sol로 라우팅되므로 쓰지 않는다.**
- F10은 서버에서 `client.responses.create({ stream: true })`를 호출하고 `response.output_text.delta` 이벤트만 읽는다. 원시 델타는 클라이언트에 보내지 않고 최대 3문장을 완성 버퍼에 모은 뒤 출처·권한·수치·금지 표현을 공통 검증한다. 통과한 텍스트만 SSE로 보내며 차단 시 고정 응답으로 대체한다.
- F9은 `client.responses.create`(비스트리밍)로 서술만 생성하고 공통 출력 필터를 거친다.
- `reasoning.effort`는 **`low`** — 무대 지연을 줄이되 3문장·거절 지시 준수는 유지한다. `max_output_tokens`는 reasoning 토큰까지 포함하므로 800으로 두고, 3문장 상한은 서버 라우트가 자른다. 지연이 더 문제면 `none`으로 내린다.
- F10 대화는 텍스트 입력만 제공한다. 음성 파이프라인은 범위 밖이다(Luna는 Realtime 미지원).

### F10 라우팅·툴·RAG 경계 [팀 확정 2026-08-11]

- **한 번 통과하는 파이프라인:** 요청·세션 검증 → 입력 안전 게이트 → 규칙 기반 질문 목적 라우팅 → 선택적 읽기 전용 조회 → Luna 최대 1회 → 공통 출력 게이트 → 구조화 응답. 모델이 스스로 툴을 반복 선택하는 에이전트 루프는 만들지 않는다.
- **툴로 만들 것:** 승인된 종목 사실 조회, 본인 거래·질문식 기록 조회, 본인 F9 JSON 조회, 본인 아카이브 조회. 모두 서버 전용·읽기 전용이며 입력·출력 스키마와 허용 필드를 고정한다.
- **툴로 만들지 않을 것:** 용어 사전, 사용법 FAQ, 추천·위기·개인정보 고정 응답, 선제 도움 고정 발화. 단순한 것은 TypeScript 데이터와 순수 함수로 처리한다.
- **사용자 경계:** 사용자·가족 식별자는 세션에서 서버가 주입한다. 모델과 클라이언트는 조회 대상을 지정하거나 다른 가족 구성원으로 바꿀 수 없다.
- **RAG:** “매수가 뭐야?” 수준은 사전으로 처리한다. 승인된 교육 문서가 사전 규모를 넘어 의미 검색이 필요할 때만 소규모 RAG를 추가한다. 공개 웹 검색은 MVP 답변 경로에 두지 않는다.
- **후속 행동:** 관련 화면 이동은 모델이 만든 URL이 아니라 허용 목록의 `uiAction`을 반환하고 사용자 탭 후 실행한다.
- **재검토 조건:** 한 요청에서 여러 툴의 반복 호출, 중단 후 재개, 사람 승인, 복잡한 재시도·분기가 실제 요구사항이 될 때만 LangGraph 도입을 재검토한다. 현재 Next.js 단일 TypeScript 서비스에 별도 Python 런타임이 필요하지 않으므로 PydanticAI는 사용하지 않는다.
- **선제 도움:** 유형은 `switch`·`dwell`·`lossRevisit` 3종으로 고정하고 LLM을 호출하지 않는다. 횟수·시간·손실률 임계값만 [가정]으로 검증한다.

## 구조 원칙

- 앱은 `web/` 하위 (레포 루트·`docs/`는 기획 문서 유지)
- API 키(OpenAI, 키움)는 서버 코드에서만 — 클라이언트 번들 및 `NEXT_PUBLIC_*` 포함 금지
- LLM 프롬프트는 기능 폴더, SDK 호출·모델 상수·필터는 `shared/llm`에 둔다. F10 `app/api/chat`은 스트림 전송만 담당하며 컴포넌트에서 SDK를 직접 호출하지 않는다
- 행동 이벤트(확신도·체류·태깅)는 zustand 스토어에 적재 → `shared/engine`이 규칙 판정 — 트리거 판정은 클라이언트 규칙으로 충분, LLM 호출만 서버 경유
- **픽스처 우선**: `shared/data/fixtures`의 목업으로 화면 먼저 완성, 실연동(키움 시세·LLM)은 마지막 스위치

## 폴더 구조 (feature-sliced — 폴더가 소유권 경계, 가드 파일 선배치)

```
web/
  AGENTS.md · CLAUDE.md     # 앱 전역 규칙 (전 에이전트 자동 로드)
  app/                      # 라우팅 전용 — 오케스트레이터 소유, page.tsx는 features 재수출 1줄
    AGENTS.md · CLAUDE.md
    api/quote/[symbol]/     # 키움 시세 프록시+폴백 캐시 (인프라)
    api/chat/               # F10 필터 통과 SSE 전송 전용 Route Handler
  features/
    f0-home/                # 홈: 순위·포트폴리오·튜토리얼 코치마크       (골든 패스 ①)
    f2-trade/               # 탐색·종목 상세·매수/매도·보유              (골든 패스 ②)
    f3-reason/              # 질문식 기록: 근거 태깅+확신도 — f2가 import (골든 패스 ②)
    f9-archive/             # 아카이브: 성향·수익률·성장기록 + 프롬프트    (골든 패스 ⑥)
    f10-chatbot/            # 플로팅 챗봇: 자유 질문·선제 도움·안전 가드   (골든 패스 ②·③·⑤)
    (각 폴더에 AGENTS.md · CLAUDE.md — 소유권·스펙·완료 기준)
  shared/                   # 공용 — 오케스트레이터 소유, 기능 에이전트 수정 금지
    AGENTS.md · CLAUDE.md   # 공용 변경 규칙 포함
    ui/                     # Button·Card·Chip·PriceText·CoachAvatar 등 (디자인시스템 §6)
    engine/                 # 행동 프로파일 엔진·정량 지표 순수 함수
    llm/                    # openai 서버 client + filter(금지 표현) + 모델 상수
    store/                  # zustand (계정·거래·확신도·행동 이벤트·챗봇 상태)
    types/                  # 공용 타입 계약
    data/                   # stocks(종목+아이 설명)·seed(축적 거래·행동)·fixtures(목업)
```

※ 폐기된 기능 ID: F1·F4·F5·F6·F7·F8 — 삭제 ID는 재사용하지 않는다 (기능명세 v7).
