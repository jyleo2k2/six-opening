# Git Session Manager 트리거 사례

## 반드시 실행

1. `챗봇 게이트 구현해줘.`
2. `이 문서를 최신 기획에 맞게 수정해줘.`
3. `내 이름으로 새 브랜치와 워크트리 만들어줘.`
4. `F9와 F10을 두 작업으로 나눠 진행할 거야.`
5. `아까 하던 챗봇 브랜치 작업 이어서 해줘.`
6. `공용 필터도 수정 범위에 추가해줘.`
7. `다른 팀원 PR이랑 파일 겹치는지 확인해줘.`
8. `첫 커밋 올리고 Draft PR 만들어줘.`
9. `병합된 워크트리 안전하게 정리해줘.`
10. `현재 병렬 작업 세션 상태 보여줘.`

## 실행하지 않음

1. `현재 챗봇 구조를 설명해줘.`
2. `이 코드가 무슨 역할인지 읽어서 알려줘.`
3. `main의 최근 커밋 세 개만 보여줘.`
4. `LangGraph와 PydanticAI 차이를 알려줘.`
5. `F10 SPEC에서 추천 금지 규칙이 어디야?`
6. `현재 PR 상태를 읽기만 해줘.`
7. `이 오류 메시지의 뜻을 설명해줘.`
8. `기술스택을 표로 요약해줘.`
9. `워크트리가 무엇인지 알려줘.`
10. `빌드 명령이 무엇인지 확인만 해줘.`
