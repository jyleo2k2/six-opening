# app/ — 라우팅·인프라 (오케스트레이터 소유)

- 이 폴더는 **오케스트레이터/인프라 담당만 수정**한다. 기능 에이전트는 수정 금지.
- 각 `page.tsx`는 `features/*`의 화면 컴포넌트를 재수출하는 1줄 — 화면 로직을 여기 두지 않는다. 라우트 스텁은 스캐폴드 때 전부 만들어두므로 기능 에이전트가 여기 올 일이 없다.
- 라우트: `/`(f0 홈) · `/stocks`(f2 탐색) · `/trade/[symbol]`(f2 상세·매매) · `/pet`(f8) · `/archive`(f9).
- `api/quote/[symbol]/` — 키움 시세 프록시 + 폴백 캐시(마지막 성공 응답 저장, 실패·장외 시 캐시 서빙). 인프라 담당 소유.
- LLM 호출은 각 기능 폴더의 server action + `shared/llm` 경유 — app/ 밑에 전용 api 라우트를 만들지 않는다 (스트리밍 요구 없음).
- **[폐기]** `api/teacher/` — 구 F7 선생님 실험 코드(2026-08-10 펫 전환으로 폐기). 신규 작업·참조 금지, 삭제 대기.
