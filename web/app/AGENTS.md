# app/ — 라우팅·인프라 (오케스트레이터 소유)

- 이 폴더는 **오케스트레이터/인프라 담당만 수정**한다. 기능 에이전트는 수정 금지.
- 각 `page.tsx`는 `features/*`의 화면 컴포넌트를 재수출하는 1줄 — 화면 로직을 여기 두지 않는다. 라우트 스텁은 스캐폴드 때 전부 만들어두므로 기능 에이전트가 여기 올 일이 없다.
- `api/quote/[symbol]/` — KIS 시세 프록시 + 폴백 캐시(마지막 성공 응답 저장, 실패·장외 시 캐시 서빙). 인프라 담당 소유.
- **예외**: `api/teacher/` 는 f7 담당 소유 (선생님 챗 스트리밍 route handler). f7 에이전트는 이 폴더만 app/ 안에서 수정 가능.
