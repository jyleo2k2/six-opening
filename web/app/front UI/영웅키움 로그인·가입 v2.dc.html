가입 경로가 둘로 나뉩니다
엄마·아빠·아이가 각자 계정과 각자 기기를 씁니다. v1의 프로필 스위처와 공용 PIN은 빼고, 계정끼리는 숫자 6자리 가족 코드로 연결합니다. 로그인은 소셜 없이 서비스 자체 아이디·비밀번호만 씁니다.
부모 경로 (4단계)
로그인 → 보호자 본인확인 → 가족 만들기/참여(코드 발급) → 아이 요청에 법정대리인 동의
아이 경로 (3단계)
아이디·비밀번호 가입 → 별명·생년월일 + 가족 코드 입력 → 부모 동의 대기 → 승인되면 시작
두 번째 보호자
아빠는 자기 계정으로 가입한 뒤 같은 가족 코드로 [기존 가족에 참여]합니다. 법정대리인 동의는 한 보호자가 하면 되고, 나머지는 가족 구성원으로 봅니다.
동의 순서를 이렇게 잡은 이유
· 동의는 특정 아이에 대한 것이어야 하므로, 부모 화면에서 그 아이의 요청을 보고 동의합니다
· 아이 쪽은 동의 요청에 필요한 최소 정보(별명·생년월일)만 먼저 받습니다
· 동의 전에는 계정이 시작되지 않고, 7일 미동의 시 요청·정보를 삭제합니다
· 필수·선택 동의 분리, 전체동의 기본 미체크, 철회 경로 병기
확인이 필요한 것
· 아이 아이디를 아이가 직접 만들지, 부모가 만들어 전달할지
· 법정대리인 확인을 휴대폰 본인확인만으로 볼지
· 만 14세 이상 자녀 수용 여부 (본인 동의 경로 분기)
· 보호자 2명이 모두 동의해야 하는지 (지금은 1명)
· 문구는 법무 검토 전 초안입니다
