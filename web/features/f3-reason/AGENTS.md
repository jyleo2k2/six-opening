# f3-reason — 매매 이유 기록 폼 (담당 에이전트 전용)

- 소유: 이 폴더 전부. 밖은 수정 금지. f2가 import하는 폼 컴포넌트를 공개 index로 내보낸다.
- 스펙: `기능명세.md` F3 + `기획서.md` §5.3.
- 매수 폼: 이유 칩 5개(성장할 것 같아서/좋은 뉴스를 봐서/제품·서비스가 잘될 것 같아서/가격이 싸다고 생각해서/그냥 관심 있어서) + 한 줄 메모(선택).
- 매도 폼: 이유 칩 5개(충분히 올라서/떨어질 것 같아서/다른 회사에 투자하고 싶어서/손실이 커질까 걱정돼서/기타) + 한 줄 메모(선택).
- 칩 선택 필수, 메모 선택. 저장은 `shared/store`의 기록 액션. 톤: '제안서'가 아니라 가벼운 생각 기록 — 부담스러운 UI 금지.
- 완료 기준: 매수·매도 폼이 f2 플로우에 삽입돼 기록이 store에 쌓임 + `npm run build`.
