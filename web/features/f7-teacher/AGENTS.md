# f7-teacher — AI 투자 선생님 (담당 에이전트 전용)

- 소유: 이 폴더 전부 + **예외로 `web/app/api/teacher/`**(스트리밍 route handler). 그 외 app/ 수정 금지.
- 스펙: `기능명세.md` F7 + `기획서.md` §6.1.
- UI: 키웅이 아바타 헤더("무엇이든 물어봐!") + 종목 맥락 카드("지금 보고 있는 종목: 삼성전자") + 예시 질문 칩("PER이 뭐야?" 등 4개) + SpeechBubble 채팅. 반말 톤.
- LLM: 모델 `claude-sonnet-5`(지연 우선). **스트리밍 필수** — 무대 시연에서 첫 토큰이 빨라야 함.
- 시스템 프롬프트 원칙(수정 금지 수준의 헌법): "사라/팔아라" 직접 답 금지 → 쉬운 설명 + 되물음. "사도 돼?" → "내가 대신 정해주진 않을게. 왜 사고 싶은지 먼저 생각해볼까?" 아이 눈높이·키웅이 페르소나·반말. 종목 맥락 주입.
- 안전: 출력도 `shared/llm` filter 통과(스트림 종료 후 검사+로깅). 전 응답 로깅.
- 완료 기준: 골든 패스 ② — 예시 질문 응답 + "사도 돼?" 회피 응답이 스트리밍으로 동작 + `npm run build`.
