# f10-chatbot — AI 챗봇 "키웅이"

- 이 폴더만 수정한다. 스펙: `docs/기능명세.md` F10.
- 범위는 50종목 공개 정보·현재 화면 맥락·서비스 사용법·금융 기초다. 추천·매매 시점·목표가·수익률 전망·훈계는 거절한다.
- FAQ·사전 우선 → 허용 질문만 `gemini-3.5-flash-lite`의 `generateContentStream` → 문장 버퍼 → `shared/llm/filter` → SSE 순서다. 원시 청크를 노출하지 않고 수치는 서버 도구 값만 쓴다.
- 선제 발화는 F10-B 고정 스크립트만 사용하고 대화·행동 데이터는 부모에게 전달하지 않는다.
- 완료: 골든 패스 ②·③·⑤ + `npm run build`.
