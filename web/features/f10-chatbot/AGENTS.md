# f10-chatbot — AI 챗봇 "키웅이"

- 이 디렉터리의 `AGENTS.md`와 `CLAUDE.md`는 한 쌍이다. 둘 중 하나를 수정하면 같은 작업에서 짝 파일도 동일하게 수정하고 완료 전 비교한다.
- 이 폴더만 수정한다. 구현·콘텐츠·데이터 단일 스펙: `web/features/f10-chatbot/SPEC.md`.
- 범위는 51종목 공개 정보·현재 화면 맥락·서비스 사용법·금융 기초다. 추천·매매 시점·목표가·수익률 전망·훈계는 거절한다.
- FAQ·사전 우선 → 허용 질문만 `gpt-5.6-luna`의 `responses.create({ stream: true })` → `response.output_text.delta` 문장 버퍼 → `shared/llm/filter` → SSE 순서다. 원시 델타를 노출하지 않고 수치는 서버 도구 값만 쓴다.
- 선제 발화는 `SPEC.md` §7의 고정 스크립트만 사용하고 대화·행동 데이터는 부모에게 전달하지 않는다.
- 플로팅 버튼 좌표·삭제 타깃 판정은 `lib/floating-avatar.ts` 순수 함수에 두고 화면은 표시만 한다(SPEC §3.2). 타깃은 버튼과 **같은 MTS 화면 사각형**을 기준으로 놓는다.
- 삭제 타깃에 놓은 버튼은 오른쪽 가장자리에 반쯤 접힌 퍽으로 남는다. 같은 호스트의 화면·주문 단계에서 유지되고, 한 번 탭하면 기본 자리로 돌아온다.
- 완료: 골든 패스 ②·③·⑤ + `npm run build`.
