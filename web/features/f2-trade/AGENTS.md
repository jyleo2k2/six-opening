# f2-trade — 모의투자 (담당 에이전트 전용)

- 소유: 이 폴더 전부. 밖은 수정 금지.
- 스펙: `기능명세.md` F2 + `docs/디자인시스템.md`.
- 화면: 종목 탐색(검색+업종 칩+리스트) → 종목 상세(현재가·라인 차트·내 보유·**아이 눈높이 설명 카드 2개**·선생님 호출 버튼) → 매수/매도(수량→예상 금액→**f3 폼 삽입**→시장가 즉시 체결).

- 시세: `app/api/quote` 프록시만 사용(KIS 직접 호출 금지). 개발은 fixtures 시세로.
