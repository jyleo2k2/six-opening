# 대표 검수 문안 적재 경로

옆 폴더의 `run-link-format-only.ts` 는 48종목 **초안 카드**를 만들어 HTML 로 보여 드리는 데서
끝났다. 대표님이 그 화면을 보고 문안을 다시 쓰셨고, 그 최종본을 DB 에 넣는 것이 이 경로다.

초안 리포트를 그대로 쓰지 않는 이유는 하나다 — **문안이 다르다.** 대표님이 다시 쓰신 글에는
근거 id 가 없는데, 스키마는 노출 필드마다 인용을 요구한다. 그래서 원문 기사를 다시 읽어
그 문안을 근거 문장에 **다시 묶는다.** 문안은 한 글자도 고치지 않는다.

## 옆 경로와 다른 점

| | `link-news/` | `curated/` |
|---|---|---|
| 문안을 누가 쓰나 | 모델 4역할 | 사람(대표 검수 최종본) |
| 기사 자격 판단 | 한다 | 안 한다 — 대표님이 이미 고르셨다 |
| 근거 id | 모델이 단다 | 원문을 다시 읽어 되묶는다 |
| 독립 검수 | `publication_reviewer` 가 한다 | **안 한다**(아래 주의) |

## 파일

| 파일 | 하는 일 |
|---|---|
| `curated-cards-2026-08-18.json` | 입력. 48종목 카드 문안·용어·사건 유형 |
| `citation-match.ts` | 문안을 근거 문장에 묶는 순수 함수 |
| `citation-match.test.ts` | 실측에서 걸린 오탐·누락을 굳힌 회귀 테스트 |
| `collect-curated-news.ts` | 원문 48건을 읽어 근거를 묶고 적재용 리포트를 만든다 |
| `load-curated-news.ts` | 근거에 묶인 것만 PostgREST 로 적재한다 |

## 문안을 근거에 묶는 규칙

두 가지를 **분리**한다. 섞으면 원문에 있는 사실을 떨어뜨리거나 없는 사실을 붙이게 된다.

1. **어느 문장이 이 줄을 뒷받침하나** — 숫자와 낱말 겹침으로 점수를 매겨 최고점을 고른다.
   조사를 떼면서 본다. `가격도`와 `가격`, `시간대를`과 `시간대`, `선택`과 `선택의` 를 통째로
   맞추려 하면 한국어에서는 거의 안 맞는다(SK하이닉스·대한항공이 이것 때문에 떨어졌다).
   이미 쓴 문장은 뒤로 미룬다 — 한 문장을 쪼갠 두 줄을 막는다.
2. **이 줄이 기사에 있는 사실인가** — 낱말 겹침으로는 셀 수 없다. 줄에 쓴 **숫자**가 기사
   어디에도 없으면 그 카드를 통째로 떨어뜨린다. 2026-08-16 전수 검사에서 유일하게 "거짓"
   이었던 결함이 이것이다.

숫자 판정에서 다음은 지어낸 값으로 보지 않는다. 전부 실측에서 오탐이 났던 자리다.

| 상황 | 예 |
|---|---|
| 공백을 사이에 둔 두 숫자 | `빌보드 200 1위` 를 `2001` 로 붙여 읽지 않는다 |
| `천`·`백` 표기 | 기사 `9만 1천 명` = 카드 `9만1000명` |
| 소수를 정수로 반올림 | 기사 `75.7%` → 카드 `76%` |
| 아랫자리를 버림(세 자리 이상) | 기사 `1868억 6100만` → 카드 `1869억` |
| 기사에 찍힌 발행 날짜 | 기사 `오는 30일` + 발행 8월 → 카드 `8월 30일` |

날짜는 반올림하지 않는다. 기사의 `16일` 에 카드의 `17일` 이 붙던 자리다(대한항공).

## 실행

```powershell
cd web

# 1. 원문 48건을 읽어 근거를 묶는다
node features/f2-trade/prototypes/child-news-role-pipeline/link-news/curated/collect-curated-news.cjs --overwrite

# 2. 문안과 인용을 눈으로 본다
node features/f2-trade/prototypes/child-news-role-pipeline/link-news/curated/load-curated-news.cjs --dry-run

# 3. 적재. 이미 있는 원문 주소는 건너뛰므로 다시 돌려도 된다
node features/f2-trade/prototypes/child-news-role-pipeline/link-news/curated/load-curated-news.cjs

# 4. 전수 검사와 복구본 갱신
npm run news:audit
npm run seed:news:export
```

그 종목들은 기존 카드를 그대로 쓰고, 다시 넣으려면 그 숫자가 실린 링크를 주시면 된다.

## 주의 — 독립 검수를 거치지 않았다

이 경로로 들어간 게시물의 `review_*` 컬럼은 **대표님이 검수 화면에서 확인하셨다는 선언**이지
모델 판정이 아니다. `manual-drafts/build.mjs` 와 같은 전제다.

문안이 기존 4역할 파이프라인을 통과한 것도 아니다. 48건 중 상당수는 채용·행사·사회공헌·
홍보성 기사라 `relevance_selector` 라면 `ROUTINE_OR_PROMOTIONAL` 로 거부했을 유형이다.
기사를 사람이 골랐다는 결정을 그대로 따른 것이며, 자동 수집 경로에는 이 완화를 적용하지 않는다.

기계로 지킨 것은 두 가지뿐이다 — **모든 노출 문장이 실제 원문 문장을 인용하고**, **기사에
없는 숫자를 쓴 카드는 들어가지 않는다.**
