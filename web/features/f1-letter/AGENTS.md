# f1-letter — 주간 투자편지 (담당 에이전트 전용) ★메인 기능

- 소유: 이 폴더 전부 (화면 + 리포트·궁합 프롬프트 + server action). 밖은 수정 금지.
- 스펙: `기능명세.md` F1 + `기획서.md` §6.2·6.3·6.6 + `docs/디자인시스템.md`.
- 화면 순서(세로 스토리): 키웅이 인트로 → 개인 리포트(유형 카드 "이번 주 민지는 뉴스 사냥꾼형!" + 지표 + 잘한 점·놓친 점) → 가족 비교(민지|엄마 나란히) → 궁합(BigPercent "76%" + 관점 한 줄 대비) → 투자토크 CTA.
- LLM: 모델 `claude-opus-5`(shared/llm 상수). 프롬프트는 이 폴더에, 호출은 `shared/llm` client 경유(필터 자동). **지표 수치는 `shared/engine` 산출값을 주입 — LLM이 계산·추정 금지.** 개발은 `shared/data/fixtures`의 목업 리포트로 먼저.
- 문구 규칙: 유형 라벨은 "이번 주" 기간 표기. 우열·추천·전망 표현 금지(필터가 잡지만 프롬프트에서부터 차단).
- 완료 기준: 골든 패스 ④ — 시드 데이터로 편지 전체 스크롤 동작(픽스처 모드), 실연동 스위치 시 필터 통과 로그 확인 + `npm run build`.
