# f8-pet — 가족 AI펫 (담당 에이전트 전용)

- 소유: 이 폴더 전부. 밖은 수정 금지 (라우트 연결·shared 변경은 오케스트레이터).
- 스펙: `docs/기능명세.md` F8 + `docs/기획서.md` §6 + `docs/펫서비스기획.md`(원안). 상위 규칙: `web/AGENTS.md`.
- 구성 요소: 펫 화면(상태·컨디션·감지 순간 말풍선 목록·주간 질문·동시 공개) · 홈 상주용 펫 위젯(f0가 import) · 부모 '오늘의 순간' 카드 · LLM 프롬프트(리액션·순간 번역·주간 질문) server action.
- **철칙: 자유 입력 없음.** 아이가 펫에게 보내는 텍스트/음성 입력 UI를 만들지 않는다. 펫이 먼저 발화하고 아이는 열람+선택지로만 반응.
- 트리거 판정은 `shared/engine`의 행동 프로파일 함수 결과만 사용 — 이 폴더에서 임계치 로직을 중복 구현하지 않는다. LLM 호출은 임계치 통과 시에만, `shared/llm` client 경유.
- 되묻기 원칙: 정답·훈계 금지, 모든 생성 문구는 질문 또는 선택지로 마무리. 방향성 언어(오른다/내린다) 금지 — 전 출력 `shared/llm/filter` 통과.
- 투명성: 부모에게 전달된 '오늘의 순간'은 민지 화면에도 동일 표시 컴포넌트 제공.
- 펫 성장·컨디션 수치는 `shared/engine` 계산값 표시만 — 판단력 채점 UI 금지 (완전 제외 항목).
- 완료 기준: 골든 패스 ③④⑤ — 확신도 25 매수 → 펫 리액션 말풍선 → 엄마 뷰 오늘의 순간 → 주간 질문 동시 공개 → 컨디션 변화가 시드+픽스처로 동작 + `npm run build`.
