# f4-talk — 가족 투자토크 (담당 에이전트 전용)

- 소유: 이 폴더 전부 (화면 + 질문 생성·관점 정리 프롬프트 + server action). 밖은 수정 금지.
- 스펙: `기능명세.md` F4 + `기획서.md` §6.4.
- 흐름: 질문 카드 → 내 답변 입력 → 제출 후 대기("엄마가 아직 답을 안 썼어요 🔒") → **둘 다 제출 시 동시 공개**(두 답 나란히) → AI 정리 카드(공통점/차이) → 다음 주 미션 카드. 상대 답은 제출 전 절대 노출 금지(앵커링 방지) — 스위처로 계정 바꿔도 안 보여야 함.
- LLM: 모델 `claude-opus-5`. 질문은 주간 데이터 기반(engine 지표 주입), 호출은 `shared/llm` 경유. 시연 질문 픽스처: "인기는 많은데 아직 돈을 못 벌고 있는 회사라면 우리 가족은 투자할까?"
- 완료 기준: 골든 패스 ⑤ — 민지 답 → 엄마 전환 답 → 동시 공개 → AI 정리까지 픽스처로 동작 + `npm run build`.
