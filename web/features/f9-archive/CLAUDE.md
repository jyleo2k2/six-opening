# f9-archive — 아카이브

- 이 디렉터리의 `AGENTS.md`와 `CLAUDE.md`는 한 쌍이다. 둘 중 하나를 수정하면 같은 작업에서 짝 파일도 동일하게 수정하고 완료 전 비교한다.
- 이 폴더만 수정한다. 단일 스펙: `web/features/f9-archive/SPEC.md`.
- `gpt-5.6-luna`는 `shared/engine` 산출로 성향 서술만 만든다. 유형 라벨·수치는 엔진이 계산하며 원시 로그와 수익률 서술은 모델에 주지 않는다.
- 유형은 기간을 표시하고 데이터가 적으면 관찰 초기로 안내한다.
- 완료: 골든 패스 ⑥ + `npm run build`.
