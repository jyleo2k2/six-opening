# f9-archive — 아카이브 (담당 에이전트 전용)

- 소유: 이 폴더 전부. 밖은 수정 금지.
- 스펙: `docs/기능명세.md` F9 + `docs/기획서.md` §6.7. 상위 규칙: `web/AGENTS.md`.
- 화면: 탭 3개 — ① AI 성향 리포트(유형 라벨 + 근거 태깅 분포 + 확신도 패턴 + 잘한 점·놓친 점) ② 수익률 리포트(추이 라인·보유·평가손익 — **LLM 서술 없음, 숫자 그대로**) ③ 가족 성장기록(시즌 초↔현재 4지표 + 펫 비포/애프터 + 시즌 말 목업 카드).
- 성향 서술·유형 라벨만 LLM: `shared/engine` 지표 JSON → server action 프롬프트 → `shared/llm` client → filter. LLM에 원시 거래 로그를 주지 않는다 — 엔진 산출만.
- 유형 라벨은 "이번 주" 기간 표기 필수 (고정 낙인 금지). 데이터 적으면 "아직 관찰 초기" 문구.
- 데이터: `shared/store` 셀렉터 + `shared/data/seed`(4주차·펫 Lv.2).
- 완료 기준: 골든 패스 ⑥ — 민지 성향 리포트("뉴스 사냥꾼형")·수익률·성장기록이 시드로 렌더 + `npm run build`.
