# F9 — 가족 아카이브 기능 명세

> **기능 단일 원본** · 2026-08-13 · 기준: `docs/영웅키움_기획_통합문서_v2.md` §11, 2026-08-13 11:00 서비스 개요
>
> F9의 스코어링 입력·출력, 화면, LLM 경계, 완료 기준은 이 파일에서 관리한다. 제품 목표·법무·전역 레드라인은 통합문서를 따르며, 이 기능을 바꿀 때는 이 파일을 먼저 수정하고 전역 문서에는 요약과 링크만 둔다.

## 1. 목적과 범위

F9는 가족의 기록을 세 부분으로 보여 준다.

- **① 거래 데이터**: 종목별 차트 위에 부모와 자녀의 매수·매도 지점을 함께 표시한다. 점을 누르면 그때 입력한 거래이유가 그대로 뜬다. 구현은 F11이 소유한다.
- **② 투자성향 분석**: 거래·행동 데이터를 **능력치 5개**(10점 만점)로 환산해 오각형으로 보여주고, 두 쌍의 우세로 **캐릭터 4종**을, 정확력으로 **정확 등급(별)**을 정한다. 예: 🎯 저격수 ★★☆.
- **③ 거래내역 피드**: 부모·자녀 거래가 한 줄로 흐르고 서로 코멘트를 남긴다. 구현은 F11이 소유한다.
- **수익률 리포트**: 정량값을 그대로 표시하며 LLM이 해석하거나 전망하지 않는다.
- **가족 비교**: 양측 동의를 전제로 서로 다른 능력치·캐릭터를 중립적으로 비교한다.

## 2. 소유권과 의존 관계

| 영역 | 소유 위치 | 책임 |
|---|---|---|
| 아카이브 UI·F9 프롬프트 | `web/features/f9-archive/` | 리포트·가족 비교·시즌 기록 |
| 스코어링 엔진 | `web/shared/engine/` | 능력치 5개·캐릭터·정확 등급 계산 |
| 가족 매매 차트 | `web/features/f11-feed/SPEC.md` | 차트 마커·거래이유 연결 |
| 거래·행동 원본 | `web/shared/store/` | F2·F3 기록과 포트폴리오 스냅샷 |
| LLM 클라이언트·필터 | `web/shared/llm/` | Luna 호출과 공통 출력 필터 |
| 시드·픽스처 | `web/shared/data/` | 2주치 누적 행동과 3주차 데모 상태 |

- F9는 `shared/engine`이 만든 JSON을 읽고 표시한다. 기능 폴더에서 스코어를 다시 계산하지 않는다.
- 공용 계약 변경은 `web/shared/AGENTS.md`를 따른다.
- F10 챗봇 대화와 선제 발화 로그는 능력치·캐릭터 산출에 넣지 않는다.
- **산출된 캐릭터·능력치는 F10의 개입 방식을 결정하는 입력값으로 전달된다** (통합문서 §12 B-1).

## 3. 입력 데이터

### 3.1 허용 입력

- F2 거래 로그: 종목, 수량, 시각, 체결가, 보유기간, 실현손익
- F2 탐색 이벤트: 뉴스·기업정보·차트 탭 진입과 상세 체류시간
- F2 포트폴리오 스냅샷: 보유 종목의 섹터, 현금비중, 평가손익
- 체결 후 5거래일 종가: 정확력 적중 판정용 시세 (`app/api/quote` 경유 캔들)
- F3 질문식 기록: 매수·매도 근거, 확신도, 예상 보유기간

### 3.2 금지 입력

- F10 대화 원문과 질문 횟수
- 가족 구성원의 비동의 원문 기록
- 모델이 추정하거나 생성한 수치
- 외부에서 임의로 보강한 투자 평가·주가 전망

## 4. 능력치 5개 · 캐릭터 4종 · 정확 등급

> 다섯 항목 모두 **주관적 설문이 아니라 실제 기록에서 기계적으로 산출**한다. 아이에게 성향 검사를 시키지 않고, 이미 한 행동으로만 계산한다.

### 4.1 능력치 산식 (각 10점 만점)

| 능력치 | 무엇을 재나 | 산출 기준 |
|---|---|---|
| 🔍 **근거력** | 사기 전에 알아보고 결정하나 | 매수 직전 뉴스·기업정보·차트 3개 탭 중 **2개 이상을 유효 열람한 매수의 비율 × 10** |
| ⚡ **직관력** | 느낌으로 빠르게 결정하나 | **10 − 근거력** (유효 열람 0~1개 상태에서 매수한 비율) |
| 🎯 **집중력** | 확신한 곳에 몰아 담나 | 보유 종목이 걸쳐 있는 **섹터 개수**와 **현금비중**을 10점으로 환산 — 섹터 **3개 이하**면 높고, **4개 이상**이거나 현금비중 **50% 이상**이면 낮음. 환산 곡선 세부는 [미결정] |
| 🧺 **분산력** | 여러 곳에 나눠 담나 | **10 − 집중력** |
| 🔮 **정확력** | 사고판 시점이 맞았나 | 매수한 뒤 오르거나 매도한 뒤 내렸으면 '적중' — **체결 후 5거래일 종가 기준 적중률 × 10** |

- **유효 열람** = 탭 진입 AND 해당 상세정보에 **10초 이상 체류**. 탭만 눌렀다 바로 나오면 세지 않는다.
- 근거력+직관력 = 10, 집중력+분산력 = 10인 **보완쌍**이다. 오각형이 한쪽으로 기울면 그쪽 성향이 우세하다.
- 정확력 적중 판정: 매수는 체결가보다 5거래일 후 종가가 높으면, 매도는 낮으면 적중. 체결 후 5거래일이 지나지 않았거나 종가 데이터가 없는 거래는 판정을 보류하고 표본에서 제외한다. 매도 체결가는 매도 당일(없으면 직전 거래일) 종가로 근사한다. [가정]
- 임계값(탭 2개, 섹터 3/4개, 현금비중 50%, 5거래일)은 개요 확정값이며 임의로 바꾸지 않는다.

### 4.2 캐릭터 4종 — 두 쌍의 우세로 결정

| 캐릭터 | 판정 | 설명 |
|---|---|---|
| 🎯 **저격수** | 근거 > 직관 · 집중 > 분산 | 찾아볼 건 다 찾아보고 확신이 선 소수 섹터에 몰아 담음 |
| 🧩 **전략가** | 근거 > 직관 · 분산 > 집중 | 알아본 뒤 여러 섹터에 나눠 담음. 근거와 분산을 모두 챙김 |
| ⚡ **승부사** | 직관 > 근거 · 집중 > 분산 | 마음에 들면 바로 한 곳에 건다. 빠르지만 기록이 얇음 |
| 🦋 **탐험가** | 직관 > 근거 · 분산 > 집중 | 여기저기 가볍게 조금씩 담거나 현금을 남겨둠 |

- **동점 처리**: 5:5로 갈리면 **근거·집중 쪽으로 귀속**한다. 기준을 하나로 고정해 시즌마다 결과가 흔들리지 않게 한다.
- 캐릭터에는 **우열이 없다**. 저격수가 탐험가보다 낫지 않다. 아이 화면에 "정답은 없어요!" 캡션을 병기한다.
- 시즌(분기)마다 다시 산출하며 기간을 반드시 표시한다. 예: "2026년 3분기 민지는 🎯 저격수".
- 판정에 쓸 체결 매수가 3건 미만이면 [가정] 캐릭터·별을 단정하지 않고 "아직 관찰 초기"라고 표시한다.

### 4.3 정확 등급 — 캐릭터 옆에 별로 붙음

| 등급 | 조건 |
|---|---|
| ★★★ | 정확력 7점 이상 |
| ★★☆ | 정확력 4~6점 |
| ★☆☆ | 정확력 3점 이하 |

- **캐릭터는 성향, 별은 실력**이다. 별은 분기마다 다시 계산되며 "다음 시즌엔 별을 하나 더"라는 재참여 동기가 된다.
- 별은 정확력 하나에서만 나온다. 다른 능력치를 등급·점수 경쟁으로 표현하지 않는다.
- **판정 중 상태**: 적중 판정이 끝난 거래가 3건 미만이면 [가정] 정확력과 별을 계산하지 않는다. 화면은 별 대신 "판정 중" 배지와 "사고판 지 5거래일이 지나면 채점돼요" 안내를 보여 준다. 중립값(5점 등)으로 채워 넣지 않는다 — 계산하지 않은 수치는 표시하지 않는다.

### 4.4 엔진 출력 계약

```ts
type BehaviorProfileSnapshot = {
  userId: string;
  periodStart: string;
  periodEnd: string;
  /** 판정에 사용한 매수 기록 수 */
  sampleSize: number;
  abilities: {
    /** 근거력 0~10 */
    evidence: number;
    /** 직관력 = 10 − evidence */
    intuition: number;
    /** 집중력 0~10 */
    focus: number;
    /** 분산력 = 10 − focus */
    diversification: number;
    /** 정확력 0~10. 적중 판정이 끝난 거래가 표본 미만이면 null */
    accuracy: number | null;
  };
  /** 저격수·전략가·승부사·탐험가 */
  character: "sniper" | "strategist" | "challenger" | "explorer" | null;
  /** 정확 등급 별 개수. accuracy 가 null 이면 null */
  starGrade: 1 | 2 | 3 | null;
  /** pending 이면 정확력·별은 아직 채점 전이다 */
  accuracyState: "graded" | "pending";
  /** 적중 판정이 끝난 거래 수 */
  gradedTradeCount: number;
  /** 5거래일 미경과 등으로 판정을 보류한 거래 수 */
  pendingTradeCount: number;
  reasonDistribution: Record<string, number>;
  confidencePattern: {
    average: number;
    actionAlignment: number;
  };
  observationState: "initial" | "ready";
};
```

실제 타입 이름은 `web/shared/types/`가 소유한다. 위 계약의 의미를 바꿀 때는 엔진 테스트와 F9 렌더링을 함께 갱신한다.

## 5. 폐기된 항목

| 폐기 | 대체 |
|---|---|
| 판단 근거·포트폴리오 폭 2축과 4유형(직관형·근거형 × 집중러·분산러) | 능력치 5개 + 캐릭터 4종 + 정확 등급 (2026-08-13 개요) |
| 성향 5축(집중–분산·속도·신중함·손실 대응·탐험심) | 능력치 5개 — 이름이 비슷해도 산식·의미가 다르므로 5축 산식을 복구하지 않는다 |
| 유형 라벨 매트릭스 8~12종 | 캐릭터 4종 |
| 친화도 스코어(ML) | 없음 — 성장은 시즌별 오각형 누적과 캐릭터·별 변화로 본다 |

"아이에게 수치를 노출하지 않는다"는 옛 제약은 폐기 상태를 유지한다. 능력치 점수와 별은 화면에 노출한다. 다만 **캐릭터를 우열·성적으로 표현하지 않는다**는 원칙은 그대로 승계한다.

## 6. 화면 구성

### 6.1 가족 매매 차트

- 종목별 차트 위 부모·자녀 매수·매도 지점. 점을 누르면 거래이유가 뜬다.
- 렌더링과 마스킹 규칙은 `web/features/f11-feed/SPEC.md` §6이 소유한다.

### 6.2 투자성향 카드

- 능력치 5개 오각형 레이더(10점 만점)와 시즌·기간 표시
- 시즌 결과: 캐릭터 + 정확 등급 (예: 🎯 저격수 ★★☆)
- 판정 근거 한 줄: "근거 7 > 직관 3 → 근거형 · 집중 6 > 분산 4 → 집중형"
- 근거 태깅 분포와 확신도 패턴
- Luna가 만든 관찰 서술 2~3문장
- "정답은 없어요!" 캡션
- 정확력이 판정 중이면 오각형의 정확력 꼭짓점을 점선으로 비우고 별 자리에 "판정 중" 배지를 단다
- 데이터 부족 시 "아직 관찰 초기" 상태

### 6.3 수익률 리포트

- 보유 종목, 평가손익, 수익률 추이
- 정량값을 그대로 표시한다.
- LLM 서술과 미래 전망을 붙이지 않는다.

### 6.4 가족 비교

- 부모와 자녀의 오각형과 캐릭터를 나란히 표시한다.
- "민지는 빠르게, 엄마는 오래 재고 정해요. 스타일이 달라요."처럼 중립적으로 설명한다.
- 캐릭터·능력치를 승패·우열·닮음 점수로 표현하지 않는다. 가족 간 별 개수 비교를 전면에 세우지 않는다. [추론]
- 양측 공개 동의가 없으면 상대 기록을 표시하지 않는다.

### 6.5 시즌 기록

- 시즌별 오각형이 겹쳐 쌓여 어느 능력치가 자랐는지가 성장 기록이 된다.
- 시즌별 캐릭터·별 변화 궤적과 수익률 결산
- 시즌이 반복될수록 이전 시즌 카드를 누적한다.

## 7. LLM 경계

F9는 `gpt-5.6-luna`를 **서술 생성에만** 사용한다.

```text
F2·F3 원본 기록
  → shared/engine 룰·통계 계산
  → BehaviorProfileSnapshot JSON
  → Luna 관찰 서술 1회
  → shared/llm/filter
  → F9 화면
```

- 모델 입력에는 엔진 산출 JSON과 능력치·캐릭터 라벨 설명만 전달한다.
- 원시 거래 로그, 가족 대화, 수익률 전망을 모델에 전달하지 않는다.
- 능력치·캐릭터·별과 모든 수치는 엔진이 계산한다. 모델이 바꾸거나 새로 만들 수 없다.
- 서술은 관찰 톤으로 2~3문장, 잘한 점·아쉬운 점 각 1~2개 이내다.
- 종목 추천, 매매 시점, 목표가, 수익률 전망, 훈계를 생성하지 않는다.
- 출력은 반드시 `web/shared/llm/filter`를 통과한다. 실패하면 고정 폴백을 표시한다.

## 8. 데모 상태

- 시즌 3주차 시점으로 시작한다.
- 시드 2주치 거래·질문식 기록·탐색 이벤트를 제공한다.
- 시연 중 새 거래를 합산해 엔진을 다시 계산하고 능력치·캐릭터·별이 화면에서 갱신되어야 한다.
- 민지와 엄마 계정 전환 시 각자의 기록만 표시한다.

## 9. 금지 사항

- 캐릭터를 우열·성적·등수로 표현하지 않는다.
- 데이터가 적은 사용자의 캐릭터를 단정하지 않는다.
- 정확 등급(별) 외의 능력치를 실력·등급으로 표현하지 않는다.
- 수익률 리포트에 LLM 해석·예측을 붙이지 않는다.
- 가족 데이터를 동의 없이 비교하지 않는다.
- 기능 폴더에서 엔진 계산이나 공용 타입을 복제하지 않는다.

## 10. 완료 기준

- 골든 패스 ⑥에서 민지의 능력치 5개 오각형, 캐릭터, 정확 등급, 근거 분포가 시드로 렌더링된다.
- 시연 중 F2·F3 기록이 추가되면 엔진 산출과 F9 화면이 갱신된다.
- 엄마 전환 후 엄마 리포트와 중립적인 가족 비교가 표시된다.
- Luna 서술이 엔진 JSON과 일치하고 공통 필터를 통과한다.
- 수익률 값은 모델을 거치지 않고 표시된다.
- 엔진 지표별 테스트와 `web/`의 `npm run build`가 통과한다.
