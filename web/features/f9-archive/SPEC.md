# F9 — 성장 아카이브 기능 명세

> **기능 단일 원본** · 2026-08-11 · 기준: `docs/영웅키움_기획_통합문서_v2.md` v2.6 §11
>
> F9의 스코어링 입력·출력, 화면, LLM 경계, 완료 기준은 이 파일에서 관리한다. 제품 목표·법무·전역 레드라인은 통합문서를 따르며, 이 기능을 바꿀 때는 이 파일을 먼저 수정하고 전역 문서에는 요약과 링크만 둔다.

## 1. 목적과 범위

F9는 부모와 자녀의 행동 데이터를 **우열 없는 투자 스타일**과 시즌별 성장 기록으로 보여 준다.

- **성향 5축**: 아이와 부모에게 보여 주는 스타일 설명이다.
- **친화도 스코어**: 서비스 전후의 친숙함·습관 변화를 검증하기 위한 지표다. 아이에게 직접 점수로 노출하지 않는다.
- **수익률 리포트**: 정량값을 그대로 표시하며 LLM이 해석하거나 전망하지 않는다.
- **가족 비교**: 양측 동의를 전제로 서로 다른 스타일을 중립적으로 비교한다.

## 2. 소유권과 의존 관계

| 영역 | 소유 위치 | 책임 |
|---|---|---|
| 아카이브 UI·F9 프롬프트 | `web/features/f9-archive/` | 리포트·가족 비교·시즌 기록 |
| 스코어링 엔진 | `web/shared/engine/` | 수치·축·유형 라벨 계산 |
| 거래·행동 원본 | `web/shared/store/` | F2·F3 기록과 포트폴리오 스냅샷 |
| LLM 클라이언트·필터 | `web/shared/llm/` | Luna 호출과 공통 출력 필터 |
| 시드·픽스처 | `web/shared/data/` | 2주치 누적 행동과 3주차 데모 상태 |

- F9는 `shared/engine`이 만든 JSON을 읽고 표시한다. 기능 폴더에서 스코어를 다시 계산하지 않는다.
- 공용 계약 변경은 `web/shared/AGENTS.md`를 따른다.
- F10 챗봇 대화와 선제 발화 로그는 성향 스코어링에 넣지 않는다.

## 3. 입력 데이터

### 3.1 허용 입력

- F2 거래 로그: 종목, 수량, 시각, 보유기간, 실현손익
- F2 탐색 이벤트: 상세 체류시간, 조회 종목·업종 수
- F2 포트폴리오 스냅샷: 종목·업종 비중, 현금, 평가손익
- F3 질문식 기록: 매수·매도 근거, 확신도, 예상 보유기간

### 3.2 금지 입력

- F10 대화 원문과 질문 횟수
- 가족 구성원의 비동의 원문 기록
- 모델이 추정하거나 생성한 수치
- 외부에서 임의로 보강한 투자 평가·주가 전망

## 4. 성향 5축

각 축은 0~100으로 주간 산출하지만 값의 높고 낮음은 실력이나 등급이 아니다.

| 축 | 측정값 | 양끝 스타일 |
|---|---|---|
| 집중–분산 | 종목·업종 집중도 | 한우물형 ↔ 골고루형 |
| 속도 | 평균 보유기간·회전율·예상 보유기간 일치 | 진득이형 ↔ 재빨리형 |
| 신중함 | 주문 전 탐색 깊이·확신도와 투자 행동의 관계 | 직진형 ↔ 돌다리형 |
| 손실 대응 | 하락 구간의 보유·매도·추가매수 패턴 | 버티기형 ↔ 갈아타기형 |
| 탐험심 | 새 종목·새 업종 시도 비율 | 익숙함형 ↔ 개척자형 |

### 4.1 유형 라벨

- 두드러진 상위 2축을 수작성 라벨 매트릭스 8~12종에 매핑한다.
- “이번 주 민지는 재빨리 개척자형!”처럼 **기간을 반드시 표시**한다.
- 주간마다 갱신하며 고정 성격이나 낙인으로 표현하지 않는다.
- 데이터가 적으면 유형을 단정하지 않고 “아직 관찰 초기”라고 표시한다.

### 4.2 엔진 출력 계약

```ts
type BehaviorProfileSnapshot = {
  userId: string;
  periodStart: string;
  periodEnd: string;
  sampleSize: number;
  axes: {
    concentration: number;
    speed: number;
    deliberation: number;
    lossResponse: number;
    exploration: number;
  };
  typeLabel: string | null;
  reasonDistribution: Record<string, number>;
  confidencePattern: {
    average: number;
    actionAlignment: number;
  };
  observationState: "initial" | "ready";
};
```

실제 타입 이름은 `web/shared/types/`가 소유한다. 위 계약의 의미를 바꿀 때는 엔진 테스트와 F9 렌더링을 함께 갱신한다.

## 5. 친화도 스코어

친화도 스코어는 투자 실력이나 수익 예측이 아니라 **서비스와 투자 개념에 익숙해지는 변화**를 검증하기 위한 지표다.

- 라벨 설계는 [미결정]이다. A안은 다음 시즌 재참여 확률, B안은 시즌 전후 설문 예측이다.
- 단순 접속·매매 횟수만으로 올리지 않는다. 근거 구체성, 계획–행동 일치, 확신도–행동 관계, 탐색 다양성 같은 질적 지표를 우선한다.
- 아이 화면에는 수치를 노출하지 않는다. 부모 리포트와 시즌 기록에만 표시한다.
- 실사용 데이터가 없는 데모 그래프에는 **시뮬레이션 데이터**임을 명시한다.
- F10 사용 데이터의 피처 포함 여부는 [미결정]이며, 결정 전에는 사용하지 않는다.

## 6. 화면 구성

### 6.1 성향 리포트

- 5축 게이지와 양끝 라벨
- 이번 주 유형 라벨
- 근거 태깅 분포와 확신도 패턴
- Luna가 만든 관찰 서술 2~3문장
- “정답은 없어요!” 캡션
- 데이터 부족 시 “아직 관찰 초기” 상태

### 6.2 수익률 리포트

- 보유 종목, 평가손익, 수익률 추이
- 정량값을 그대로 표시한다.
- LLM 서술과 미래 전망을 붙이지 않는다.

### 6.3 가족 비교

- 부모와 자녀의 5축을 막대로 나란히 보여 준다. 레이더 차트는 현재 범위가 아니다.
- “민지는 재빨리, 엄마는 진득하게. 스타일이 달라요.”처럼 중립적으로 설명한다.
- 승패·우열·닮음 점수로 표현하지 않는다.
- 양측 공개 동의가 없으면 상대 기록을 표시하지 않는다.

### 6.4 시즌 기록

- 시즌 초와 현재의 5축 변화
- 부모용 친화도 추이
- 수익률 결산
- 시즌이 반복될수록 이전 시즌 카드를 누적한다.

## 7. LLM 경계

F9는 `gpt-5.6-luna`를 **서술 생성에만** 사용한다.

```text
F2·F3 원본 기록
  → shared/engine 룰·통계 계산
  → BehaviorProfileSnapshot JSON
  → Luna 관찰 서술 1회
  → shared/llm/filter
  → F9 화면
```

- 모델 입력에는 엔진 산출 JSON과 필요한 라벨 설명만 전달한다.
- 원시 거래 로그, 가족 대화, 수익률 전망을 모델에 전달하지 않는다.
- 유형 라벨과 모든 수치는 엔진이 계산한다. 모델이 바꾸거나 새로 만들 수 없다.
- 서술은 관찰 톤으로 2~3문장, 잘한 점·아쉬운 점 각 1~2개 이내다.
- 종목 추천, 매매 시점, 목표가, 수익률 전망, 훈계를 생성하지 않는다.
- 출력은 반드시 `web/shared/llm/filter`를 통과한다. 실패하면 고정 폴백을 표시한다.

## 8. 데모 상태

- 시즌 3주차 시점으로 시작한다.
- 시드 2주치 거래·질문식 기록·탐색 이벤트를 제공한다.
- 시연 중 새 거래를 합산해 엔진을 다시 계산하고 축 또는 분포가 화면에서 갱신되어야 한다.
- 민지와 엄마 계정 전환 시 각자의 기록만 표시한다.

## 9. 금지 사항

- 성향 축을 점수·실력·등급으로 표현하지 않는다.
- 데이터가 적은 사용자의 유형을 단정하지 않는다.
- 아이에게 친화도 숫자를 노출하지 않는다.
- 수익률 리포트에 LLM 해석·예측을 붙이지 않는다.
- 가족 데이터를 동의 없이 비교하지 않는다.
- 기능 폴더에서 엔진 계산이나 공용 타입을 복제하지 않는다.

## 10. 완료 기준

- 골든 패스 ⑥에서 민지의 5축, 주간 유형, 근거 분포가 시드로 렌더링된다.
- 시연 중 F2·F3 기록이 추가되면 엔진 산출과 F9 화면이 갱신된다.
- 엄마 전환 후 엄마 리포트와 중립적인 가족 비교가 표시된다.
- Luna 서술이 엔진 JSON과 일치하고 공통 필터를 통과한다.
- 수익률 값은 모델을 거치지 않고 표시된다.
- 엔진 지표별 테스트와 `web/`의 `npm run build`가 통과한다.
