# web/ — 앱 전역 규칙 (전 에이전트)

Next.js(App Router)+TS+Tailwind. 폴더 구조·스택 상세: `../docs/기술스택.md`.

## 모든 에이전트 공통

- 너의 작업 범위는 담당 폴더의 `AGENTS.md`가 정의한다. 그 밖은 읽기만.
- UI는 `../docs/디자인시스템.md`의 토큰·컴포넌트만 사용. 임의 hex·임의 컴포넌트 사본 금지. 등락색은 상승 `up`(빨강)/하락 `down`(파랑) 토큰 강제.
- `shared/`는 import 전용. 변경 필요 시 `shared/AGENTS.md` 요청 로그.
- LLM·시세 데이터가 필요한 화면은 `shared/data/fixtures` 목업으로 먼저 완성. SDK·외부 API 직접 호출 금지(각각 `shared/llm`, `app/api/quote` 경유).
- API 키를 클라이언트 코드·번들에 넣지 않는다. `NEXT_PUBLIC_` 접두사에 키 금지.
- 완료 판정 공통: `npm run build` 통과 + 담당 골든 패스 스텝이 시드 데이터로 동작 + 디자인시스템 위반 0.
- 커밋은 담당 브랜치(`feat/f2-trade` 형식)에만.

## AI 출력 안전 (전 기능)

- 모든 LLM 출력은 `shared/llm/filter` 통과 후 표시. 금지: 사야/팔아야/매수 기회/목표가/손절가/오를·내릴 전망/확실 — 방향성 언어 전면 금지.
- **자유 입력 없음**: 사용자가 AI에게 자유 텍스트/음성으로 말을 거는 UI를 어디에도 만들지 않는다. 펫이 먼저 발화, 반응은 선택지로만 (기획서 §6.1).
- 펫 발화는 훈계·정답 제공 금지 — 항상 되묻기 또는 선택지로 마무리. 판단력 채점 UI 전면 금지.
- LLM은 숫자를 계산하지 않는다 — 지표·트리거 판정은 `shared/engine` 산출값을 프롬프트에 주입. LLM 호출은 임계치 통과 시에만.
- 카피 말투: 민지(자녀) 뷰 반말, 부모 뷰 존댓말 (디자인시스템 §4).
