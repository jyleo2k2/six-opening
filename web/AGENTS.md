# web — 자녀 셸 · 부모 뷰 세션 하네스

> 적용 범위: `web/` 하위 전체.
> 규칙 본문은 이 파일에만 쓴다. 같은 폴더 `CLAUDE.md`는 `@AGENTS.md` 한 줄이다 (루트 `AGENTS.md` §동기화).
> 최종 갱신: 2026-08-07 (게임 = 히스토리 투자 시뮬. 채팅 정책 신설)

## 담당 오너

세 트랙이 한 앱을 나눠 쓴다. **공유 파일의 단일 작성자는 통합 오너 이재용이다.**

| 경로 | 트랙 | 담당 |
|---|---|---|
| `app/(child)/game/**` | ① 게임 | 이재용·이호연 |
| `app/(child)/{home,stock,proposal}/**` · `app/(parent)/**` · `app/(public)/invite/**` · `features/proposal/**` · `lib/brokerage/**` | ② 투자제안서 | 김설빈·박혜준 |
| `app/(child)/{news,dex}/**` | ③ 뉴스·도감 | 김경렬·강소정 |

**공유 핫스팟** — claim이 겹치면 세션 생성이 거부된다: `app/layout.tsx` · `app/(child)/layout.tsx`(탭바) · `components/ui/**` · 트랙을 가로지르는 공용 타입.

신규 화면·컴포넌트는 각 트랙이 독립 구현하고, **공용 연결(레이아웃·탭바 배선·라우팅)은 통합 오너의 별도 PR로 넘긴다.** 트랙 간 계약이 바뀌면 계약 PR을 먼저 머지한다.

## 세션 시작 규칙

1. 루트 `AGENTS.md` → `docs/구현계획.md` → 이 파일 순서로 읽는다. 게임 화면 작업이면 `game/AGENTS.md`도 읽는다.
2. 루트 `C:\dev\six-opening`에서 고치지 않는다. `git_session_manager.py start`로 워크트리를 받아 거기서 작업한다.
3. 위 표에서 자기 트랙 경로만 claim한다. 다른 트랙 폴더는 읽기만 한다.

## 불변식

- **룰을 재구현하지 않는다.** 게임 판정·가격 계산은 `game` 워크스페이스에서 import한다. 클라이언트에 룰을 복제하면 서버 권위 판정과 갈라진다.
- **서버가 주는 것만 보여준다.** 클라이언트는 `viewFor`를 거친 상태만 받는다 — 이벤트 큐·타인 뉴스·타인 정보 내용·타인 보유 내역을 화면이 요구하지도, 추측해 그리지도 않는다 (기획서 §9).
- **게임 회의는 템플릿 조합만이다** (기획서 §4, v2 확정 — 자유 텍스트 폐기). 화면은 `[주어]×[섹터]×[동사]` 칩 + 내 뉴스 공유 + 이모티콘만 제공하고, 자유 입력창을 만들지 않는다. 유저 생성 텍스트가 없으므로 금칙어 필터 과제는 소멸. 이모티콘 5종은 모든 페이즈 상시.
- **앱이 종목을 추천하지 않는다.** 추천·제안의 주체는 항상 자녀다 (투자권유 규제, 구현계획 §7).
- **부모 승인 없이 체결되지 않는다.** 제한모드를 우회하는 경로를 만들지 않는다.
- 아이 노출 텍스트에 **수익 보장·확정 수익·원금 보장·매수 권유** 표현을 쓰지 않는다. 아이 노출 문구를 바꾼 PR은 머지 전에 변경 범위를 직접 검색한다.
- **자동 발행 금지.** 아이에게 보이는 편집 콘텐츠는 사람 검수를 거쳐 커밋된 것(`content/` MDX, `game/data` 문구)만 렌더한다. 게임 회의 발화는 템플릿 조합이라 검수 대상 자체가 아니다.
- 자녀 개인정보는 **닉네임 + 부모 FK만** 수집한다.
- 실계좌·실시세는 **mock 어댑터(`lib/brokerage/mock`) 뒤에** 둔다. 라우트·컴포넌트가 외부 API를 직접 부르지 않는다. 실연동은 어댑터 교체로 한다.

## 검증 명령

**PowerShell에서 실행한다** — Bash 툴 셸에는 node가 PATH에 없다.

```powershell
npm run typecheck -w web   # tsc --noEmit
npm run build -w web       # next build
npm run dev                # 로컬 확인
```

아이 노출 문구를 바꿨으면 금지 표현을 검색한다.

```powershell
rg -n "수익.*보장|원금.*보장|확정 수익|추천 종목|매수하세요" app components features
```
